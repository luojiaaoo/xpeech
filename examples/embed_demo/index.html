仅供本地测试：正式接入必须从业务后端获取 JWT，签名密钥只能保存在后端，不能放在前端。 这里开放通道和 Key 输入只是为了方便测试；填写的 Key 会通过 POST 发送到本地演示后端，由后端签发 JWT 后返回，浏览器不签名。
