# GB/T 9704-2012 排版标准参数速查

> 本文件为参考文档，排版参数的完整依据来自《党政机关公文格式》国家标准（GB/T 9704-2012）。

## 页面设置

| 项目 | 数值 |
|------|------|
| 纸张 | A4 (210mm × 297mm) |
| 上边距 | 37mm |
| 下边距 | 35mm |
| 左边距 | 28mm |
| 右边距 | 26mm |
| 版心尺寸 | 156mm × 225mm |
| 每页行数 | 22行 |
| 每行字数 | 28字 |

## 字体字号

| 要素 | 字体 | 字号 |
|------|------|------|
| 标题 | 方正小标宋简体（或SimSun） | 二号 |
| 一级标题（一、二、） | 黑体 | 三号 |
| 二级标题（（一）（二）） | 楷体 | 三号 |
| 三级标题（1. 2.） | 仿宋 | 三号 |
| 四级标题（（1）（2）） | 仿宋 | 三号 |
| 正文 | 仿宋 | 三号 |
| 页码 | 宋体 | 四号半角 |

## 段落格式

- 正文行距：固定值 28磅
- 标题行距：固定值 32磅（标题较长时可适当调整）
- 正文首行缩进：2字符
- 正文中数字、英文使用 Times New Roman 字体
- 标题居中排列，回行时词意完整

## 页码

- 格式：`-1-`，`-2-`（数字左右各一条一字线）
- 单页码居右空一字，双页码居左空一字
- 距版心下边缘 7mm

## 层次序号规范

```
第一层：一、二、三、（黑体）
第二层：（一）（二）（三）（楷体）
第三层：1. 2. 3.（仿宋）
第四层：（1）（2）（3）（仿宋）
```

## 高级参数

| 参数 | 说明 | 示例 |
|------|------|------|
| `--author` | 发文机关名称（落款右对齐） | `--author "XX镇人民政府"` |
| `--date` | 成文日期（自动格式化） | `--date "2026-04-16"` 或 `--date "2026年4月16日"` |
| `--print-author` | 印发机关（版记居中） | `--print-author "XX镇人民政府办公室"` |
| `--print-date` | 印发日期（版记居中） | `--print-date "2026-04-17"` |
| `--cc` | 抄送机关（版记中） | `--cc "县委办公室，县政府办公室"` |
| `--redhead` | 红头机关名称 | `--redhead "XX省人民政府"` |
| `--doc-number` | 发文字号 | `--doc-number "X政发〔2026〕12号"` |
| `--copies` | 份号（6位阿拉伯数字） | `--copies "000001"` |
| `--secret-level` | 密级和保密期限 | `--secret-level "机密★20年"` |
| `--urgency` | 紧急程度 | `--urgency "特急"` |
| `--signer` | 签发人姓名（上行文） | `--signer "张三"` |
| `--recipient` | 主送机关 | `--recipient "县委办公室"` |
| `--notes` | 附注（可多个） | `--notes "此件公开发布"` |

### 日期格式化

支持 `2026-04-16`、`2026/04/16`、`2026年4月16日` 等格式，自动转为标准中文日期。

### 份号（GB/T 9704-2012 §7.2.1）

- 位置：版心左上角第一行
- 字体：阿拉伯数字，Times New Roman
- 格式：6位阿拉伯数字，如 `000001`
- 顶格编排
- 涉密公文必须标注份号

### 密级和保密期限（GB/T 9704-2012 §7.2.2）

- 位置：版心左上角第二行
- 字体：3号黑体
- 格式：密级★保密期限，如 `机密★20年`
- 顶格编排
- 保密期限中的数字用阿拉伯数字标注
- 密级和保密期限之间用“★”分隔

### 紧急程度（GB/T 9704-2012 §7.2.3）

- 位置：版心左上角第三行
- 字体：3号黑体
- 格式：特急、加急、平急
- 顶格编排

### 签发人（GB/T 9704-2012 §7.2.4）

- 位置：发文机关标志下空二行，居右空一字
- 字体：“签发人”三字用3号仿宋，签发人姓名用3号楷体
- 格式：签发人：XXX
- 上行文必须标注签发人
- 如有多个签发人，每行排两个姓名，回行时与上一行第一个签发人姓名对齐

### 主送机关（GB/T 9704-2012 §7.3.2）

- 位置：标题下空一行
- 字体：3号仿宋
- 格式：居左顶格，回行时仍顶格
- 最后一个机关名称后标全角冒号
- 如主送机关名称过多导致首页不能显示正文时，应将主送机关移至版记

### 附注（GB/T 9704-2012 §7.3.5）

- 位置：成文日期下一行
- 字体：3号仿宋
- 格式：居左空二字，加圆括号
- 示例：`（此件公开发布）`、`（联系人：张三，电话：13800138000）`
- 如有多个附注，每个附注单独一行

### 附件处理

正文中包含 `附件：xxx` 或 `附件:xxx` 时，自动识别为附件说明，使用仿宋三号居左排版。

### 红头

`--redhead` 添加红色发文机关标志（方正小标宋简体）+ 红色分隔线 + 可选发文字号 `--doc-number`。

## 注意事项

1. **字体兼容**：Linux 环境可能没有方正小标宋简体，脚本会自动降级到 SimSun（宋体），标题使用宋体加粗作为替代
2. **标题分行**：如果标题超过一行，脚本会自动换行并保持词意完整
10. **PDF 导出**：支持 `--format pdf` 或输出路径直接用 `.pdf` 后缀，通过 LibreOffice headless 转换，需要预装 `libreoffice-writer`
3. **智能层级识别**（不依赖Markdown语法也能识别）：
   - `一、` `二、` `第X部分` → 一级标题（黑体）
   - `（一）` `（二）` → 二级标题（楷体）
   - `1.` `2.` → 三级标题（仿宋）
   - `（1）` `（2）` → 四级标题（仿宋）
   - Markdown `##` 和 `**加粗**` 也能识别
4. **首行缩进**：正文段落自动首行缩进2字符，标题和列表项不缩进
5. **数字字体**：正文中的阿拉伯数字自动使用 Times New Roman
6. **页码设置**：单页码居右空一字、双页码居左空一字，格式 `-1-`，符合国标
7. **附件说明**（GB/T 9704-2012 §7.3.4）：
   - 正文下空一行，左空二字编排
   - 支持多种输入格式：
     - `附件：1. xxx  2. xxx`（单行多个，自动拆行）
     - `附件：xxx`（单行单个）
     - 多行续行（缩进行自动识别为一个附件块）
     - `附件1：xxx  附件2：xxx`（多行编号）
   - 多个附件每个单独一行，与「附件：」后内容对齐
   - 附件名称后自动去除末尾标点（国标要求不加标点）
   - 空附件兜底：`附件：` → `附件：（见附件）`
8. **日期格式化**：`--date` 和 `--print-date` 支持多种输入格式，自动转为标准中文日期
9. **印发信息**：`--print-author` 和 `--print-date` 在落款下方添加印发机关和日期
