## 一、统一入口六步

> **与 `SKILL` §4 的关系**：六步骨架同源，本表只写各步的**扩展口径**（年龄阶段表、启蒙/亲子单独定位、危机触发概括）；步骤定义与判定纪律以 `SKILL` §4、§3 为准，本表不复写。

### 第 0 步 · 紧急扫描（先于一切，包括读档案）

用户输入命中以下**十类红旗**任一 → **跳过所有流程与知识输出**，只给安全引导（身体类逐条判定清单与就医档位见 `09-危机信号与安全边界.md` §1.1、§1.2；心理危机与暴力伤害类见 §2）：

> **呼吸**（喘不上气 / 嘴唇发紫）｜**意识**（叫不醒 / 昏厥）｜**抽搐**｜**严重外伤**（大出血 / 坠落摔头）｜**中毒误服**｜**过敏反应**（面唇肿胀 + 呼吸急促）｜**高热伴精神差**｜**脱水 / 便血尿血**｜**心理危机**（"不想活了"、自伤）｜**虐待与家暴**

本步只负责**触发**：命中任一 → 停流程、只给安全引导。**具体条目与档位一律以 `09` §1.1 / §1.2 为准**，本文件不另列清单（避免与 `09` 出现两份口径）。

### 第 1 步 · 意图识别

先判**触发**（是否涉及孩子或家长的养育状态；六类隐式信号与不触发边界见主技能文件「意图自动识别」章节），再判**意图类型**（求方案/求话术/情绪宣泄/求判断/求安排/求记录/求资源/危机），决定输出形态；命中危机 → 只输出安全引导，其余全停。

### 第 2 步 · 年龄定位

| 阶段 | 年龄 | 主要承载文件 |
|---|---|---|
| 婴儿期 | 0-1 岁 | `01` §1、`02` 全篇 |
| 幼儿期 | 1-3 岁 | `01` §2、`05` §2-§6 |
| 学龄前期 | 4-6 岁 | `01` §3 |
| 学龄期 | 7-12 岁 | `01` §4 |
| 青春前期 | 10-12 岁 | `01` §5 |
| 青春期 | 13-18 岁 | `01` §6 |

无法判断年龄 → 只问一个问题："孩子大概几岁？"
10-12 岁重叠分流规则见 `01` §8。

**启蒙类问题单独定位**：早教怎么做、绘本共读、识字/拼音、数学与思维、外语启蒙、艺术音乐运动、专注力与自由玩耍、家庭启蒙环境、早教班与兴趣班、早教机与学习 APP、抢跑误区 → 一律读 `13`（不按年龄阶段拆到 `01`/`02`），年龄差异在 `13` §2 内部分段处理；学龄期学习动机与课外班取舍 → `13` §13。

**亲子关系类问题单独定位**：孩子"只认某一个人"、照顾者更换、长期分离后的重聚、关系是否健康、关系长期冷淡怎么重建、父母把孩子当情感伴侣、爸爸与孩子不亲、独属时间怎么排、关系紧张到什么程度该找专业 → **先按 `09` §3.5 判档（第 1 个文件）**，再按档位**只取 1 个落点文件（第 2 个文件），不并列加载**：分龄与依恋 → `01` §1.3（5）、§2.3（9）；重聚 → `05` §4.6；关系修复与边界 → `07` §6.3、§4.8；陪伴与父职/独属时间 → `10` §3.6、§4.7；关系体检 → `11` §3.3A。

### 第 3 步 · 场景域判定

把问题归入 §三 场景域之一确定**主域**，必要时再定**辅域**（一次最多 2 个文件）。

### 第 4 步 · 加载文件

只读命中章节，禁止全量加载（行号精读纪律见 `SKILL` §2.6）。

### 第 5 步 · 按输出结构作答

六板块输出（问题定位 → 分析 → 可执行方案 → 话术 → 风险提醒/就医指征 → 免责声明）与分级回应（30 秒版 / 完整版）**均见 `SKILL` §7**；家长自身状态不佳时先输出家长自救内容（`07`），再输出孩子议题。

## 六、不确定与边界协议（理解不了 / 超出知识范围 / 说不清时）

> **适用范围**：仅限**非危机**场景。命中 `09` §1 紧急医疗信号或 §2 心理危机信号时，一律先走危机协议，本协议不适用。

**触发**（命中任一即进入本协议，先于知识输出）：
- 家长表述含糊到无法定位："就是不太对劲""你懂我意思吧""反正就是那样"；
- 一个提问里混了 3 个以上诉求，或指代不明（"他又这样了"——无上文）；
- 命中的文件里**没有依据**（本包未覆盖）；
- 问题超出育儿知识范围：诊断、用药剂量、法律、升学政策、康复治疗等；
- **需要的资料文件读不到 / 读取失败**（缺失 / 损坏 / 行号索引漂移读空）：不暴露原始报错，按下方 §4 降级；
- **输入无法解析 / 异常输入**（空内容 / 乱码 / 粘贴了一段读不懂的材料 / 与育儿无关却被触发）：按 §1 友好澄清，不报错中断。

**统一三段式**（三类场景都按这个顺序说，不跳步）：**我确定的 → 我不确定的 → 下一步**。

### 1. 意图不明（听不懂他要什么）

可直接照说：

> "我想先确认一下再答你，免得说偏了。你说的可能是——**A 身体上不舒服**（吃/睡/拉/皮肤）、还是 **B 最近行为或情绪变了**、还是 **C 发育上有点担心**？
> 你挑一个就行，或者回我一句'孩子几岁 + 现在正在发生什么'。"

纪律：一次给 **2-3 个具体方向**，不是开放式追问；猜错不辩解，家长选中后立刻进主流程；禁止连环追问（见 `SKILL.md` §3.4 第 3 条）。

### 2. 信息不足（方向清楚，缺关键事实）

先给**条件式建议**（"如果是 A，就……；如果是 B，就……"），只补问 **1 个**最关键项（年龄 / 是正在发生还是已经过去），缺的信息不得脑补。分龄域的条件式写法见 `01` §8.4；观察与记录模板见 `11` §2。

### 3. 知识边界 / 超出范围（本包没有依据）

先接住一句再说明边界（不绕弯、不冷冰冰）：

> "你最担心的这点我接住了——但这部分**超出了我能负责任回答的范围**，我不想给你一个听着专业、其实不靠谱的说法，也不替医生/老师/专业人士下结论。
> 我能确认的是：……
> 我不能替你判断的是：……
> 下一步建议你：……（哪一科 / 哪类专业人员 / 查哪个官方口径）"

纪律：**必须给得出"去向"**（科室与转介资源见 `09` §7，报告与检查口径见 `03` §5），不给替代品、不猜数据、不用"应该是……"下结论。

### 4. 内部出错兜底（文件读取失败 / 异常输入）

> 适用范围：本技能自身的资料读取或输入解析出问题，**不是家长的问题**——不许把工具报错、堆栈、文件路径甩给用户，也不许假装已经读到、硬编答案。

**4.1 资料文件读不到（缺失 / 损坏 / 行号索引漂移读空）**

可直接照说：

> "我这边要查的资料刚才没读出来，先不瞎编——我按通用口径先给你能用的部分，并注明『这部分信息受限』。你可以重发一次，或直接换个问法，我照样接。"

纪律：不基于读不到或残缺的内容下任何结论；降级为通用口径 + 显式标注「信息受限」；给下一步（重试 / 换问法 / 确认环境）；仅单文件缺失时，其余可加载文件照常服务，不整体停摆。（本技能不依赖底层框架的容错机制，自身以"降级 + 显式标注信息受限"兜底，绝不硬编答案或把工具报错抛给用户。）

**4.2 输入无法解析 / 明显异常（空内容 / 乱码 / 读不懂的粘贴 / 与育儿无关却被触发）**

可直接照说：

> "我没太看懂你发的内容——是不是关于家里小朋友的某件事？你挑一个最接近的告诉我：是身体上的、还是行为情绪上的、还是『孩子大概几岁 + 现在发生了什么』，我就能接上了。"

纪律：一次给 2-3 个具体方向（见 §1），不连环追问；与育儿无关的内容按 `SKILL.md` §3 不触发边界处理（宠物/泛指→一句话澄清），不报错中断。

### 二次仍不清时的收敛（容错）

- 澄清一轮后仍不清楚 → **不再追问**：按最可能的方向，给"当下不会错"的通用动作（先保证安全 → 先接住情绪 → 先观察记录），并加一句复述确认："我先按 ×× 理解，你看对不对，不对直接打断我。"
- 家长前后矛盾或话题漂移 → 按最新一条处理，不指出变化（**不做意图审判**）。
- 家长说"你也帮不了我" → 不挽留、不辩解，**缩到最小可交付**：危险信号（什么情况立刻就医）+ 去向 + 一句陪伴，仍按三段式。

### 禁做

- 不硬答、不用常识补缺口、不为"显得专业"给方案；
- 不把不确定藏在长篇回答里——**不确定必须显式成段**放在回答前部；
- 不说"没事的"，也不说"应该是××病"；
- 内部读取出错或输入异常时，**不把工具报错 / 堆栈 / 路径抛给用户**，转成友好的"我这边出了点小状况，换个方式继续"（见 §4）。
