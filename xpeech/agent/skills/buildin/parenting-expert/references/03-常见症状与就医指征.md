# 03 · 常见症状与就医指征

> **加载时机**：孩子出现具体身体症状（发烧、咳嗽、流涕、呕吐、腹泻、便秘、皮疹、湿疹、腹痛、口腔问题等）、家长问"要不要去医院/要不要挂急诊"、需要解读化验报告单时加载。
> **读法**：**§0 输出规则（每次加载先读，不可跳过）** / §1 症状速查 / §2 就医与急诊指征 / §3 发育与行为异常 / §4 报告解读 / §5 信源时效与免责。
> **配套**：危机与风险分级读 `09`；中医辨证与推拿食疗读 `04`；日常照护操作读 `02`；症状伴随的情绪行为反应读 `05`。
> **口径（必须贯穿每一次输出）**：
> 1. **不诊断、不处方**：只做"症状 → 可能被关联到的几种情况"的说明，**绝不说"就是××病"**；不推荐药品、不给剂量。
> 2. **危险信号优先**：命中 §2 任一急诊指征，先建议就医，再谈其它。
> 3. **中西医并存**：现代医学判断优先，中医作为辅助观察视角；两者冲突处显式标注差异。

## §0 使用前必读：症状类问题的输出规则

1. **先问三个最小信息**（只在确实需要时问）：症状**持续多久**、**体温/程度**、**精神状态与进食排尿**。不要索要详细背景。
2. **回答结构固定**：可能被关联到的情况（2-3 条）→ 家庭可做的照护 → **什么情况下必须就医** → 免责口径；可选加一块「**你可能忽略的**」——1-2 个家长可能没想到的角度（该年龄段的正常发展表现被误当问题 / 常见认知误区 / 结合档案的个性化提醒如过敏史）。
3. **"精神状态"是最高权重指标**：孩子的精神反应（能否玩、能否交流、眼神是否有神）比体温数字更关键。**精神差、嗜睡、难唤醒 → 无论体温多少都应就医**。
4. **月龄权重**：**3 月龄以下婴儿出现发热（肛温 ≥ 38℃）必须立即就医**，不做居家观察。
5. **不给药物与剂量**：涉及退热、止咳、止泻、抗过敏等药物，一律"是否用药、用哪一种、用多少请遵医嘱或按说明书"，本技能不提供具体药品名与剂量。
6. **就医指征量化书写口径**：指征必须含「数值/程度 + 持续时长 + 状态变化」三要素中的至少两项，如"发热 ≥ 39℃ 持续 > 24 小时""腹泻 > 1 周""精神差 + 6 小时无尿"；**禁止**写"严重就去医院""多观察看看"这类无法执行的模糊口径。

## §1 症状速查

### 1.1 发热

**体温参考**：腋温 ≥ 37.3℃ 视为发热；37.3-38℃ 低热，38.1-39℃ 中等热，39.1-41℃ 高热，> 41℃ 超高热。（不同测量部位阈值略有差异，以所用体温计说明为准。）

**可能被关联到的情况**：病毒性上呼吸道感染（最常见）、幼儿急疹、流感、手足口病、疱疹性咽峡炎、细菌感染（肺炎、中耳炎、尿路感染）等。**发热本身是症状，不是疾病，也不是"烧坏脑子"的原因。**

**家庭照护**
1. 补充水分（母乳/配方奶/温水，少量多次）。
2. 穿着适度，不捂汗（捂热可致脱水甚至惊厥）。
3. 体温与精神状态记录（每 4 小时一次，见 `02` §5）。
4. 退热药是否使用、用哪一种、用多少 → **遵医嘱或按说明书**，本技能不推荐药品与剂量。
5. ❌ 不用酒精擦浴、不冰敷、不灌肠退热。

🚨 **立即就医**：3 月龄以下发热；精神差/嗜睡/难唤醒/持续尖叫；抽搐；呼吸急促或费力；皮肤出现出血点或花纹；颈项强直；持续呕吐或明显脱水；发热 > 3 天不退或退后又升；有基础疾病（心脏病、免疫缺陷等）。

### 1.2 咳嗽

**可能被关联到的情况**：上呼吸道感染后咳嗽、急性支气管炎、肺炎、过敏性咳嗽、哮喘、异物吸入、鼻后滴漏。

**家庭照护**
- 保持室内湿润（加湿器/浴室内蒸汽）；少量多次温水；1 岁以上夜间可少量温蜂蜜水（**1 岁内禁蜂蜜**）。
- 抬高床头、清理鼻腔（鼻塞引起的咳嗽常被忽略）。
- 拍背排痰（空心掌自下而上）。
- ❌ 2 岁以下不自行使用止咳药/复方感冒药；❌ 不用成人药减量服用。

🚨 **立即就医**：呼吸急促/费力、鼻翼扇动、肋骨间隙凹陷（三凹征）、口唇发紫；咳嗽伴高热不退；犬吠样咳嗽（警惕喉炎）；咳嗽超过 2 周不缓解；**突然剧烈呛咳后持续咳**（可疑异物吸入）；夜间憋醒或呼吸暂停。

### 1.3 鼻塞、流鼻涕（流涕）

**可能被关联到的情况**：普通感冒、过敏性鼻炎、鼻窦炎（病程长、脓涕、面部不适）。

**家庭照护**：生理性海水喷鼻/滴鼻 → 吸鼻器清理；抬高床头；保持湿度；过敏相关需排查环境过敏原（尘螨、宠物、花粉）。
🚨 **就医**：脓涕伴高热、面部疼痛、病程 > 10 天不缓解；仅单侧持续流脓涕伴异味（可疑异物）。

### 1.4 呕吐

**可能被关联到的情况**：喂养不当/呛奶、急性胃肠炎、肠套叠、幽门狭窄（2-6 周龄喷射性呕吐）、肠梗阻、颅内压增高（喷射性呕吐伴精神差）、食物过敏/中毒。

**家庭照护**：暂时减少每次进食量、少量多次补水；呕吐后不要马上大量进食；记录呕吐次数、性状（奶/食物/胆汁样绿色/咖啡样）、伴随症状。
🚨 **立即就医**：**喷射性呕吐**；呕吐物带血或胆汁样绿色；伴剧烈腹痛/腹部包块；伴精神差、嗜睡、抽搐；伴明显脱水（尿少、哭无泪、口唇干、前囟凹陷、皮肤弹性差）；反复呕吐无法进食。

### 1.5 腹泻

**可能被关联到的情况**：病毒性肠炎（轮状病毒、诺如病毒等）、细菌性肠炎、食物过敏/不耐受、抗生素相关腹泻。

**家庭照护**
1. 核心是**防脱水**：继续喂养（母乳/配方奶不中断），少量多次补充水分与电解质（口服补液盐按说明冲调）。
2. 继续进食易消化食物，不强行禁食。
3. 记录大便次数、性状（水样/黏液/血丝）、尿量。
4. ❌ 不自行使用止泻药；❌ 不自行使用抗生素。
5. 臀部护理：便后清水洗、拍干、涂护臀霜。

🚨 **立即就医**：大便带血或呈果酱样；持续呕吐无法补液；明显脱水表现；高热不退；精神差；腹泻超过 1 周；6 月龄以下婴儿腹泻。

### 1.6 便秘

**可能被关联到的情况**：膳食纤维/水分不足、排便习惯未建立、如厕训练压力、饮食结构突变、器质性问题（长期严重便秘需评估）。

**家庭照护**：增加膳食纤维（蔬果、全谷物）与饮水；增加运动；固定餐后如厕时间（10 分钟，不施压）；不长期依赖开塞露（需遵医嘱）。
🚨 **就医**：新生儿期便秘伴腹胀呕吐；大便带血；长期严重便秘伴腹痛或生长受影响；如厕训练期出现明显疼痛恐惧。

### 1.7 皮疹与皮肤问题

| 类型 | 典型表现 | 可能被关联到 | 处理方向 |
|---|---|---|---|
| 湿疹 | 面颊/肘窝/腘窝红斑、干燥、瘙痒、反复 | 特应性皮炎 | 保湿为主（每天 1-2 次、洗澡后 3 分钟内）、避免过热出汗、剪短指甲防抓；中重度需就医 |
| 热疹 | 颈部/背部/皱褶处密集小红点 | 捂热、出汗 | 降温、透气衣物、保持干爽 |
| 尿布疹 | 臀部/会阴红斑，边界与尿布接触区一致 | 尿布刺激、念珠菌感染 | 勤换、清水洗、拍干、护臀霜；破溃或持续 > 3 天就医 |
| 荨麻疹 | 风团、来去快、剧痒 | 食物/药物/感染/环境过敏 | 记录可疑诱因；伴呼吸困难/口唇肿 → 急诊 |
| 手足口病 | 手足臀疱疹 + 口腔疱疹/溃疡 | 肠道病毒感染 | 居家隔离、清淡饮食、观察重症信号 |
| 水痘 | 向心分布、分批出现的疱疹/结痂 | 水痘-带状疱疹病毒 | 就医评估 |

🚨 **立即就医**：皮疹伴高热与精神差；**压之不褪色的紫红色出血点**（警惕脑膜炎/血液系统问题）；伴呼吸困难、面部/口唇肿胀（过敏性休克，**急诊**）；大面积水疱或皮肤剥脱；皮疹伴黄疸。

### 1.8 腹痛

**可能被关联到的情况**：肠痉挛/胀气、便秘、胃肠炎、肠系膜淋巴结炎、肠套叠、阑尾炎、尿路感染、心理因素（如入学压力可表现为反复腹痛）。

**家庭照护**：观察部位与性质的变化，记录时间与伴随症状；轻度腹胀可顺时针摩腹（**不明原因剧烈腹痛时不揉肚子**）。
🚨 **立即就医**：持续加重或**固定于右下腹**的疼痛；痛到不能站直、蜷缩不动；伴发热、呕吐、血便（果酱样）、腹部包块；阵发性哭闹 + 屈腿 + 面色苍白（婴幼儿肠套叠典型表现）→ **急诊**。

### 1.9 惊厥（抽搐）

**处理（第一现场）**
1. 保持安静，把孩子**侧卧**，移开周围危险物。
2. **不强行按压肢体、不往嘴里塞任何东西**（包括手指、勺子、毛巾）。
3. 松开衣领，记录发作开始与结束的**准确时间**与表现（眼睛、四肢、面色）。
4. 发作后可能嗜睡，保持侧卧观察呼吸。
5. 发作超过 5 分钟、或反复发作、或伴呼吸困难 → **立即拨打急救电话**。
6. 首次发作无论时长 → 就医评估。

**可能被关联到的情况**：热性惊厥、癫痫、低血糖、电解质紊乱、颅内感染、中毒。（不做自行判断，由医生确诊。）

### 1.10 其他高频症状

| 症状 | 关键观察点 | 🚨 就医指征 |
|---|---|---|
| 黄疸（新生儿） | 出现时间、范围（脸→躯干→四肢→手足心）、精神与吃奶 | 出生 24 小时内出现；持续上升；精神差、拒奶、大便发白 → 立即就医 |
| 肠绞痛（婴儿） | 固定时段（傍晚）哭闹、屈腿、排气后缓解，多在 3-4 月龄自行缓解 | 哭闹伴发热、呕吐、血便、体重不增 |
| 湿疹瘙痒夜间加重 | 是否影响睡眠、有无继发感染（渗液、脓痂） | 大面积渗液/感染、影响睡眠与进食 |
| 眼红/分泌物增多 | 单双眼、分泌物性状、是否畏光 | 畏光、剧烈眼痛、视力下降、眼睑高度肿胀 |
| 耳痛/抓耳 | 是否伴发热、流脓 | 婴幼儿不明原因哭闹伴发热 + 抓耳 → 就医（警惕中耳炎） |
| 鹅口疮 | 口腔黏膜白色斑块不易擦去 | 拒食、发热、面积大；免疫低下儿 |
| 打鼾/张口呼吸 | 是否伴呼吸暂停、白天嗜睡 | 打鼾伴呼吸暂停 → 就医 |
| 过敏反应 | 皮疹+消化道+呼吸道三联症状 | 呼吸困难、声音嘶哑、口唇肿、意识改变 → **急诊** |
| 头部外伤 | 是否呕吐、嗜睡、意识改变、耳鼻出血/流液 | 任一出现 → **急诊** |
| 误吞异物 | 吞了什么、多久、有无呛咳/流涎/拒食 | 纽扣电池、磁力珠、尖锐物 → **急诊**；可疑气道异物 → **急诊** |
| 皮肤/指甲/头发异常 | 长期变化、伴随生长发育问题 | 伴生长迟缓、发育问题 |

> 【中医·辅助】常见辨证提示（仅作观察视角，不用于自行用药）：发热无汗属"风寒"、高热口渴属"风热"、腹泻水样属"湿热/脾虚"、咳嗽痰黄属"痰热"、夜卧不安汗多属"心经积热/阴虚"。小儿推拿（清天河水、退六腑等）只在**轻症辅助**范围使用，出现本节红灯指征**一律以就医为先**。手法与禁忌详见 `04`。

## §2 就医与急诊指征

### 2.1 急诊（立即就医，不观察、不等待、不先做知识讲解）

| 类别 | 表现 |
|---|---|
| 呼吸 | 呼吸急促或费力、三凹征、口唇/面色发紫、喘息不能说话、呼吸暂停 > 10 秒 |
| 意识 | 嗜睡难唤醒、意识不清、抽搐、持续尖叫不能安抚、颈项强直 |
| 循环/皮肤 | 皮肤花斑、发灰、压之不褪色的出血点、四肢冰冷、手脚发凉伴精神差 |
| 脱水 | 尿量明显减少（6 小时无尿）、哭无泪、口唇干燥、前囟凹陷、皮肤弹性差 |
| 发热 | 3 月龄以下发热；发热伴出血点、抽搐、精神极差 |
| 腹部 | 固定右下腹或持续加重的腹痛、腹肌紧张、果酱样便、腹部包块 |
| 外伤/意外 | 头部外伤后呕吐或嗜睡、烫伤起疱或面积大、溺水、误吞纽扣电池/磁力珠/尖锐物、可疑气道异物 |
| 过敏 | 呼吸困难、声音嘶哑、口唇或眼睑肿胀、意识改变 |
| 其他 | 喷射性呕吐、便血、惊厥首次发作、无明显原因的剧烈疼痛 |

### 2.2 尽快就医（24 小时内）

- 发热超过 3 天不退，或退热后精神仍差。
- 精神差、食欲明显下降、尿量减少但尚未达急诊标准。
- 咳嗽超过 2 周、反复喘息、夜间憋醒。
- 呕吐/腹泻伴轻中度脱水表现，居家补液效果不好。
- 皮疹持续加重或伴发热；尿布疹破溃 3 天以上未愈。
- 反复发作的腹痛、耳痛、头痛。
- 生长发育指标连续 2 次偏离正常范围、发育能力倒退（见 §3）。

### 2.3 可先居家观察（同时给出明确的"何时升级"标准）

- 精神好、能吃能玩、尿量正常的低热或普通感冒症状。
- 接种后 48 小时内的低热与局部红肿。
- 轻度热疹、轻度尿布疹、轻度便秘、出牙期不适。

> **观察不等于放任**：任何情况下都要明确告知家长"出现以下情况就来医院"，并给出具体条目（精神、呼吸、尿量、症状持续时间），不能只说"观察一下"。

### 2.4 就医前的准备（提高就诊效率）

1. 带齐记录：体温曲线、症状时间线、用药记录、过敏史（`02` §5）。
2. 带上保健手册/接种证与既往检查报告。
3. 提前想好 3 个问题：最需要判断的是什么、需要做什么检查、回家后要注意什么。
4. 不要因担心而给孩子提前用退热药掩盖症状（除非医生指导），以免影响判断。

## §3 发育与行为异常

> 原则：**先区分"偏离正常范围"与"个体差异"**；本节只提供"需要专业评估"的判断线索，不做诊断。里程碑的正常范围见 `01` §7.1。

### 3.1 语言发育迟缓

**线索**：12 月龄无意识发音/无手势（指、摇头）；18 月龄不会叫爸妈、词汇 < 10 个；24 月龄词汇 < 50 个或不会组词；3 岁不能组句、陌生人听不懂其表达；**任何年龄段出现语言能力倒退**。
**要做什么**：查听力（最常见可治原因）→ 儿科/儿童保健科发育评估 → 必要时转语言治疗/康复。
**同时排查**：听力问题、自闭谱系、家庭语言环境单一/多语混用（多语环境可能稍晚，但"完全无语言/倒退"仍属红旗）、缺少互动。

### 3.2 自闭谱系早期征象（社交沟通红旗）

- 不看人眼睛/不追视人脸；不指物分享兴趣；不应名；不模仿；
- 语言落后或只会"背台词"式语言；
- 重复刻板动作（转圈、甩手、排成一排）；对特定物品异常执着；
- 感官异常（对声音/触觉过度敏感或迟钝）；
- **能力倒退**（曾经会的话/社交行为消失）。

**要做什么**：**不等待观察**。尽早到儿童保健科/发育行为儿科做专业评估（早期干预越早效果越好）。家长可先用权威筛查量表配合（`11` §3）。

### 3.3 注意力与多动问题（ADHD 相关线索）

**线索**（需在**家庭与学校两个场景**都出现、持续 ≥ 6 个月、影响学习与社交）：难以维持注意、易分心、丢东西、坐不住、插话打断、难以等待、做事冲动。**< 4 岁一般不作诊断**（此年龄好动多属正常发展差异，以观察与行为引导为主）；症状须在 12 岁前出现。
**要做什么**：先排除睡眠不足、听力/视力问题、贫血、情绪压力（霸凌、家庭冲突）；再就诊儿童保健/精神心理科做专业评估。**不做自行贴标签**，也不因"成绩不好"就下结论。

### 3.4 抽动

**线索**：眨眼、清嗓子、耸肩、甩头等不自主、快速、重复的动作或发声，紧张时加重、专注时减轻，可波动迁延。
**要做什么**：**不提醒、不批评、不刻意制止**（越关注越加重）；多数为短暂性抽动可自行缓解；持续 > 1 年或影响生活 → 神经科就诊评估。

### 3.5 遗尿与遗粪

**路径**：先排查便秘（遗粪与部分遗尿的常见诱因）、尿路感染、睡眠过深、心理压力；5 岁后仍每周多次尿床 → 儿科就诊评估，不责备、不羞辱。

### 3.6 屏气发作（婴幼儿）

**表现**：哭闹中突然屏气、面色发紫或发白、短暂意识丧失、肢体僵硬或松软，多发生在 6 月-3 岁。
**处理**：保持侧卧、不要摇晃与泼水、记录时长与表现；**首次发作就医评估**（排除癫痫等），日常避免过度冲突与惊吓。

### 3.7 情绪行为问题与躯体化

- 躯体症状（反复腹痛、头痛、恶心）在检查无异常后，需同时关注心理压力源：入学/入园适应、霸凌、家庭冲突、学业压力、丧失事件。
- 提示信号：症状多在特定情境（上学前）出现、周末缓解；伴随情绪低落、退缩、睡眠变化。
- **处理路径**：认真对待每一次主诉（不否定、不说"装病"）→ 记录"前因—症状—结果"（`02` §5）→ 与学校沟通 → 心理评估（`08` §3）。
- 🚨 出现自伤、自杀意念、疑似虐待、家暴 → 立即转入危机协议（`09` §2）。

### 3.8 发育倒退（最高优先级红旗）

**已获得的能力丧失**（说话、走路、社交、如厕等任一倒退），无论发生在哪个年龄段 → **尽快就医评估，不要观察等待**。常见排查方向：神经系统问题、代谢/内分泌问题、听力/视力问题、癫痫、心理社会因素（需专业评估）。

### 3.9 学习障碍（阅读 / 书写 / 计算的持续困难）

**线索**（智力与努力正常，但某一项**持续 ≥ 6 个月**明显吃力，且家庭与学校两个场景一致）：认字读字慢、读得磕巴且读了不理解；写字镜像、漏笔画、抄写极慢；数感与计算明显跟不上；拼读困难；"会做但写不完"。**先排除**视力/听力问题、睡眠不足、情绪压力与教学环境问题。
**与 ADHD 的区别**：学习障碍是**特定能力**的困难，ADHD 是**注意与自控**的困难，两者可以并存；不要用"笨""懒""不认真"解释。
**要做什么**：① 与老师核对跨场景表现（`06` §5.2）；② 到儿童保健科/发育行为儿科或儿童心理科做专业评估；③ 有结论后再谈个别化支持（座位、作业量、辅助工具）与家庭辅导方式（`11` §6.6）。
**不要做**：❌ 罚抄、❌ 当众比较、❌ 用"你不够努力"解释一切、❌ 自行买"专注力训练"课程替代评估。
⚠️ **越早越好**：反复的失败体验会带来低自尊与拒学（`08` §3.4）；评估一次不是终点，支持是长期的。

### 3.10 性早熟（发育偏早的识别与就医）

**线索**：女孩 **8 岁前**乳房发育、**10 岁前**月经初潮；男孩 **9 岁前**睾丸增大、变声或长胡须；两类共同的早期信号是**身高突增早于同龄**、体味与痤疮提前出现。
**要做什么**：① 记录"第一次发现的时间 + 变化速度"（每 3 个月记录一次或拍照留存），这是医生最需要的信息；② 直接到**儿童内分泌科**评估——骨龄、激素与影像判断由专科完成（见 §4.3、§4.4），**不做自行判断**。
**不要做**：❌ 不因"发育早"就给孩子节食或少吃；❌ 不用偏方、保健品、"调理"类产品干预（`04` §1.4）；❌ 不指责孩子，不让他因此羞耻（`08` §7）。
⚠️ **口径**：多数早期线索属正常变异，也可能与营养状态、家族发育时间相关——**"发现早"不等于"有问题"，但"评估早"必须做到**；最终判断只能由专科医生给出。

### 3.11 身高偏矮与生长监测

**先看三件事**：① 生长曲线上的**位置**（是否一直沿同一条百分位线走）；② **年增长速度**（2 岁以上 < 5 cm/年需关注，见 `02` §4.2）；③ **父母身高与青春期启动时间**（家族性矮小与"晚长"是常见原因）。
**要做什么**：把至少 3-6 次身高测量（间隔 ≥ 3 个月、同一时间、同一量具）记入生长曲线（`11` §1.5）→ 儿保科/儿童内分泌科评估；骨龄与激素检查由专科判断（见 §4.3）。
**不要做**：❌ 自行购买"增高"保健品、贴剂，或自行使用所谓"生长激素"（`04` §1.4）；❌ 在孩子面前反复讨论"太矮了"（身高焦虑会内化）；❌ 用"多喝骨头汤"替代评估。
**🚨 建议尽快评估**：身高持续 < P3、年增长速度 < 5 cm、明显低于父母遗传预期、伴能力倒退或多饮多尿/头痛（§3.8、§4.3）。

## §4 报告解读

> **原则**：报告解读只做"这些指标通常用于看什么"的说明，**不做诊断**；参考范围以报告单标注为准（不同医院、不同方法学不同）；异常值必须由医生结合症状判断。**临界值措辞纪律**：处于参考范围边缘的指标**不标"异常"**，标"处于正常值上/下限，建议关注"——临界 ≠ 异常，夸大表述会制造不必要的焦虑。

### 4.1 血常规

| 指标 | 通常用于看什么 | 常见理解误区 |
|---|---|---|
| 白细胞（WBC） | 感染与否的参考（升高多见于细菌感染，降低可见于病毒感染） | 单看白细胞不能区分病毒/细菌；应激、剧烈运动也可升高 |
| 中性粒细胞 | 细菌感染倾向 | 婴幼儿中性粒与淋巴比例本就与成人不同，须用年龄对应参考范围 |
| 淋巴细胞 | 病毒感染倾向、某些传染病的评估 | 同上，年龄相关 |
| 血红蛋白（HGB） | 贫血判断 | 6 月龄后血红蛋白偏低常提示缺铁性贫血（需结合铁代谢指标） |
| 血小板（PLT） | 出血与凝血相关问题的参考 | 感染期可一过性波动，需复查趋势 |
| CRP | 炎症反应程度的辅助指标 | 与白细胞配合看，单看一次数值意义有限 |

### 4.2 大便与尿常规

- **大便常规**：白细胞/红细胞提示肠道炎症或出血，轮状病毒/诺如病毒抗原用于病原筛查，隐血试验用于消化道出血筛查。
- **尿常规**：白细胞/亚硝酸盐提示尿路感染（婴幼儿发热原因排查的重要项目）；蛋白、红细胞提示肾脏相关问题（需复查与进一步检查）。

### 4.3 其他常见检查

| 检查 | 用途 | 重要提醒 |
|---|---|---|
| 支原体/病毒抗体 | 病原感染判断 | 抗体阳性不等于现症感染，需结合 IgM/IgG 与临床 |
| 胸片 | 肺部感染、异物评估 | 由医生结合症状判断，仅凭报告不下结论 |
| 腹部超声 | 肠套叠、阑尾炎、泌尿系统评估 | 急腹症首选影像之一 |
| 过敏原检测 | 过敏风险的**线索** | **阳性不等于过敏**（需结合实际接触后的反应）；阴性也不能完全排除 |
| 骨密度 | —— | **儿童不推荐常规检测**评估"缺钙" |
| 微量元素检测 | —— | 不作为儿童常规筛查项目；是否检测与解读听医生 |
| 肝功能/肾功能 | 脏器功能评估 | 需结合年龄参考范围与临床表现 |
| 骨龄片 | 生长迟缓/性早熟评估 | 由专科医生判读，指导后续方案 |

### 4.4 生长曲线与百分位

- P3-P97 之间属常见范围；判断重点在**曲线的趋势**（突然变平/下降比一直偏小更值得关注）。
- 早产儿按**矫正月龄**评估（`01` §8.3）。
- 详细绘制方法与记录模板见 `02` §4、`11` §2。

### 4.5 与医生沟通的五个问题

1. 这个检查结果最可能说明什么，还需要什么检查才能确认？
2. 是否需要用药？用多久？出现哪些副作用需要停药？
3. 回家后观察什么指标？什么情况下要提前复诊？
4. 生活和饮食上需要注意什么？
5. 下次复查在什么时候？

## §5 信源时效与免责

### 5.1 信息分级与使用规则

| 等级 | 来源形态 | 使用方式 |
|---|---|---|
| S | 国家卫健委/疾控/世卫组织等官方规范与指南 | 直接采信 |
| A | 权威医疗机构、专业学会的共识/指南 | 直接采信，标注出处 |
| B | 专业医疗机构科普、教科书、循证专著 | 可用，需与 A 级交叉验证 |
| C | 自媒体、个人经验分享 | **仅作参考，不作为判断依据** |
| D | 无出处、夸大疗效、推销导向内容 | 不采用 |

**最低要求**：任何健康类结论至少 **2 个独立权威来源**交叉验证；无法验证时明确说明"无法确认"，而不是含糊带过。

### 5.2 数据时效规则

| 数据类型 | 时效要求 |
|---|---|
| 急性症状 | 当日状态为准（24 小时内），过期数据需重新确认 |
| 用药史 | 本次病程内有效，跨病程需重新确认 |
| 过敏史 | 需确认是否更新（新出现的过敏反应须重新评估） |
| 疫苗与体检记录 | 按接种证/保健手册最新记录 |
| 生长发育数据 | 超过 1 个月（婴幼儿为 2 周）需重新测量再判断 |
| 政策/福利/补贴类 | 一律以当地**最新官方发布**为准，引用需标注检索时间 |
