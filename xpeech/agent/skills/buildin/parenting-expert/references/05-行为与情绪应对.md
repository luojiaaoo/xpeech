# 05 · 行为与情绪应对

> **加载时机**：家长描述孩子的**行为或情绪问题**时加载——哭闹发脾气、打人咬人、黏人分离焦虑、对抗顶嘴、撒谎否认、怕黑焦虑、手足争抢、不自信、"我不行"、输不起、高敏感、吼完孩子怎么补、怀疑行为异常。
> **读法**：只读命中章节——§1（通用框架）/ §2（情绪与发脾气）/ §3（说谎与说真话）/ §4（恐惧焦虑与分离）/ §5（无礼对抗与设边界）/ §6（手足冲突）/ §7（羞耻感与自我价值）/ §8（挫折耐受与韧性）/ §9（高敏感孩子）/ §10（修复关系）/ §11（情绪小生物）/ §12（反模式清单）/ §13（行为异常筛查）/ §14（重复性习惯行为）。**§1 与 §12 是通用底座**，任何章节输出前先对照。
> **配套**：**具体该说什么话** → `06`（话术库，含 27 个高频场景脚本）；**是否属于症状/需要就医** → `03`；**家长自己的情绪与原生家庭议题** → `07`；**神经多样性、心理疾病、霸凌、离异等特殊议题** → `08`；**危机信号（自伤、虐待）** → `09` §2；**行为记录表与情绪追踪工具** → `11` §4。
> **口径**：以发展心理学与儿童行为科学为主线；所有方法的前提是**行为是需求的窗口，不是要被消灭的对象**。**30 秒判断要不要开本文件**：问题关于"孩子/家长的行为或情绪怎么应对" → 是；是具体疾病/用药 → 开 `03`；是要"具体说哪句话" → 开 `06`；是危机信号（自伤/家暴/虐待） → 直接 `09` §2。

## 使用须知（四条硬规则）

1. **先安全，后情绪**：涉及人身安全（打人、咬人、自伤、危险动作）时，先物理制止与保护，再处理情绪；不讲道理、不谈判。
2. **先调家长，后调孩子**：家长处于失控边缘时，先输出家长自救内容（`07` §2、`06` §6），本轮不给孩子议题方案。
3. **给方法必须给话术**：任何"怎么做"都要附上"可以怎么说"（具体句子），否则家长无法执行。
4. **不做诊断**：可以描述"这可能是…的正常表现/这需要评估"，但不得给出"多动症""感统失调""高敏感人格"等结论性判断；判断类内容一律走 §13 分流。

## §1 通用框架

### 1.1 四步底层流程（所有行为问题通用）

```
第 1 步 · 稳住自己（3 秒）
   → 家长先降唤醒：深呼吸、放低音量、蹲下来。孩子的大脑会"借用"家长的状态。

第 2 步 · 命名情绪与愿望（先接住，再谈事）
   → "你很生气，因为你特别想要那个东西。"（承认愿望，不等于同意行为）

第 3 步 · 设边界并身体力行（简短、事先、一致）
   → "我不会允许你打人。"（只说自己会做什么，不命令孩子"必须"怎样）

第 4 步 · 事后修复与重建（平静后 30 分钟—24 小时内）
   → 四步修复见 §10；不当场翻旧账，不在风暴中讲道理。
```

### 1.2 三条核心原则

1. **连接先于纠正**：孩子的"不配合"多是关系与状态问题（饿、困、累、压力、想被看见），而不是"品德问题"。先连接，纠正才有效。
2. **行为 ≠ 人品**（善意养育/最善意解释）：把"他做了坏事"和"他是坏孩子"分开；在解释动机时优先选最善意的那个假设——"他不是在整我，他是在求助"。
3. **关系长于方法**：方法会失败，关系是容器。允许自己用错方法，但不允许关系破裂后不修复（§10）。

### 1.3 年龄适配：先看"大脑有没有这个能力"

| 年龄 | 能力现状（判断基线） | 对应策略 |
|---|---|---|
| 0-1 岁 | 无自控能力，哭是唯一语言 | 及时回应；不做行为训练 |
| 1-3 岁 | 前额叶极不成熟（3 岁孩子**没有能力控制情绪**） | 共情 + 物理转移 + 有限选择；不讲大道理 |
| 3-6 岁 | 语言快速发展，能理解规则但执行弱 | 游戏化、仪式化、提前预告；事后简短复盘 |
| 7-12 岁 | 能理解因果关系，开始在意同伴与评价 | 参与制定规则、给选择与后果、强调过程 |
| 10-12 岁 | 自主需求上升，怕"丢人" | 尊重隐私与面子；私下沟通，不在同学面前亲密 |
| 13-18 岁 | 情绪强度高，需要被当成独立个体 | "不接球"（不反击不辩解）、平等语言、可选求助 |

## §2 情绪与发脾气

### 2.1 识别（Recognize）：这是"情绪风暴"还是"有目的的要挟"

| 特征 | 情绪风暴（失调） | 有目的的行为 |
|---|---|---|
| 触发 | 常因小事突然爆发，如饼干断了 | 指向具体目标（要买玩具） |
| 过程 | 听不进话、身体失控、可能砸打自己 | 边哭边观察大人反应，可能"哭停交替" |
| 结束 | 需要时间与陪伴才平复 | 达到目的即停 |
| 应对 | **陪伴 + 安全 + 少说话** | **边界 + 一致性 + 替代方式** |

> 关键提醒：**两种情况的处理都不能用"讲道理"开场**。失调时孩子听不见道理；有目的时讲道理等于给"谈判"加戏。

### 2.2 解读（Interpret）：发脾气在说什么

- "我能力不够"：想做的事做不到（搭高塔倒了）；
- "我不会表达"：语言能力追不上情绪强度（1-3 岁最常见）；
- "我太累了/饿了/刺激过度了"：生理性失调；
- "我需要被看见"：一天都在分享别人，没有一分钟是他的；
- "我要确认边界在哪里"：孩子通过反抗试探"你会不会崩"。

### 2.3 行动（Engage）：控制火势四步

1. **保安全**：把他带离危险区（拿走危险物、抱离现场），不必马上"讲清楚"。
2. **设住边界**：只对行为设限——"我不会允许你打人/砸东西"，可以抱住保护，但不羞辱、不打、不扔下他走。
3. **陪坐不讲理**：在旁边安静陪着，简短复读共情——"我知道你很难受，我在这里。"（陪伴本身就是调节；不要在这时教育、分析、提要求）
4. **事后修复**：情绪过去 30 分钟后，按 §10 修复；若涉及他人，一起完成"怎么办"的小行动（擦干净、吹吹、说一句）。

### 2.4 边界（Boundary）：不能让步与可以变通

| 不可让步 | 可以变通 |
|---|---|
| 人身安全（打人、咬人、爬窗、玩水玩电） | 物品的替代方案（"这个不买，可以选那个"） |
| 已说好的规则（说一样就一样、9 点关灯） | 时间的小幅弹性（"再玩 5 分钟"） |
| 尊重他人（不辱骂、不伤害） | 表达方式（可以哭、可以跺脚、可以画画） |

### 2.5 家长话术模板（细节脚本见 `14` §3）

- 共情：**"我知道你特别想要它，想得都难过了。"**
- 情绪体量：**"你特别想吃冰激凌，你的这个愿望就跟这个房子一样大！"**（把愿望的大小说出来，被理解的愿望本身就能降一档强度）
- 设边界：**"我不会允许你打人。你可以生气，但不可以伤害别人。"**
- 陪伴：**"你可以哭一会儿，我在这里陪你。等你准备好了，我们就走。"**
- 替代：**"生气的时候可以跺跺脚，或者来告诉我。你试试说'这是我的，不要拿！'"**

### 2.6 常见失败模式

❌ 在风暴中讲道理、逼道歉、要孩子"自己控制"；❌ 用"冷处理/隔离"把孩子推开（用隔离当惩罚会加剧失调）；❌ 因当众尴尬而妥协或发狠；❌ 事后翻旧账、贴标签（"你就是脾气大"）。

## §3 说谎与说真话

### 3.1 识别：三种"说谎"，性质完全不同

| 类型 | 例子 | 性质 | 应对方向 |
|---|---|---|---|
| **幻想型**（3-6 岁常见） | "我的恐龙会飞" | 想象力发展，不是撒谎 | 陪他一起想象，不纠正 |
| **否认/逃避型** | "不是我打翻的""我没拿" | 怕惩罚、怕羞耻 | 减少审问，降低承认的成本 |
| **隐瞒/保护型** | 隐瞒成绩、隐瞒交友 | 怕失望、怕失去信任空间 | 修复沟通通道，明确安全例外 |

### 3.2 解读：把谎言当成愿望

核心理解：**孩子撒谎不是为了骗你，而是为了避开他承受不住的东西（惩罚、羞耻、失控）。** 越逼供，越练出更高级的谎言；越让他"承认=被理解"，越容易说真话。

### 3.3 行动：四步（针对否认型）

1. **降羞耻，不审问**：不给"是不是你干的"这种只有两个答案的陷阱题。改为描述事实——"我注意到杯子倒了，地上都是水。"
2. **给承认的安全通道**："如果是不小心打翻的，没关系，我们一起擦干净。"
3. **表扬诚实本身**："谢谢你告诉我真的是你碰倒的，你很勇敢。"（把"说实话"变成一个被奖励的行为）
4. **一起解决**："我们想想下次怎么小心一点？"
5. **缓冲句 + 稍后再谈**（死不承认时）：先给一句"我不确定到底是怎么回事。我确定的是，我爱你，你是个好孩子。"——把做错事与被爱脱钩；等羞耻感降下来后再回到事实："假如那种事真的发生了，我们可以一起想办法。"（目标不是当下认错，是将来敢说真话）

### 3.4 边界与安全例外（必须讲清楚）

- **安全例外要明确告知**：**"凡是涉及安全的事（有人要伤害你、有人碰你的身体、有人让你保密），你不需要替我保密，也不需要替任何人保密，一定要告诉我。"**（此类情况参见 `08` §4、`09` §2）
- **不承诺"你说实话我就不生气"再反手惩罚**——一次背刺，通道关闭数年；如果确实要处理后果，先说清楚"我会难过，但不会因此不再爱你，我们一起处理这件事"。
- **家长自己说真话**：不骗孩子去医院、不骗孩子"妈妈不走"（做不到就不说）、不要求孩子撒谎圆场（如"别告诉爸爸"）。**孩子学的是你的行为，不是你的说辞。**

### 3.5 常见失败模式

❌ 逼供式连环问（"是不是你？""还说不是你？"）；❌ 贴标签（"你撒谎精"）；❌ 罚到承认（恐惧驱动，只为逃罚不说真话）；❌ 因诚实而加惩罚。

### 3.6 假装 / 装病：与说谎、躯体化怎么分

家长最常问"他是不是装病"。先分三层，再决定怎么处理：

| 层次 | 判断依据 | 归到哪里 |
|---|---|---|
| **功能性假装**（为获得关注、逃避某件事） | 症状**随场合变化**：要上学时腹痛，周末完全没事；能被喜欢的事打断 | 本节处理（见下） |
| **躯体化**（情绪变成身体难受） | **他真的难受**，部位游走、检查无异常，且与压力时间线吻合 | `03` §3.7（不当"装病"处理） |
| **说谎 / 隐瞒**（有事实性真假） | 存在一个可核对的事实，且他有隐瞒动机 | §3.1 三种"说谎" |

**怎么处理功能性假装**：
1. **不拆穿、不说"你在装"**——拆穿只让他升级到更严重的症状；
2. **看功能，不看真假**：问"今天学校有什么让你不太想去？"，而不是"你到底痛不痛"；
3. **给正当的退路**：把"逃避"变成可以明说的请求（"不想去可以说，我们一起看是什么让你难受"）；
4. **保留必要的回应**：不因为"可能是装的"就放弃关心——真的难受被当成装的，是最伤的一次。

**判断线**：影响上学/社交、持续 > 2 周、或伴体重下降/睡眠改变 → 按 `03` §3 做评估，不在此处纠结真假。

## §4 恐惧、焦虑与分离

### 4.1 识别：正常恐惧的年龄表

| 年龄 | 常见恐惧对象 | 说明 |
|---|---|---|
| 0-1 岁 | 陌生人、巨响、突然的移动 | 陌生人焦虑是认知里程碑（`01` §1） |
| 2-4 岁 | 黑暗、怪物、狗、面具、马桶/下水道 | 想象力萌芽 + 无法区分想象与现实 |
| 5-7 岁 | 幽灵、小偷、打针、独自入睡、上学 | 关注"安全与伤害" |
| 7-12 岁 | 考试失败、同伴评价、灾难新闻 | 转向社会性评价 |
| 13-18 岁 | 社交评价、未来、身材、被排斥 | 需要尊重与平等语言 |

> 判据：**恐惧是否影响功能**（不上学、不吃不睡、持续 >4 周、伴随身体症状）＋ **是否泛化**（怕的东西越来越多）。两者都满足 → 走 §13 分流（`08` §3 / `03` §3）。

### 4.2 解读："跳进洞里"原则

怕黑的孩子不是"胆小"，是**真的处在恐惧里**。家长站在洞口喊"这有什么好怕的""快点出来"只会让他更孤单。**正确做法是跳进洞里陪他待一会儿，再一起出来。**

### 4.3 行动：四步

1. **肯定恐惧**："你会怕，是真的怕。怕不是丢人的事。"
2. **不辩论、不讲道理**：不对"怪物不存在"做逻辑证明（会触发更强的防御与自我怀疑）；改为**提供安全感的动作**——"我们一起看看床下，然后我把门留一条缝。"
3. **给过渡客体与仪式**：小夜灯、玩偶、固定告别仪式、固定短句（"妈妈一定会回来，每次都会"）。
4. **安全距离法（渐进暴露）**：把"怕的东西"按距离排梯度，从最安全的距离开始一点点靠近——如怕狗：远远看 → 隔着栏杆看 → 在家长怀里靠近 → 摸一下。**每一步都由孩子决定前进还是停下，绝不推入。**

### 4.4 分场景要点

| 场景 | 关键动作 |
|---|---|
| 怕黑/怕怪物 | 夜灯 + 检查仪式 + 不在黑暗里讲恐怖故事；白天玩"打怪游戏"以掌控感对抗无助感 |
| 噩梦/夜惊 | 噩梦：安抚 + 白天用画画重写结局；**夜惊（尖叫、不看人、次日无记忆）不要叫醒**，保护安全，等其自行结束（就医指征 `03` §1） |
| 分离焦虑/入园哭 | 固定的告别仪式 + 具体可理解的回来时间 + 交给老师后果断离开（不反复回头）；详见 `14` §5「入园与学校」 |
| 不敢独睡 | 分阶段：同房不同床 → 床边坐 → 门口 → 门外；每次退一步都先商量好 |
| 就医/打针恐惧 | 提前告知 + 诚实承认会疼 + 给可控选择（打哪只手）+ 事后不否定哭泣（`14` 对应情景节） |
| 考试焦虑 | 正常化 + 呼吸落定 + 降低结果重要性（`14` 对应情景节） |

### 4.5 边界

- 可以接纳情绪，**不接纳因恐惧产生的攻击与破坏**（"你怕可以，但不能打妹妹"）；
- **家长不做"壮胆式"训练**（把哭着的孩子硬塞给别人抱、把他独自关在黑屋子上"练胆子"）；
- 强迫暴露、羞辱（"男子汉哭什么"）会加固恐惧并损害信任。

### 4.6 长期分离后的重聚（先修复，后管教）

> 适用：父母出差/异地、孩子住院、送回老家、隔离等**连续分离 ≥1 周**后的重逢。重聚不是"接着过日子"，而是关系需要重新接线的一段时间。

**三条原则**

1. **头 1-3 天只做连接**：不设新规矩、不纠正旧习惯（吃饭慢、要抱睡都先接受）；规矩在连接恢复后再谈。
2. **预期"排斥期"**：孩子可能不理你、只找原照顾者、夜里更黏或更抗拒——这是依恋的**正常反应**（他在确认"你还会不会走"），既不是"不爱你了"，也不是"被带坏了"。
3. **不用礼物开路**：礼物等于用物质填补空缺，反而延后真实连接；带一件"一起做的小事"比带玩具管用。

**重聚 72 小时脚本**

| 时段 | 只做这件事 | 不做 |
|---|---|---|
| 见面当下 | 抱、在场、说"我回来了"；他推你就等在旁边 | 不当众问"想不想我"、不追问"有没有想妈妈" |
| 第 1 天 | 陪他做他熟悉的那件事（同一本书、同一个游戏） | 不纠正行为、不发脾气、不谈规矩 |
| 第 2 天 | 恢复固定日常（洗澡、睡前流程）由你来负责 | 不急着把养育权全部拿回 |
| 第 3 天起 | 规矩照旧恢复，按家庭原有节奏来 | 不"补偿式溺爱"（前松后紧比一直松更伤） |

**分龄差异**：0-3 岁几乎只能靠"身体在场 + 固定流程"恢复，讲道理无效；3-6 岁会问"你为什么要走"，回答要诚实、简短、不承诺做不到的事（"妈妈要去上班，去 X 天，回来就陪你"）；7-12 岁可能用冷淡或生气表达失落，允许他表达，不要求他立刻热情。

**不要做**：❌ 追问"你是不是不想妈妈了"；❌ 用"你再这样我下次不回来了"（把分离当惩罚工具）；❌ 见面第一件事就纠习惯；❌ 以为"多买点东西就补回来了"。

> **判断线**：重聚后 2-4 周仍持续回避、睡眠进食明显受影响、已会的能力退行 → 按 `09` §3 判档，必要时走 `03` §3 发育评估、`05` §13 行为评估（本文件本节只做关系修复，不做判断）。

## §5 无礼对抗与设边界

### 5.1 识别：对抗的本质是三种需求之一

- **自主需求**（"我说了算"）：2-4 岁与青春期两个高峰；
- **关系需求**（"你注意到我了吗"）：家长越忙越闹；
- **边界需求**（"你到底有没有底线"）：孩子通过越界来确认大人的稳定。

### 5.2 解读与职责划分

**家长只对自己的行为负责**：不说"你必须尊重我"，只说"我不会允许你用这种语气跟我说话"；不说"你必须马上写作业"，只说"我会在 8 点收走平板，作业由你决定什么时候写"。

### 5.3 行动：先拉近关系，再提要求（顺序不能反）

1. **先连接**（10-30 秒）：走进他的世界——"你看的这个挺有意思的。还有多久看完？"
2. **再提要求**（简短、一次、有具体时间点）："好，10 分钟后开始写作业，我帮你设闹钟，到时间你自己关。"
3. **给选择权**（选项都由你接受）："现在开始，写完还能看 15 分钟；或者再等一下，但今天的屏幕时间就用完了。你选。"
4. **执行后果而不加戏**：时间到就执行，不嘲讽、不吼叫、不追加惩罚——"时间到了，遥控器先放这里。"
5. **事后讲经历不讲道理**（冲突后 30 分钟）：把"我的感受"说出来，而不是给结论——"刚才我对你大声说话了，我不该那样。"见 §10。

### 5.4 设边界的正确句式

| ❌ 无效/有害 | ✅ 有效 |
|---|---|
| "你必须…""你不许…" | "我不会允许你…"（只陈述自己的行动） |
| "去写作业！" | "我们约好 8 点开始写。" |
| "你怎么又这样！"（翻旧账） | "现在的情况是…"（只谈当下这一件） |
| "再哭我就不带你出来了"（威胁） | "你可以哭，我在这里陪你；哭完我们就走。" |
| "你怎么这么没礼貌！"（标签） | "刚才那句话会让人难受。你可以说'我现在不想说'。" |
| "说对不起！"（逼道歉） | 先修复关系，再让孩子决定要不要道歉（`14` 对应情景节） |

### 5.5 青春期专项（13-18 岁）

- **"不接球"**：孩子说"你不理解我""你好烦"时，不反击、不辩解——"嗯，也许我确实不太理解，你愿意说说看吗？"（他期待对抗，你不接，冲突就降级）
- **摔门后的处理**：不追进去；30-60 分钟后送水到门口——"水放这儿，你想聊我在客厅。"
- **可选时机再谈**："昨天你说我不理解你，我想了想，有些地方我可能确实做得不好。你能告诉我是什么事吗？"

### 5.6 严重冲突的完整处理示例（家长可照抄）

**场景**：14 岁儿子摔门、骂了句难听的话、作业一字未动，你在客厅气得发抖。

**① 30 秒版（当场，先接住自己）**
> "我现在也很火大，我们先都去喘口气。这事晚点说，但不是不算。"

**② 2 分钟版（等双方降温后，按四步框架）**
1. **先降火不追凶**：不在这时翻旧账、不逼道歉，先让生理激动退潮（见 §1、§2）。
2. **给一句连接的话（照说）**："我刚才也吼了，对不起。但我不是因为讨厌你，是因为又急又不知道怎么帮你。"
3. **把要求改成可执行的下一步（照说）**："今晚先别想写完，咱们就定一件事——你先把手机放下、去洗个澡，剩下的明早一起排。"
4. **设边界（照说）**："摔门、骂人这两件事咱们得另找时间定规矩，但现在先保你我能好好说话。"

**③ 事后修复（第二天，低压力时机）**
> "昨天那事我想了想，我也有不对的地方。咱们定个君子协定：以后谁先上头，就比个暂停手势，各自去冷静 10 分钟再谈——你愿意试吗？"

**边界**：他砸东西、动手、说"不想活了" → 立刻停本流程，走 `09` §2 危机协议，不按本示例处理。
- **底线不动**：安全、尊重、法律相关的底线坚持；作息、穿搭、发型等生活偏好可协商。

### 5.6 常见失败模式

❌ 用"陪伴式威胁"（我走了/我不要你了）；❌ 用条件式爱（"你再这样我就不爱你了"）；❌ 当众训斥、翻旧账；❌ 规则随家长情绪变化（今天严明天松），孩子只能靠试探来定位边界。

## §6 手足冲突

### 6.1 识别：冲突的四种底层诉求

① 物权（这是我的）；② 关注（你更爱他）；③ 能力差（小的玩不了，只能用哭与抢）；④ 情绪转移（学校受气，回家打弟弟）。

### 6.2 解读：放弃"公平"，转向"满足所需"

**"公平"是一个陷阱**：孩子要的往往不是一样的东西，而是"你看见我了"。判定标准应是"**每个人有没有得到他需要的**"，而不是"给两个人都一模一样"。

### 6.3 行动：四步

1. **先分开，确保安全**（不评判谁对谁错）："先停下来。"
2. **分别共情**（不做裁判）：对大的——"你的城堡被弄倒了，你一定很生气很心疼。"；对小的——"你想和哥哥玩，哥哥说不行，你不开心。"
3. **把问题还给孩子**（引导而非裁决，主要与能表达的那个谈）："你们都想要。你觉得怎么才能两个人都能玩到？"（等他想；想不出来再给建议）
4. **尊重物权与边界**："有些东西是哥哥自己的，弟弟不能动。哥哥可以选几样不想让人碰的放到自己房间。"

### 6.4 高龄差与低龄差的不同处理

| 情形 | 要点 |
|---|---|
| 年龄差 <3 岁 | 以"分开 + 平行陪伴"为主；避免让大的长期"让小的" |
| 年龄差 >5 岁 | 明确物权边界；不把"照顾"变成硬性义务（邀请代替指派） |
| 一方有特殊需要 | 避免让普通孩子永久承担"懂事"角色（`08` §2） |

### 6.5 争宠与"你偏心"

- **不否认感受**：不说"我没有偏心"，改说"你觉得我偏心了，这让你很难过。谢谢你告诉我，你的感受很重要。"
- **给具体解释**："弟弟妹妹现在小，确实需要更多照顾，这不代表我更爱他，你小时候我也是这样照顾你的。"
- **行动大于语言**：增加与该孩子的**一对一专属时光**（每天 15-20 分钟，不看手机、不照顾其他孩子），这是安全感的"刚需"（`14` §6「二胎与手足」）。
- **把需求问出来**：分别问每个孩子"**你此刻需要我为你做什么？**"——回应的是各自的需求，而不是"一人一半"的公平。
- **绝不比较**：只和"他自己的昨天"比。

### 6.6 退行行为（二胎出生后常见）

吮手指、尿床、要人喂、装小宝宝、黏人——**这些都是正常反应，不是变坏**，是在确认"你还愿意照顾我"。

- 温柔接纳几次（"来，张嘴"喂两口、抱一抱），多数孩子几周后自然放弃；
- 不讽刺、不嘲笑、不逼他"当哥哥姐姐要懂事"；
- 若退行持续超过 1 个月且伴随攻击行为加剧 → 按 §13 参考分流。

### 6.7 例外：这不是"手足冲突"

若出现**持续压制、羞辱、身体伤害、以强凌弱、孤立排挤**，属于**霸凌性质**，不按手足冲突处理 → 走 `08` §4，并优先保护受欺负的一方；如有暴力与安全风险 → `09` §2。

## §7 羞耻感与自我价值

### 7.1 识别：羞耻的三个信号

① 语言："我就是笨""反正我做不好""没人喜欢我"；② 身体：低头缩肩、脸红、躲避目光、突然沉默；③ 行为：放弃尝试、说谎掩盖、攻击性提升、过度讨好。

> 羞耻（"我这个人不好"）与内疚（"我做了一件不好的事"）必须分开：**内疚可以促进改变，羞耻只会生产更多隐瞒与攻击。**

### 7.2 解读：遇困时，孩子仍然是"好孩子"

核心信念：**行为可以有错，本心始终是好的。** 孩子做错事时，他最难承受的不是你的生气，而是"在你眼里我变成了坏孩子"。

### 7.3 行动

1. **把人和行为分开**："这件事做得不对" ≠ "你是个坏孩子"（明确说出这句话）。
2. **亲密解毒**：羞耻需在关系中被解除。冲突后主动靠近（身体接触、一起做件小事），不要用疏远"惩罚"，那会加深羞耻。
3. **相信孩子的感受**（身体主权与自信）：孩子说"我不喜欢被这样抱/摸"时，**第一时间相信并停止**，不否定（"人家是喜欢你"）、不强迫（"快给阿姨一个拥抱"）。被相信的孩子才敢在遇到越界行为时说出来。哭泣同理——"眼泪告诉我们，身体里正在发生一些重要的事"，不呵止、不贴"假哭"标签。
4. **夸过程，不夸天赋**："我看到你一直在想办法""你试了三次"，替代"你真聪明"。（夸特质会让孩子为了维持"聪明"而逃避挑战）
5. **区分"评价"与"感受"**：不说"你这样很没出息"（评判人格），说"你这样做，我有点担心"（表达感受）。

### 7.4 情感资本：日常"存钱"，冲突时才有"余额"

**情感资本**＝孩子心里的那句话——"我在爸妈这里是被爱的、安全的、值得的"。冲突与管教是"取钱"，若不日常"存钱"，关系账户会透支。

日常存取方式（**一对一专属时光**是最高效的一种）：
- 每天 15-20 分钟只属于他（手机放下、100% 投入，孩子主导玩什么，父母只观察与印证，不指挥不评判）；
- **填充游戏**：平和时用肯定的话语"填满"他（"你笑起来真好看，我忍不住想一直看着你"）；
- **情绪疫苗**：难事来临前先打"预防针"——用预演+亲密提前连接（"明天要打针，我知道你可能会怕，我会一直陪着你"），而非临场说教；
- **坐情绪长椅**：孩子有情绪时，想象和他并排坐在"长椅"上一起看问题，而不是站在他对面；
- 具体化的肯定（"今天你自己收拾了书包，我注意到了"）；
- 保留固定仪式（睡前故事、接送路上的话题、周末一件事）；
- 用讲故事的方式回顾他的成长（"你小时候……"）；
- 在孩子情绪好时，主动靠近与身体接触（不用等到出问题才关注）。

### 7.5 常见失败模式

❌ "你怎么这么笨/这么没出息"（人格羞辱）；❌ 用比较制造羞耻（"你看人家"）；❌ 公开批评、当众揭短；❌ 用冷落、撤回爱当作惩罚；❌ 只在孩子出问题时才给关注（等于告诉孩子：只有出事才有你）。

## §8 挫折耐受与韧性

### 8.1 识别

- 输不起、一输就哭、摔东西；
- 遇难就退，宁可说"我不行"也不尝试；
- 完美主义：写错就整页撕、考试非满分不交；
- 被批评就崩、长时间纠结于"我是不是做错了"。

### 8.2 解读：**调节在先，快乐在后**

韧性不等于"扛得住"，而是**先能调节情绪，再能回到问题上**。顺序搞反（先逼他坚持、先讲道理）只会加剧崩溃。

- 压力−支持＝伤害；**压力 + 支持＝成长**。家长能给的是"支持"这一侧，不是替他搬走压力。
- **压力 + 应对方式 = 内心感受**：同一件事，应对方式不同，内心体验就不同——教应对方式，比消除压力更可行。
- **示范优于命令**：家长自己如何面对失败，是孩子唯一的教材。（孩子不听你怎么说，只看你怎么做）

### 8.3 行动

1. **先接住崩溃**："你觉得好难，这很正常。"（不急着让他好起来、不急着讲道理）
2. **重定义"难"**："你是现在还不会，不是永远不会。"（引入"暂时"这个词）
3. **拆小步**："第一步是什么？就做这一小步就行。"（把任务切成他能力范围内的动作）
4. **认可过程**："我看到你一直在想办法，这比答对更重要。"
5. **重定义失败与学习**："犯错说明你在学新东西。"对完美主义的孩子可用**游戏化倒转**帮他接纳灰色地带——"这页我们故意全部写错/所有词都要拼错！"（从"必须完美"里松绑）
6. **示范扛挫**：家长主动说出自己的失败与处理——"我今天也搞砸了一件事，我打算这样补救。"
7. **不急着让他高兴**：允许他待在不舒服里一小会儿（陪着），再一起回到任务——这是真正的抗压训练。

### 8.4 边界

- 不制造"压力训练"（故意让他输、故意打击、挫折教育的羞辱版本）；
- 不把"坚强"等同于"不许哭"；
- 不替他做完（剥夺练习机会，等于告诉他"你确实不行"）；
- 不把"成绩"与"我的爱"挂钩。

## §9 高敏感孩子

### 9.1 识别（描述性，非诊断）

对声音/光线/气味/衣物标签异常在意；情绪强度大、恢复慢；观察细节、共情强；怕生、对新环境谨慎；被批评后反应远大于事件本身；信息过载后突然崩溃。

> **重要**：高敏感不是病，也不等于"有问题"；一小部分孩子同时存在感觉处理困难，需要专业评估（`03` §3、`08` §2）。**不给"高敏感/感统失调"贴标签**，用"这孩子对刺激的反应比较强"这类描述性语言。

### 9.2 行动：控场 + 间接帮助

1. **控制局面而非控制孩子**：降低刺激（音量、灯光、人多场合、行程紧凑度）、提前预告变化、留出缓冲时间。**改环境比改孩子有效得多。**
2. **间接帮助**：不正面评判、不当众提示（"他又开始了"）。用间接方式给支持——递一条毯子、把他带到阳台、事后私下聊一句"刚才人太多了"；也可用**不直视的间接游戏**绕过防御（如"大拇指游戏"：让孩子在拳头里藏真正想说的话，用竖大拇指/藏拇指示意愿不愿说——他在自己准备好的时候才开口）。
3. **降低语言量**：情绪高时少说话、少提问、少分析。**身体在场 > 语言安慰。**
4. **提前预告与撤退预案**：出门前说清安排；准备好"提前离场"的合理理由（不让孩子背负"扫兴"的羞耻）。
5. **接纳强度**：不要求"别那么激动"，改为"你的感受比别人强，我们现在学怎么把它降下来"（配合 §11 的身体信号方法）。
6. **保护优势面**：敏感孩子往往细腻、共情强、观察敏锐——具体地指出这些优势（不是空夸）。

### 9.3 边界

- 不把"敏感"当成纵容一切行为的理由（安全底线不变）；
- 不因"敏感"而长期回避所有挑战（会窄化生活）；用渐进方式介入；
- 若伴随**语言/社交功能明显落后、刻板行为、感官异常影响日常生活** → 走 §13 分流。

## §10 修复关系

### 10.1 何时做

- 在你吼过、骂过、动手过、说过羞辱性的话之后；
- 在孩子哭到崩溃、你丢下他走开之后；
- **不在冲突中修复**——等双方都落回基线（一般 30 分钟—24 小时；孩子越小需要越短）。

### 10.2 先修自己（否则修复会变形）

先处理自己的羞耻与自责：**"发火不代表我是坏父母，它代表我资源耗尽了。修复比完美更重要。"**（家长自身的疗愈见 `07` §2、§6）

### 10.3 四步修复法

```
第 1 步 · 命名事件，不找借口
   "刚才我对你大声说话了。"

第 2 步 · 承认错误与影响
   "我不该那样吼你。我生气不是你的错，是我没管好自己的情绪。"

第 3 步 · 明确下次的做法
   "下次我会先走开冷静一下，再跟你说话。"

第 4 步 · 修复连接
   "你能原谅我吗？来抱抱。"（不强迫原谅；他拒绝就说明天再来）
```

**「修复 = 开启对话」变体**（道歉只是结束对话，修复是开启对话）：
① "**我一直在想那件事**"（让孩子知道你没翻篇、没假装没事）→ ② 尊重孩子的感受（"你当时肯定很受伤/很害怕"）→ ③ "下次我会……"（给安全感）→ ④ **好奇收尾**："你还有什么想让我知道的吗？"——留出孩子说话的空间，听完再停，不急着宣布"这事过去了"。

### 10.4 修复的四个误区

| 误区 | 为什么无效 |
|---|---|
| 道歉里带"但是"（"对不起，但是你也不该…"） | 变成二次指责，通道再次关闭 |
| 只赔礼不讲行为改变 | 孩子学到"发火可以用礼物抵消" |
| 强迫原谅、逼"说没关系" | 用成人需要覆盖孩子感受 |
| 道歉后立刻要求配合（"那现在可以写作业了吧？"） | 把修复变成交易 |

### 10.5 边界：修复 ≠ 撤销后果

道歉不代表规则失效。可以同时成立两件事：**"我爱你"和"昨晚的规则依然有效"**（"两件事都成立"原则）。修复的是关系，不是规则。

**"两件事都成立"话术模板**（守住决定 + 接纳感受，用理解取代说服）：
- "我坚持不让你看这部电影，**同时**你为此难过是完全合理的。"
- "我说不行，这是我的决定；你生气，这是你的权利。两件事都成立。"
- ❌ 说服用语（"你应该懂事""别难过了""我都是为你好"）会退回"只有我的真相算数"的对抗。

## §11 情绪小生物（身体信号法，主要 0-8 岁）

### 11.1 原理与适用

幼儿无法抽象命名情绪，但能注意到"肚子怪怪的""手热热的"。**把情绪映射到身体信号（内感受觉察），让情绪变得外在、可管理**，孩子就能通过一次次"被接住"的经历建立调节能力，而不是靠讲道理。

**年龄纪律（必须遵守）**：
- **0-2 岁：不使用**情绪小生物。家长只用简单的身体描述帮宝宝命名："你现在身体绷绷的""你的小手在抓紧"，主要靠拥抱、摇晃、声音节奏来调节。
- **3-4 岁**：只强调小生物 + 身体感觉（用"热热的/紧紧的/软软的"这类对比词），每个小生物搭配一个固定动作，不要求反思。
- **5-6 岁**：加入一个明确情绪词；平静后允许一个简短选择；可以问"小火苗跑到身体哪里了？"
- **7-8 岁**：加入简短反思，邀请孩子注意"早期预警信号"，可把"小生物 + 身体信号 + 修复计划"串起来。
- **9-12 岁（过渡期）**：孩子仍喜欢可继续，但**不强加**；更多使用直接的情绪语言（"你现在感觉很挫败"），身体觉察仍有效。
- **12 岁以上：不使用**。改用直接、平等的情绪语言；"你现在身体有什么感觉？"比"小火苗来了"更合适。

### 11.2 核心映射表

| 情绪 | 小生物 | 身体信号（内感受） | 调节动作 |
|---|---|---|---|
| 愤怒 | 小火苗 🔥 | 手心发烫、牙齿咬紧、胸口要炸开 | 和大人一起慢慢把火"吹灭" |
| 伤心 | 小水滴 💧 | 喉咙发酸、眼睛发烫、胸口沉沉的 | 温暖拥抱 / "雨伞臂" |
| 害怕 | 小乌云 ☁️ | 肚子里有蝴蝶、腿发抖、心跳好快 | 牵手 / 气球呼吸 |
| 挫败 | 小石头 🪨 | 下巴发紧、身体僵硬、想放弃 | 抖掉石头 / 慢慢踩地 |
| 嫉妒 | 小藤蔓 🌿 | 胸口发紧、肚子酸酸的、想黏人或变刺 | 说出想要的，再重新连接 |
| 兴奋 | 小星星 ✨ | 腿想跳、脑袋转个不停、声音好大 | 慢慢数数 + 落地呼吸 |
| 焦虑 | 小蜜蜂 🐝 | 脑袋嗡嗡响、坐不住、肚子紧紧的 | 落地呼吸 + 数五样看得到的东西 |
| 委屈 | 小刺猬 🦔 | 嘴巴撅起来、胸口又堵又酸、想躲起来 | 让刺猬慢慢打开 + 说出来 |

### 11.3 场景 → 小生物映射（快速选用）

| 家庭场景 | 可能的小生物 | 常见身体信号 | 建议第一步 |
|---|---|---|---|
| 不肯刷牙/洗澡/睡觉 | 小石头 / 小火苗 | 身体僵硬、脸发烫 | 慢过渡 + 一起做动作 |
| 出门前磨蹭 | 小乌云 / 小石头 | 黏人、脚不动 | 牵手连接 + 倒数 |
| 抢东西/打人 | 小火苗 / 小藤蔓 | 手发烫、下巴紧 | 安全边界 + 呼吸/踩地 |
| 公共场所哭闹 | 小乌云 / 小水滴 | 心跳快、眼睛烫 | 减少围观压力 + 落地 |
| 分离焦虑 | 小乌云 / 小蜜蜂 | 肚子翻腾、黏人 | 告别仪式 + 熟悉短语 |
| 输了游戏 | 小石头 / 小水滴 | 嘴巴紧、胸口沉 | 认可崩溃 + 身体重置 |
| 兄弟姐妹嫉妒 | 小藤蔓 / 小水滴 | 胸口紧、肚子酸 | 说出渴望 + 重新连接 |
| 屏幕时间结束 | 小火苗 / 小石头 | 身体发烫、肩膀僵 | 缓冲仪式 + 活动身体 |
| 写作业崩溃 | 小石头 / 小蜜蜂 | 身体僵硬、脑袋嗡嗡 | 暂停 + 身体重置 + 拆分任务 |
| 被同学排挤/欺负 | 小水滴 / 小刺猬 | 胸口沉、想躲起来 | 先接住感受，不急于解决（`08` §4） |
| 考试/表演前紧张 | 小蜜蜂 / 小乌云 | 肚子紧、手心出汗 | 落地呼吸 + "紧张说明你在乎" |
| 被批评后委屈 | 小刺猬 / 小水滴 | 嘴巴撅、胸口堵 | 让感受被看到 + 不急着讲道理 |

### 11.4 固定仪式短句库（保持一致，反复使用）

- "哦，小火苗/小乌云/小藤蔓来了。"
- "它先跑到身体哪里了？"
- "我们先一起做一个动作，不急着马上解决。"
- "等身体舒服一点，我们再选下一步。"
- "小生物不是坏的，它只是来告诉你：身体里有一个大大的感觉。"

### 11.5 视觉状态协议（画出来或讲出来）

- **爆发期**：小生物变大、颜色加深、动作加快；
- **调节期**：小生物变柔和、颜色变浅、节奏变慢；
- **恢复期**：小生物恢复正常大小，出现连接符号（爱心/星星）。

### 11.6 使用规则

- 危机模式下只使用**一个小生物**（孩子明确描述混合情绪时例外）；
- 不一次给太多身体信号；优先使用熟悉、反复出现的那几个，不要不断创造新的；
- 孩子拒绝这个比喻 → 立刻切换为简单的身体语言描述，**不强迫想象**；
- 9 岁以上酌情使用，**12 岁以上不使用**。

## §12 反模式清单（家长高频错误做法）

> 用法：家长问"我这么做对不对""是不是我方法有问题"时，对照本表；指出问题时**一次最多给 2-3 条**，并附替代做法，不做全面批判。

| # | 反模式 | 为什么有害 | 替代做法 |
|---|---|---|---|
| 1 | **逼道歉** | 强迫的道歉只教"说对的话躲惩罚"，不产生同理 | 先修复关系与照顾受伤方，让孩子自己决定是否道歉（`14` 对应情景节） |
| 2 | **追"公平"** | "公平=相同"会强化争宠与比较 | 转向"满足所需"，明确物权边界（§6） |
| 3 | **否定感受** | "这有什么好哭的"教孩子不信任自己的感受 | 先命名并承认，再谈行为（§1） |
| 4 | **恐惧时讲道理** | 恐惧中大脑不处理逻辑 | 提供安全感动作 + 渐进暴露（§4） |
| 5 | **命令"自己控制情绪"** | 前额叶未成熟，命令做不到的事＝制造失败体验 | 家长先共调节（陪伴、呼吸、身体动作）（§2） |
| 6 | **贴标签** | "笨/坏/撒谎精/脾气大"会内化成自我认知 | 描述具体行为 + 描述性语言（§7） |
| 7 | **把"只想要孩子快乐"当目标** | 回避一切不适，孩子失去调节机会 | 允许不适存在，陪着度过（§8） |
| 8 | **用完美标准讲道理** | 完美主义与高期待会提升放弃率 | 拆小步 + 认过程 + 允许犯错（§8） |
| 9 | **"假哭/装的"判定** | 判定动机等于关闭沟通，孩子只会哭得更凶 | 只描述可见事实 + 给情绪命名（§2） |
| 10 | **冷处理/隔离当惩罚** | 被推开加重失调，且传递"你的情绪会让人离开" | 在场陪伴＋设边界（§2） |
| 11 | **承诺"说实话就不生气"再惩罚** | 一次背刺，真话通道关闭多年 | 先降后果、先表扬诚实（§3） |
| 12 | **条件式爱与撤回爱** | "再这样我就不爱你了"制造生存级别的恐惧 | 分离行为与关系："我不允许这个行为，我爱你不变"（§1、§7） |
| 13 | **只道歉不改变** | 关系反复破裂 → 修复失去信用 | 道歉必须包含"下次怎么做"（§10） |

## §13 行为异常筛查与分流

> 本节的**唯一产出是"要不要去评估/找专业"以及"去哪里"**，绝不做诊断、不下结论。任何判断都使用"这可能是…的正常范围""这些情况建议由专业评估"的表述。

### 13.1 需要专业评估的信号（黄灯：建议预约评估）

| 领域 | 信号 |
|---|---|
| 情绪 | 持续低落/易怒 >2-4 周；情绪强度远超同龄；反复说"我没用""都怪我" |
| 焦虑 | 恐惧泛化、影响上学/睡眠/进食；反复洗手/检查等强迫样行为 |
| 社交 | 明显回避同伴、长期被排斥、不会解读社交线索 |
| 行为 | 攻击行为持续且升级；频繁说谎/偷拿且不因后果改变；破坏规则成模式 |
| 注意与自控 | 多场景（家庭+学校）持续明显难以专注、坐不住、冲动，影响学业与人际 |
| 发展 | 语言/运动/社交能力**倒退或明显落后**同龄（`01` §7、`03` §3） |
| 睡眠/进食 | 显著改变并持续（入睡困难、夜惊频繁、拒食、暴食、体重异常变化） |
| 感觉处理 | 对触觉/声音/衣物标签异常敏感或迟钝、动作笨拙、平衡差、明显寻求旋转攀爬，跨场景持续 ≥1 个月且影响生活/学习/社交（`08` §2.6） |

### 13.2 红灯（立即处理，走危机协议）

- 自伤行为、表达"不想活了"、遗书/告别式言语 → **`09` §2 心理危机协议**；
- 身体伤害他人、严重暴力、疑似虐待或家暴 → **`09` §2**；
- 出现幻觉、妄想、意识改变、抽搐 → **`09` §1 + 急诊**；
- 突然完全不出门、不进食、不说话（紧张症样表现）→ 急诊。

### 13.3 分流表

| 问题类型 | 去向 |
|---|---|
| 症状、发育里程碑、是否需要就医 | `03` §1、§2、§3 |
| 神经多样性（ADHD/自闭谱系/感统） | `08` §2 |
| 抑郁、焦虑症、强迫、自伤 | `08` §3 + `09` §2 |
| 霸凌、校园排挤 | `08` §4 |
| 屏幕/游戏成瘾 | `08` §5 |
| 家庭结构（离异、单亲、留守） | `08` §1 |
| 家长的焦虑与自责 | `07` §4、§5 |
| 记录与追踪工具 | `11` §4 |

### 13.4 评估前的准备（提高就诊效率）

- 记录"行为 ABC"：**前因**（发生了什么）→ **行为**（具体做了什么、持续多久）→ **后果**（大人如何回应、孩子如何结束）；
- 记录频次、场景（家/校/两者）、时间点（如每晚睡前）；
- 收集老师/幼儿园的观察（跨场景信息是评估关键）；
- 同时记录**好的表现**，避免只呈现问题面；
- 工具模板见 `11` §4。

## §14 重复性习惯行为（咬指甲、吃手、拔毛、撞头等）

> 这类行为多数**不是"坏习惯"，也不是故意对抗**，而是无聊、紧张或困倦时的身体动作（与抽动的规律一致，见 `03` §3.4）。盯着它纠正，通常只会让它更频繁。

### 14.1 识别：先看它什么时候发生

| 出现时机 | 更可能是什么 | 应对方向 |
|---|---|---|
| 看电视、坐车、等餐等空白时间 | 无聊时的自我刺激 | 给手上一个替代动作 |
| 被催促、被批评、考试或分离前 | 紧张与压力 | 提前预告 + 身体降级（§2） |
| 困了、累了、睡前 | 自我安抚 | 提前入睡 + 固定睡前程序 |
| 专注或放松时反而减少 | 提示与紧张相关 | 不加关注、不纠正 |

### 14.2 行动：替而不禁

1. **先减关注**：提醒、纠正、当众指出都会增加发生率（同一规律见 `03` §3.4 抽动）；不贴"脏""难看""没出息"的标签（§7）。
2. **找触发点**：连续记录 1-2 周"什么时候出现"（`11` §4.3 行为 ABC），针对最集中的那类时机动手，不做全面禁止。
3. **给可接受的替代动作**：捏减压球、搓手指、撕纸、握小积木——在**想咬/想吃手的那一刻**递上去，而不是事后讲道理。
4. **降低背景压力**：提前预告变化（"再 5 分钟出门"）、减少催促、保证睡眠；压力降下来，频率常随之下降。
5. **约定优于禁止**："我们试试让手忙起来"优于"不许咬手"；用可见的进步记录（`11` §4.4）。
6. **家长自查**：这类动作常与"一天里被纠正的次数"同步——先减少纠正频率，再谈改变行为（`07` §2）。

### 14.3 边界：什么时候只管、什么时候要评估

- **多数情况**：2-6 岁常见，5-6 岁后逐渐减少；不破皮、不影响进食与社交 → 只做替代与减压，不做干预。
- 🟡 **建议评估**：每天多次且难以被打断、手指破皮出血、拔头发成片或出现斑秃、撞头致伤、伴明显焦虑或抽动 → `03` §3 + `08` §2。
- 🚨 **立即走危机协议**：伴自伤行为、说"不想活了"、疑似虐待或家暴 → `09` §2。
