## 使用须知（三条硬规则）

1. **先接情绪，再给边界，最后才谈解决**——顺序颠倒，任何话术都失效。
2. **一次最多给 3 句核心话术 + 1 条禁忌**。家长记不住更多，给多了等于没给。
3. **涉及安全与危机（自伤、虐待、暴力、身体伤害）**：跳过本文件话术流程，直接走 `09` §2。

## §1 通用话术原则与禁忌

### 1.1 五条核心原则

| # | 原则 | 说明 |
|---|---|---|
| 1 | **先连接，后纠正** | 开口第一句永远不是指令，而是看见——"你看的这个挺有意思的。" |
| 2 | **短句优先** | 情绪中的孩子只能接收 1 句 10 字左右的话；长段＝噪音 |
| 3 | **描述，不审问** | "我注意到杯子倒了，地上都是水。"（而不是"是不是你弄的？"） |
| 4 | **给选择，但选项都由你接受** | "现在开始，写完还能看 15 分钟；或者再等一下，今天就不看了。你选。" |
| 5 | **接纳感受，限制行为** | "你可以很生气" ✔ ／ "但不可以打人" ✔（两者必须一起说） |

### 1.2 三类通用句式公式

| 用途 | 公式 | 示例 |
|---|---|---|
| **共情句** | 命名情绪 + 说出愿望 + 承认合理 | "我知道你特别想要它，想得都难过了。" |
| **设边界句** | 我不会允许 + 具体行为 + 替代方式 | "我不会允许你打人。生气可以跺脚，或者来告诉我。" |
| **我句式（事后）** | 我看到 + 我感到 + 我需要 + 你怎么想 | "我叫你三遍你没回应，我有点着急。我希望我们能有个约定。你怎么想？" |
| **连接句（事后/平时）** | "我有没有跟你说过，有一次……" + 自己当年的类似经历 | "我有没有跟你说过，有一次我撒谎被你外婆发现了……当时我吓坏了。"（传递"你不是一个人"，拉近距离） |

### 1.3 禁忌清单（出现即判定为不合格话术）

| # | 禁忌类型 | 典型句子 | 为什么不行 |
|---|---|---|---|
| 1 | **恐吓** | "再哭我就把你扔这儿""警察来抓你" | 制造生存恐惧，孩子的恐惧会留在身体里 |
| 2 | **威胁抛弃** | "你再这样我就走了""我不要你了" | 直接攻击依恋安全感，最伤 |
| 3 | **羞辱** | "丢不丢人""这么多人看着呢" | 把"我的面子"放在孩子感受前面 |
| 4 | **条件式爱** | "你再这样我就不爱你了" | 爱变成交易，孩子学会讨好 |
| 5 | **贴标签** | "你就是懒/笨/脾气大/撒谎精" | 标签会内化为自我认知 |
| 6 | **否定感受** | "这有什么好哭的""没什么大不了" | 教孩子不信任自己的感受 |
| 7 | **翻旧账** | "你每次都这样""上次也是你" | 从"这件事"升级为"你这个人" |
| 8 | **当众训斥** | 在同学/亲戚/商场里批评 | 羞耻创伤远大于教育效果 |
| 9 | **比较** | "你看人家×××""弟弟都比你强" | 制造嫉妒与自我否定 |
| 10 | **逼道歉** | "快说对不起！" | 只会教"说对的话躲惩罚" |
| 11 | **从远处大喊指令** | 厨房喊"写作业了！"×5 | 无效，且训练孩子忽略你 |
| 12 | **空口承诺后反悔** | "说出来我不生气"→转身惩罚 | 一次背刺，真话通道关闭多年 |

### 1.4 禁语替代对照（高危禁语 → 当场可改口的话）

> 用法：家长引用了 §1.3 禁忌句、或话冲到嘴边时，直接给"改说这句"。输出时一次最多给 3 组，只给原句不给解释。

| ❌ 禁语 | ✅ 改说 |
|---|---|
| "再哭我就把你扔这儿" | "你可以哭，我在这里陪你；哭完我们就走。" |
| "这有什么好哭的" | "你现在很难过，换成我我也会难过。" |
| "快说对不起！" | "妹妹在哭，你觉得她现在需要什么？" |
| "你怎么这么懒" | "作业还差两样，你打算先做哪个？" |
| "你再这样我就不爱你了" | "我不允许这个行为，但我一直爱你。" |
| "你看人家×××" | "你自己比上周进步的地方是……" |
| "赶紧的！都要迟到了" | "离出门还有 10 分钟，先穿鞋还是先背书包，你选。" |
| "我说不行就不行" | "这事没得商量，因为它涉及安全。其他的我们可以聊。" |

### 1.5 身体语言（比措辞更重要）

- **蹲下来**：与孩子视线齐平（3 岁以下尤其关键）；
- **降低音量**：声音越小，孩子越需要靠近听；
- **距离与触碰**：先握手/轻拍肩/搂一下，再说话；
- **面部表情**：中性或柔和，不用"皮笑肉不笑"的讥讽笑；
- **说完停 5 秒**：留出孩子的反应时间，不追加第二遍。

### 1.6 话语归因：一句话背后是什么、会造成什么

> 与 §1.3 禁忌清单**互补**：§1.3 判"这句话能不能说"，本表说"**说了意味着什么、代价是什么**"——知道代价，才改得动。

**父母的话 → 孩子这边的原因 → 长期影响**

| 父母常说 | 孩子这边实际发生的事 | 长期影响 |
|---|---|---|
| "你真笨" | 遇到了超出他能力的困难 | 低自尊、习得性无助 |
| "你怎么这么不听话" | 他在发展自主性 | 表面顺从、内心叛逆 |
| "再不听话就不要你了" | 他在测试爱的边界 | 焦虑型依恋 |
| "看看别人家孩子" | 他与你的期望有差距 | 嫉妒、无法欣赏他人 |
| "我都是为你好" | 他的感受被否定 | 情感隔离 |
| "你怎么这么没出息" | 他有自己的节奏 | 成就焦虑 |
| "别烦我" | 他有真实需求 | 情感忽视 |
| "我这么辛苦都是为了你" | 他被情感绑架 | 愧疚型人格 |
| "你必须按我说的做" | 他需要练习做决定 | 决策困难 |
| "不准哭" | 他有真实情绪 | 情绪压抑 |
| "你一定能考第一名" | 他在承受你给的压力 | 考试焦虑 |

**孩子的行为 → 核心原因 → 不同的处理会带来什么**

| 行为 | 核心原因 | 被惩罚 / 被倾听的不同走向 |
|---|---|---|
| 发脾气 | 情绪调节能力还没长好 | 被惩罚→表达更激烈；被倾听→学会管理 |
| 说谎 | 害怕惩罚 | 被逼供→更复杂的谎与羞耻；被接住→敢说真话 |
| 打人 / 破坏东西 | 说不出那股强烈的情绪 | 被压制→攻击性持续；被命名→学会表达 |
| 不听话 | 在发展自主性 | 硬碰→权力斗争；给选择→健康自主 |
| 沉迷手机 / 游戏 | 在逃避现实里的压力 | 只没收→对抗升级；补上现实成就感→自然减少 |
| 说"我恨你" | 在表达痛苦 | 辩论爱不爱→通道关闭；听见情绪→学会表达 |
| 不写作业 | 太难，或在反抗控制 | 加压→动力继续下降；拆小步→回到主动 |
| 欺负别的小朋友 | 在模仿家里的互动方式 | 只罚→行为持续；改家庭互动→行为改变 |

## §2 分龄话术要点

### 2.1 0-1 岁：回应即语言

- **理解要点**：哭是唯一沟通方式；这个阶段**不存在"惯坏"**；他听不懂道理，只感知你的音调、体温、节奏。
- **话术重点**：把正在做的事**说出来**，固定用词、固定语气——"妈妈抱你起来啦""要换尿布喽"。
- **可说**："妈妈在这儿。""我在呢，宝宝。""你是不是饿了？来了来了。"
- **别说**：❌ 对婴儿发火；❌ "不许哭""再哭我把你放下来"（他无法理解，只感到被抛弃）；❌ 在他面前争吵。
- **注意**：**绝不摇晃婴儿**。父母的状态就是话术的一部分（疲惫时说的话必然走形，先处理自己，见 `07` §2）。

### 2.2 1-3 岁：短句 + 选择 + 转移

- **理解要点**：听得懂远少于想说的；**3 岁的孩子没有能力控制情绪**；"我的""不要"是自主性发展的标志。
- **话术重点**：**短、具体、可视化**；一次只给一个指令；用"我们"代替"你"；把规则变成游戏。
- **可说**：
  - "该收玩具啦。你想先收积木还是先收小汽车？"
  - "我们来比赛谁先穿好衣服！预备——开始！"
  - "牙刷先生说：我要去抓牙虫虫啦！啊——张大嘴巴。"
  - "妈妈去倒杯水，一分钟就回来。"
- **别说**：❌ "说了多少遍了！"；❌ "你怎么这么不听话"；❌ 长篇解释为什么不能买。
- **注意**：说"不"最有效的场合只有安全（电、水、火、马路）；其他场合用"可以……但是……"替代"不行"。

### 2.3 3-6 岁：预告 + 仪式 + 游戏化

- **理解要点**：想象力爆发（"我的恐龙会飞"是想象不是撒谎）；能懂规则但执行弱；害怕与分离焦虑高发。
- **话术重点**：**提前预告**（还有 5 分钟、还有 2 本书）、**固定仪式**（告别仪式、睡前程序）、**游戏化**。
- **可说**：
  - "还有 2 本书我们就关灯哦。"
  - "亲三下：鼻子、额头、手心。我的亲亲印在你手心里，想我了就看看手心。"
  - "妈妈吃完午饭、睡完午觉后就来接你。"
  - "我们来玩'假装游戏'：小熊很生气，它可以怎么做？"
- **别说**：❌ "有什么好哭的，别的小朋友都不哭"；❌ "你撒谎！"（幻想型内容不需要纠正）；❌ "你再哭妈妈不来接你了。"
- **注意**：新食物平均要 10-15 次接触才被接受——餐桌上不说"你必须吃完"。

### 2.4 7-12 岁：参与制定 + 自然后果

- **理解要点**：能理解因果；开始在意同伴评价与公平；需要被当成"有能力的合作者"。
- **话术重点**：**一起定规则**、**说清后果**、**强调过程而非结果**、**不站在问题对面**。
- **可说**：
  - "你的上床时间是 9 点。9 点之前你自己安排，但 9 点灯必须关。你来管时间好吗？"
  - "老师跟我说你最近上课有点走神。你觉得是什么原因？是听不懂，还是觉得无聊？"
  - "你是现在还不会，不是永远不会。"
  - "我看到你一直在想办法，这比答案对不对更重要。"
- **别说**：❌ "你怎么这么不努力"；❌ "别人都行就你不行"；❌ "这次考不好就别想出去玩了"（把爱与结果绑定）。
- **注意**：把"命令"改成"约定"；把"监督"改成"信任 + 自然后果"。

### 2.5 10-12 岁（青春前期）：面子优先

- **理解要点**：开始在意"我爸妈会不会让我丢人"；同伴评价高于家长评价；这不是嫌弃，是长大的正常表现。
- **话术重点**：**叫大名不叫小名**、不当同学面讲糗事、主动给空间、把亲近方式改成私下。
- **可说**：
  - "我注意到你不太想我在同学面前太亲热。没关系，我可以调整。但在家里，你还是我的宝贝，这个不变。"
  - "你决定要分享什么，我不主动替你说。"
- **别说**：❌ "我养你这么大你嫌我丢人"；❌ "你翅膀硬了是吧"；❌ 在他社交场合过度亲密。
- **注意**：不要用"叛逆"定义这个阶段，用"正在建立自己的边界"。

### 2.6 13-18 岁：不接球 + 留门缝

- **理解要点**：情绪强度高、需要隐私与尊严；他期待的是对抗，你越接，战越久。
- **话术重点**：**不反击、不辩解、不下结论**；用"嗯/我听到了"接住；把门留着但不推开。
- **可说**：
  - "嗯，也许我确实不太理解。你愿意说说看吗？"
  - （摔门后）"我给你倒了杯水放门口。如果你想聊，我在客厅。"
  - （事后）"昨天你说我不理解你。我想了想，可能有些地方我确实做得不好。你能告诉我是哪些事吗？"
  - "你到了这个年纪，喜欢一个人是很正常的。如果你愿意说，我很想听；不想说也没关系。"
- **别说**：❌ "你才多大你懂什么"；❌ "我吃的盐比你吃的饭多"；❌ 偷看手机/日记后当面对质；❌ 在亲戚面前讲他的事。
- **注意**：底线（安全、尊重、法律）不退让，其余（发型、穿搭、房间、作息）尽量放手。

## §4 时机三类剧本

> 同一个问题，**说在什么时候**比**说什么**更决定结果。本节的顺序是"先止损 → 再修复 → 后预防"。

### 4.1 剧本一：风暴中（当场止损）

**时机**：情绪强度最高、听不进道理的**前 5-20 分钟**。

**目标**：不是教育，是**降温**。三件事——保安全、设边界、陪着。

```
① 先降自己：降低音量、放慢语速、蹲下来（不说话也可以）
② 命名一次，不重复： "我知道你很生气。"
③ 只设一条边界： "我不会允许你打人。"
④ 陪着，不追问： "你可以哭一会儿，我在这里陪你。"
⑤ 撤退选项： 情绪失控 → 平静抱起离开现场，找安静处坐下
```

**禁忌**：讲道理、问"你为什么这样"、逼道歉、要承诺（"你说下次还敢不敢"）、威胁（"我走了"）、翻旧账、当众训斥。

### 4.2 剧本二：平复后（修复对话）

**时机**：情绪落回基线之后——学龄前约 30 分钟—数小时；学龄期当天睡前为宜；青春期可延到 24 小时内。**判断标准：他能听、你能稳。**

```
① 开场不审问： "刚才的事，我想跟你聊聊。" （或直接先给连接：抱一下/递杯水）
② 我句式先说自己： "我刚才对你大声说话了。"
③ 让孩子说： "当时你最想要的是什么？"（听，不评判，不插话纠正）
④ 共同复盘： "下次遇到同样的情况，我们可以怎么做？"（让他先说方案）
⑤ 修复收尾： "对不起，我生气不是你的错，是我没管好自己的情绪。下次我会先冷静一下再跟你说。"（完整四步见 `05` §10）
```

**禁忌**：在修复里夹带"但是"（"对不起，但是你也不该…"）；用礼物代替行为改变；强迫孩子原谅；修复后立刻要求配合（"那现在可以写作业了吧？"）。

### 4.3 剧本三：平静期（预防与预演）

**时机**：完全没冲突的时候。**这是最被忽略、也最有效的一类。**

```
① 提前约定（出门/睡前/写作业前）：
   "我们今天去超市买牛奶，你可以选一样小零食。我们拉钩。"
② 角色扮演预演：
   "我们玩个游戏：小熊很生气，小熊想打人——但小熊可以怎么做呢？"
③ 规则可视化：
   把睡前流程、写作业时间表画成图贴在墙上，让规则代替家长说话。
④ 家庭会议（7 岁以上）：
   "我们家有个问题：早上总是很赶。你们觉得怎么改会好一点？"
⑤ 家长先排练自己：
   把自己最容易失控的 2 个场景写下来，各自准备一句"退场台词"（"我需要冷静一下，一分钟就回来"）
⑥ 绘本与故事：
   用第三方故事为情绪与规则打预防针（《我的情绪小怪兽》《菲菲生气了》等）
```

**要点**：平静期做的约定，孩子记住的是"我们商量过"，而不是"你逼我"。

## §5 隔代与家校场景

### 5.1 隔代育儿：先理解，再合作

**共同前提**：老人通常出于爱和担心（"不吃饱会饿""不多吃长不高"）——这是他们那个年代"吃饱＝健康"的生存经验。**不需要证明他们错了，而是一起找到更好的方式。**

**五条沟通原则**

1. **不争对错，争合作**；
2. **先肯定，再建议**（"我知道您担心孩子吃不饱，您对他真好。不过……"）；
3. **借权威**（医生、老师、体检报告、书）比自己说更易被接受；
4. **给台阶、给让步**（"周一到周五让他自己吃，周末您想喂就喂，好不好？"）；
5. **不在孩子面前讨论分歧**，事后私下沟通。

**⚠ 三条底线必须统一（不可让步项）**

1. **安全**（过马路、触电、水火）；
2. **打人必须制止**；
3. **说好的规则要一致**（不当场"翻盘"）。

#### 场景 1：老人喂饭追着跑/强迫喂食（1-6 岁）

- **❌ 避免**："妈/爸，你这样喂不对！""都说了不要追着喂！你怎么不听！""现在科学育儿不是你们那一套了！"
- **✅ 先肯定再建议**："妈，我知道您担心孩子吃不饱，您对他真好。不过医生（育儿书上）说，追着喂反而会让孩子对吃饭产生抗拒。我们试试让他坐在餐椅上自己吃？吃多少算多少，他的身体知道自己需要多少。"
- **✅ 借权威**："上次体检医生说了，孩子体重身高都达标，不用担心吃少。""幼儿园老师说他在学校自己吃得挺好。"
- **✅ 给台阶**："要不这样，周一到周五我们让他自己吃，周末您想喂就喂，好不好？"
- **✅ 当场看到追喂时**：❌ 不当着孩子面训斥老人（破坏老人权威，孩子也会学会"不听老人话"）→ ✅ 温和接过来："妈，辛苦了，我来吧。" 事后再私下沟通。

#### 场景 2：老人过度溺爱/无原则满足（全年龄）

- **常见情况**：要什么买什么；孩子打人发脾气老人护着；"他还小不懂事"；父母管教时老人插手护孩子。
- **❌ 避免**："你们这样会把孩子惯坏的！""都是你们惯的！""我管孩子的时候你别插嘴！"
- **✅ 私下、平静、具体**："爸妈，我知道你们疼孩子，我特别感激。但有一件事想和你们商量——当我在教育孩子的时候，哪怕你们觉得我太严了，能不能先不插手？等孩子不在的时候我们再讨论。如果当着孩子面有不同意见，他会觉得'找爷爷奶奶就能翻盘'，以后谁的话都不听了。"
- **✅ 用"我们一起"代替"你不对"**："我们一起想想怎么让他学会等待好不好？不是不满足他，是教他'不是所有东西马上就能得到'。"
- **✅ 孩子当面"找靠山"时**：提前和老人约好统一口径——"这个爸爸/妈妈已经说了，奶奶也同意的。"（关键：老人不"翻盘"）若老人还是当场妥协 → 不当场翻脸，事后沟通："妈，今天那个冰淇淋的事，我理解您心疼孩子。但我们说好了饭前不吃零食，如果他一哭您就给了，下次他会哭得更厉害。我们能不能统一一下？"

#### 场景 3：育儿观念根本性冲突（"你们这一代太娇惯了"）

- **常见冲突点**："我们那时候都这么养的，不也好好吗？""现在的孩子就是太惯了""男孩子哭什么哭，没出息""穿这么少不冷吗""打一顿就好了"
- **✅ 第 1 步 承认与感谢**："爸妈，你们把我养大了，说明你们的方法也有很多是对的。我今天能成为一个还不错的人，都是你们的功劳。"
- **✅ 第 2 步 温和表达**："时代变了，有些方面确实不一样了。不是说以前的方式不好，而是现在有更多的研究帮我们了解孩子的心理。比如打孩子这件事，研究发现虽然短期有效，但长期会让孩子更容易用暴力解决问题。我想试试不打的方式，您帮我观察看看效果好不好？"
- **✅ 第 3 步 邀请参与**："这本书/这个视频挺有意思的，我给您看看？""我也在学习，有时候也做不好，您帮我一起想办法？"
- **✅ 如果完全无法沟通（底线策略）**：
  1. 涉及安全和身心健康的底线绝不妥协（不打孩子、不恐吓、不羞辱）；
  2. 生活习惯的分歧可适当让步（穿多穿少、吃什么零食）；
  3. 实在无法统一 → 调整照顾安排，减少冲突场景；
  4. 记住：**你和老人的关系也是孩子的教材**——你如何对待自己的父母，孩子以后就会如何对待你。
- **✅ 自我调节**："他们是爱孩子的，方式不同不代表不爱。""我改变不了他们所有观念，但我可以在我带孩子的时间里贯彻我的方式。""完美的统一不存在，够好就行。"

### 5.2 家校沟通：做合作者，不做被告

- **核心姿态**：**不是来告状，也不是来挨训**——"想和您一起想想怎么帮孩子"。
- **三个动作**：先听完（不打断不辩解）→ 问具体（时间、场景、科目、同伴）→ 谈配合（"我们在家可以怎么配合？"）。
- **对称信息**：不只问"坏的部分"，也问"他有什么表现好的方面"。
- **难点场景脚本**：被请家长/收到投诉 → §3 E2；上课走神 → §3 E3；孩子被欺负 → §3 E4。
- **跨文件**：校园霸凌的处置原则见 `08` §4。

### 5.3 与医生/专业机构的沟通（就医前准备）

- **去之前写下三件事**：① 症状开始时间与变化过程；② 试过什么、效果如何；③ 最担心的问题是什么。
- **就诊时的话术**："医生，我最担心的是××。我想知道：什么情况需要立刻复诊？在家我要注意观察哪些？"
- **不隐瞒信息**：包括已用过的手法、保健品、偏方（隐瞒会导致误判）。
- **不带预设结论**："网上说是××，是不是？" → 改为"有人说是××，您怎么看？"
- **跨文件**：症状分级与就医指征见 `03` §1、§2；记录模板见 `11` §4。

## §6 父母情绪急救话术

### 6.1 为什么放在最后但最重要

**家长的状态就是孩子的话术环境。** 当你要爆炸时，任何"正确话术"都会走形——此时唯一该做的是处理自己（`07` §2、§3）。

### 6.2 自我对话急救卡（对自己说）

```
"我现在很生气，这是正常的。"
"我可以生气，但我选择不在这个情绪里做决定。"
"他只有 3 岁/8 岁。他不是在和我作对。"
"先冷静，再处理。"
"我要做的是解决问题，不是发泄情绪。"
"他不是坏孩子，他只是遇到了他处理不了的事。"
```

### 6.3 退场话术（对孩子说，然后离开 1-3 分钟）

```
"妈妈/爸爸现在有点生气了，我需要冷静一下。
不是因为不爱你，是因为我需要让自己平静下来。
我去喝杯水，一分钟就回来。"
```

**配套动作**：把孩子放在安全处（婴儿可放婴儿床）→ 离开房间 2-3 分钟 → 深呼吸 5 次 → 喝一杯水 → 回来。
⚠️ **永远不要摇晃婴儿**。⚠️ 离开前必须确认环境安全，且对 3 岁以下要说清"我马上回来"。

### 6.4 发火之后的修复（四句话）

```
① "刚才我对你大声说话了，对不起，我不应该那样吼你。"
② "我生气不是你的错，是我没有管好自己的情绪。"
③ "下次我会努力先冷静一下再和你说话。"
④ "你能原谅我吗？来抱抱。"
```

**为什么一定要说**：这样做不会让你失去权威，反而——教会孩子"犯错了可以道歉"、修复亲子关系、以身作则示范情绪管理。**不需要完美才能当好父母；发完火后的修复同样重要。**（完整四步修复法与「修复＝开启对话」变体见 `05` §10；家长侧的先修自己见 `07` §6.1）

### 6.5 什么时候需要求助

- 持续 2 周以上情绪低落/焦虑/绝望；
- 有伤害自己或孩子的念头；
- 反复失控（每周多次吼叫/打骂）且事后陷入严重自责；
- 对伴侣关系或育儿完全失去信心。
→ **立即联系医生或心理咨询师**。这不是你的错，是需要治疗的状况（`07` §2、`09` §2）。
