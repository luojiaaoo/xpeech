> **加载时机**：问题不在"孩子这个行为怎么办"，而在"我们家的情况本身就特殊"——离异/分居/重组/单亲/留守/隔代抚养、ADHD/自闭谱系/感统、抑郁焦虑强迫/进食问题、霸凌、丧亲与丧失、家暴与父母入狱、手机游戏短视频成瘾、性教育/青春期身体/性取向/多元文化身份。

> **配套**：**家长自己的状态** → `07`；**具体说什么话** → `06`；**是否属于症状、要不要就医** → `03`；**自伤/自杀意念/虐待/家暴 → 危机协议** → `09` §2；**风险等级与转介** → `09` §3、§7；**信源与时效** → `09` §4、§5。
> **口径（贯穿全篇）**：**不诊断、不下结论、不评判家庭形态、不站队父母任一方**。所有"可能关联到…"的表述都不是诊断；凡涉及临床判断，一律指向专业评估。

## 使用须知（三条硬规则）

1. **危机优先**：任何特殊议题里只要出现自伤、自杀意念、暴力、疑似虐待 → **立即跳到 `09` §2**，不在本文件内处理。

3. **表述纪律**：说"这些表现被关联到…"，不说"就是…病"；说"建议评估"，不说"不用管"。

## §1 家庭结构

> **覆盖**：离异/分居、选边站、重组家庭、单亲、多孩与偏心、留守与隔代抚养、祖辈冲突、收养/寄养、多胞胎。

### 1.1 永远排在第一位的两句话

无论结构如何，**孩子最需要先听到的两句**是：

1. "**这不是你的错。**"（尤其离异、分离、家暴、父母入狱、生病）
2. "**你可以问我，我会答。**"（保留提问通道，不隐瞒、不糊弄）

孩子的问题行为是"感受到变化"的信号，不是"捣乱"的原因。

### 1.2 离异 / 分居

**核心原则**：分开是成人关系的变化，**不是亲子关系的结束**。

| 要做的 | 不要做的 |
|---|---|
| 明确告知："爸爸妈妈分开，不是因为你。永远不是因为你。" | ❌ "都是因为你我们才这样" |
| 允许孩子难过、生气、反复问同一个问题 | ❌ "别哭了，这有什么好难过的" |
| 保证与双方的相处时间**可预测**（时间表写出来） | ❌ 用"见不见"当奖惩 |
| 允许孩子爱另一方 | ❌ "你妈/你爸不要你了" |
| 成人的冲突在成人之间解决 | ❌ 在孩子面前评价对方 |

**行为问题的解读**：离婚后成绩下降、发脾气、不听话，**是信号不是原因**。先问："我注意到你最近[具体变化]，发生了什么？"，而不是先纠正行为。

**不同年龄的反应差异**：学龄前多以退行（尿床、黏人）表达；学龄期多表现为学业波动、身体不适、攻击或讨好；青春期多表现为疏离、愤怒、站边。**同一件事，年龄不同，回应不同**（分龄见 `01`）。

### 1.3 被迫选边

**信号**：孩子明显紧张、回避谈论某一方、说话像在"汇报"、说"我不想说这个"。

| 对象 | 该说的一句话 |
|---|---|
| 对父母 | "我知道你夹在中间很为难。从现在开始，你不需要帮我们传话。" |
| 对父母 | "爸爸妈妈的事是爸爸妈妈的事，你只需要做孩子。" |
| 对亲子双方的约定 | 所有沟通由成人直接联系，**孩子不是信使** |
| 孩子可以说的话（教给孩子） | "我不想当传话筒，这样让我压力很大。" |

**三个不要**：❌ 让孩子传话；❌ 向孩子诉苦"你爸/你妈多差劲"；❌ 问孩子"对方有没有找新对象"。

### 1.4 重组家庭与继兄弟姐妹

**关键认知**：继兄弟姐妹之间**不需要"同等对待"**，孩子需要的是"**独特的我被看见**"。

| 常见做法 | 问题 | 替代 |
|---|---|---|
| "他/她是你弟弟妹妹，你要让着" | 用身份压需求 | 分开听各人感受，再定具体规则 |
| "我们是一家人，不许比较" | 否认真实差异（钱、时间、关注） | 承认差异，说明理由 |
| 无意识偏心（压岁钱、时间、亲生的那个） | 孩子对偏心极其敏感 | 父母先诚实面对自己的偏心 |

**可以说的话**：

> "我听到你在说[孩子觉得不公平的事]。我想知道，你的感受是什么？"
> "你是你自己，继弟弟妹妹是继弟弟妹妹。你们有不同的需要。"
> "我可能有时做得不够好。你可以告诉我，我哪里让你觉得被忽略了。"

**结构性提醒**：再婚初期（前 1-2 年）是冲突高发期，把期望值调低、把规则写清、把"每个孩子单独的时间"排进日程，比反复讲道理有效。

### 1.5 多孩家庭：竞争、偏心与手足欺凌

**先分清两件事**：

- **竞争**：互相的、双向的、能轮流占上风；
- **欺凌**：一方长期占主导，另一方不敢反抗、隐瞒、退让。

**手足欺凌最容易被忽略**，因为它常被当成"打打闹闹很正常"。长期被欺凌的一方会习得"我的感受不重要"，且这种模式会影响成年后的人际关系。

| 不要做 | 要做 |
|---|---|
| "你是哥哥姐姐，要让着" | 分开听各自感受，再一起定规则 |
| "他们只是打闹，别大惊小怪" | 检查是否长期单向、有无恐惧与隐瞒 |
| 每次冲突都当裁判、判定谁对谁错 | 教解决流程（轮流/转移/求助成人） |
| 用"公平"等于"一样" | 说明"公平是按需要，不是按一样" |

**偏心的识别与处理**：写下三个孩子的"关注时长 / 单独时间 / 被表扬次数"，一周记录一次。偏心多数是无意识的，**看见就是改变的开始**。

**一句话回应模板**：

> "我看到你们又在争。我需要先听听你们各自的感受。"

### 1.6 留守、隔代抚养与父母分离

**核心风险不是"分开"，而是"分开时没有解释、没有联系、没有稳定照顾者"。**

| 要做 | 说明 |
|---|---|
| 用孩子能懂的话解释为什么分开 | 避免"大人有事"这类模糊说法 |
| 固定频率的联系（视频/电话/写信） | **稳定**比频率高更重要 |
| 明确主要照顾者并保持规则一致 | 减少"在谁那儿一套" |
| 保留一方不在场时的"存在感" | 照片、共读一本书、共同的小仪式 |

**重逢后的重建节奏**：先恢复"关系"（一起玩、不问成绩、不提旧账），再谈"规则"，最后才谈"期待"。不要一见面就补功课。

**隔代抚养的常见冲突**：喂养方式、穿衣、纪律、屏幕时间、安全（见 `06` §5 与 `07` §4.6）。处理顺序：**安全底线 > 健康 > 习惯 > 偏好**；底线之外的差异，优先保留关系。

### 1.7 祖辈与父母养育冲突

- 祖辈不是敌人，**是用旧方法爱孩子的人**；
- 冲突的本质常是两代人对"什么是好父母"的不同定义；
- **划定边界不需要赢得祖辈的同意**，只需要坚定执行；
- 与祖辈的沟通句式："我知道你是爱孩子的。我们现在学到了一些新方法，不是因为你错了，是知识在更新。"；"在这几件事上，我们决定这样做。你可以不同意，但请尊重我们的决定。"；
- 与孩子的沟通句式："爷爷奶奶的方式和爸爸妈妈不一样。你觉得有什么不一样？不管他们怎么做，你都可以告诉我们你的感受。"；
- **不在孩子面前评价祖辈**（孩子会撕裂）。

### 1.8 收养 / 寄养 / 非血缘养育

- **身世不是禁忌**：用**适龄、渐进**的方式告诉孩子他的来历（3-6 岁用简单事实，7 岁以上可以谈更多细节），比"等他长大再说"更能建立信任；**被隐瞒后自行发现，伤害远大于早说**。
- **依恋优先于纠正行为**：早期照料中断的孩子可能表现为**过分主动亲近陌生人**或**很难被安抚**；先建立可预期的日常——固定的人、固定的节奏、离开前预告——行为问题随后再谈（`05` §1）。
- **不逼感恩**："我们养你多不容易"会把爱变成债；孩子对生父母的好奇、愤怒、想念或无所谓都是正常反应，**不贬低、不要求他表态**。
- **学校与外界的说法**：与老师提前沟通告知范围与口径，避免孩子在班级里被"惊讶式暴露"；由孩子自己决定何时、向谁讲（隐私口径见 `09` §6）。
- **需要评估的信号**：长期无法被安抚、明显退行、持续攻击或自伤、依恋行为长期异常 → `03` §3 + `09` §2。

### 1.9 多胞胎（双胞胎及多胞胎）

- **按两个人对待**：不同称呼（不用"大宝/小宝"当唯一名字）、各自的物品与衣物、每天**各有一段独属时间**（10 分钟即可）——个体化是多胞胎养育的第一原则。
- **比较是最大风险**：❌"你怎么不如哥哥"；✅ 各自与自己比——两人发展速度不同属常见现象（`01` §8.3）。
- **照护现实**：同步作息能省力，但要避免长期固定"一个总被抱、一个总在等"；喂养、睡眠、排泄各自记录（`11` §2.1）。
- **健康注意**：多胎早产与低出生体重比例高，里程碑按**矫正月龄**评估（`01` §8.3）；持续落后于矫正月龄 → 评估（`03` §3）。
- **父母疲惫是结构性问题，不是能力问题**：排班、外包部分家务、明确"谁在什么时段负责哪个孩子"（`07` §6.4、`10` §4）。

## §2 神经多样性

> **覆盖**：ADHD/注意力缺陷、自闭谱系、抽动与强迫倾向、感统差异与感统评测、残障与特殊教育需要（听障/视障/肢体/智力与发展障碍）、疑似发育差异的就医路径。

### 2.1 立场先行

**神经多样性不是"病"，是人类大脑的一种自然变异**。孩子的困难是**与环境不匹配**产生的，不是"故意不听话"或"父母没教好"。

诊断的作用是**理解需要什么支持**，不是"贴标签"。父母对"标签"的恐惧通常来自自己被贴标签的经历——这一层要放在 `07` §3 里处理。

### 2.2 父母自己的第一反应（先处理自己，再处理孩子）

| 常见本能反应 | 实际是 | 替代 |
|---|---|---|
| "我的孩子不是有问题的孩子" | 羞耻感在起作用 | "诊断说明他需要什么环境，我们一起想办法" |
| "我不想让他一辈子背这个标签" | 对标签的恐惧（常来自自身经历） | 标签可以只在家里/学校内部用于争取支持 |
| "是不是我怀孕时做错了什么" | 自责 | 现有证据指向多因素，责备自己不解决问题 |
| "他长大就好了" | 否认，会延误支持 | 观察、评估、干预越早，代价越小 |

**可以说的话**：
> "这个诊断告诉我们，他需要什么样的环境和支持。我们一起想办法。"
> 对孩子（适龄）："你的大脑和别人不太一样，这让你有独特的优势，也有独特的挑战。"

### 2.3 ADHD / 注意力缺陷

**核心事实**：ADHD 是**执行功能**（注意力调节、冲动控制、组织计划）发育差异。孩子**不是"不想做"，是真的"做不到"**。

**四个常见误解**：

| 误解 | 实际 |
|---|---|
| "他就是懒/不专心" | 注意力调节困难，不是意愿问题 |
| "打一顿就记住了" | 惩罚对执行功能缺陷基本无效，且持续损害自尊 |
| "长大自然就好了" | 部分症状会变化，但许多持续到成年 |
| "成绩好就不是 ADHD" | 高智力可部分代偿，但日常功能仍可能吃力 |

**养育策略（六条）**：

1. **分解任务**：不给长指令，一次一个步骤（"先把书包放好"）；
2. **可视化常规**：日程表/图片流程图贴出来，减少口头重复；
3. **缩短反馈回路**：做对了**立刻**反馈，奖励比惩罚有效得多；
4. **提前预告过渡**：切换活动前 5 分钟告知，用计时器；
5. **给身体出口**：每天有足够的大运动量，坐着不动对这类孩子尤其难；
6. **父母减压**：这类孩子的养育压力显著高于普通家庭（约为普通家庭的 2-3 倍），父母需要固定休息与外部支持（`07` §6.4）。

**回应孩子的核心句**：
> "你的大脑处理信息的方式和大多数人不一样。这不是你的错。"

**必须做的事**：建议专业评估（儿科/儿保/儿童精神科/心理科），评估可确诊，也有相应干预。**本包不做诊断**。

### 2.4 自闭谱系

**核心取向**：**需要的是"适配"，不是"矫正"**。

**常见误解**：不看不等于不爱；不说话不等于不理解；重复行为往往是自我调节方式；"眼神接触"不是所有文化/所有孩子都必须的训练目标。

**可落地的适配**（家庭层面）：
- 减少感官过载（噪音、强光、拥挤），提供可退避的空间；
- 提前预告变化，用视觉化方式呈现日程；
- 用**具体**语言替代隐喻、暗示、反话；
- 允许"特殊兴趣"成为入口（学习、交流都可能经此发生）；
- 理解崩溃（meltdown）与关机（shutdown）是过载反应，**不是操控**。

**对孩子的态度句**：接受他本来的样子，他才能接受自己。

**必须做的事**：专业评估（发育行为儿科/儿童精神科）+ 相关支持资源；学校层面的配合（个别化安排）。本包不提供诊断与治疗方案。

### 2.5 抽动与强迫倾向

**信号**：反复眨眼/清嗓/耸肩/做鬼脸；反复洗手、检查、排列物品、要求对称；明知不合理但停不下来。

**要点**：
- 抽动常与情绪紧张相关，**越是制止、提醒、纠正，往往越频繁**；
- 父母能做的是**减少关注与压力**，不指责、不当众指出；
- 强迫行为通常伴随焦虑，惩罚无效；
- 影响日常生活、造成痛苦、或伴随学业/社交困难 → 走专业评估（儿童精神科/心理科）。

**回应句**："我知道你不想这样，也知道你在努力。我们一起找人帮忙看看怎么让它好过一点。"

### 2.6 感统差异与感统评测

**信号**（家长通常这样描述）：对某些触觉/声音/衣物标签异常敏感或异常迟钝、动作笨拙、坐不住、平衡差、易晕车、过度寻求旋转/攀爬。

**取向**：先做**环境适配**（衣物、座位、噪音、光线），再谈训练。

> ⚠️ **本技能不做感统测评、不解读他方报告的结论、不承诺任何训练效果**。本节只做三件事：帮你判断**要不要评**、识别**谁有资质评**、说明**结果怎么用**。这里出现的术语（过度反应 / 感觉寻求等）**仅用于记录与沟通，不当作自我诊断标签**。

**① 要不要评：三条判断线**

| 档位 | 判断标准 | 该做什么 |
|---|---|---|
| 🟢 先观察 | 只在疲劳/陌生/高刺激时出现，能自己调节回来；不影响吃饭、睡觉、上学、交友 | 做 2 周观察记录 + 环境四点（见 ⑦），不急于测评 |
| 🟡 建议评 | 跨场景（家 + 园/校）持续 **≥1 个月**，且**已影响功能**：不敢穿某类衣物、上课坐不住到跟不上、拒食、回避同伴、理发或剪指甲严重困难 | 预约专业评估（儿童保健科 / 发育行为儿科 / 康复科），并带上观察记录（准备清单见 `05` §13.4） |
| 🔴 立即 | 伴随能力倒退、自伤、拒学、伤人 | 按 `09` §3 判档 + 立即就医 |

**② 评什么（评估通常看三组问题，家长可对照自己的记录）**

| 组别 | 表现举例 | 常见通道 |
|---|---|---|
| 感觉**调节** | 过度反应（怕吹风机、怕标签、怕人多）/ 反应不足（摔了不太疼、对冷热不敏感）/ 感觉寻求（转圈、撞、到处摸、跳不停） | 触觉、听觉、前庭（平衡与运动）、视觉 |
| 感觉**辨别** | 分不清轻重、方向、质地；用手摸不出形状 | 触觉、本体觉（肌肉关节位置感） |
| 感觉性**动作** | 姿势控制差、动作计划困难（系鞋带/骑车/跳绳学不会、容易摔） | 前庭 + 本体觉 |

> 家庭记录比"分数"更重要：记**触发—表现—如何恢复**（见 ⑦）。跨场景信息（家 + 园/校）是评估中最有用的一项。

**③ 谁来评（最容易被商业机构利用的一环）**

- **有资质的方向**：儿童保健科 / 发育行为儿科 / 康复科（**作业治疗师 OT**）；若需鉴别 ADHD、自闭谱系 → 儿童精神科（感统表现常与它们**重叠**，鉴别必须由医生做）。
- **常见商业化操作**：训练机构自编的"感统测评"——用器材观察或自编问卷，给出"感统失调重度/XX 项不达标"，**没有标准化常模、不属诊断依据**，其结论常直接绑课时包。
- **识别三问**（拿去问对方，答不上来就别信）：① 用的是哪个标准化工具、有没有常模？② 评估人是什么资质（有没有作业治疗师或医师资质）？③ 结论是"需要什么支持"，还是"你必须买多少课时"？

**④ 常用标准化工具（家长可能遇到的名称，仅用于核对）**

| 工具 | 形式 | 适用 | 说明 |
|---|---|---|---|
| SIPT（感觉统合与运用测验） | 一对一临床操作 | 约 4-9 岁 | 需经认证的评估者实施；国内可及性有限 |
| SPM（感觉加工量表） | 家长问卷 + 教师问卷 | 约 5-12 岁 | 两套并行，用于看家/校差异 |
| Sensory Profile（感觉剖面图） | 家长问卷 | 儿童版 | 描述感觉反应模式，常用于沟通与干预计划 |
| ITSP（婴幼儿感觉剖面图） | 家长问卷 | 0-3 岁 | 低龄版 |

> 名称只用于**识别与核对**；具体做哪一项、结果怎么解读，由评估机构判断，本技能不解读报告结论。

**⑤ 结果怎么用（三条）**

1. **用于"环境适配 + 功能目标"**：能自己穿衣服、能坐住 20 分钟、能去理发店——目标是**参与能力**，不是"治好"；
2. **跨场景信息优先于分数**：把观察记录和老师反馈一起带去（`05` §13.4）；
3. **要落到家里和幼儿园/学校**：报告要能翻译成"家里怎么做、园里怎么配合"；只给一张分数表、不给做法的报告，用不上。

**⑥ 循证立场：能承诺什么、不能承诺什么**

| 可以说 | 不能说（属过度宣传） |
|---|---|
| 以作业治疗为取向的感觉统合干预，对**感觉相关行为与活动参与**有一定支持，但证据质量有限、个体差异大 | "感统训练能**提高智商 / 提高成绩**" |
| 个体化、以游戏和真实活动为载体、家长能在家延续的方式，更值得投入 | "**N 节课治好**感统失调" |
| 环境适配与日常活动量（户外、重体力游戏）本身就是有效的一环 | "**不训练就会耽误一辈子**"——用恐惧促单 |

> 遇到上述"不能说"的话术，按 `09` §4 三步验证法核对来源。**效果承诺不是医学结论，是销售话术。**

**⑦ 不等测评，家里先做什么**

- **观察记录（连续 2 周，模板见 `11` §4）**：时间 / 场景 / 触发（声音、衣物、拥挤、被碰）/ 表现 / 大人如何处理 / 多久恢复；
- **环境四点**：衣物（剪标签、宽松、允许先试穿再洗一次）/ 座位（靠墙或靠前，减少过道刺激）/ 噪音光线（安静角、耳机、调暗）/ **活动量**（每天户外 + 重体力游戏：攀爬、推拉、搬运、蹦跳）；
- **不要做**：强迫暴露训练（把怕声音的孩子按在音响旁"脱敏"）→ 与 `05` §4.5 同一条红线；也不要因为一份机构报告就停掉孩子原本喜欢的活动。

**转介线**：明显影响日常生活、学习或社交 → 儿童保健科 / 康复科 / 发育行为儿科（`03` §3、§2.8）。评估前后家长要避开的坑见 §2.7。

### 2.7 评估前后父母要避开的坑

| ❌ 坑 | ✅ 替代 |
|---|---|
| 只评估一次就想要"全套答案" | 评估是过程，支持是长期 |
| 拿到诊断就急着找"治好"的方法 | 目标是功能改善与适配 |
| 把诊断告诉孩子时使用贬义措辞 | 用"你的大脑不一样"的中性框架 |
| 与另一方/老人隐瞒诊断 | 家庭内信息一致，孩子才不会困惑 |
| 让诊断成为家庭唯一话题 | 保留孩子的其他身份（朋友、爱好、优点） |

### 2.8 残障与特殊教育需要（听障 / 视障 / 肢体 / 智力与发展障碍）

**立场**：障碍与支持需求是同一件事的两面；目标不是"变得正常"，而是**功能改善与环境适配**（同 §2.1）。

**信号与去向（按需转介，不做判断）**

| 观察到 | 先去 |
|---|---|
| 对大声无反应、不会转头找声源、语言明显落后 | 听力筛查 → 耳鼻喉科/儿童保健科（`03` §3.1） |
| 追视差、歪头或凑很近看物、眼球震颤、畏光 | 眼科 |
| 肢体活动不对称、肌张力异常、运动明显落后 | 儿童保健科/神经科/康复科（`01` §7.3） |
| 理解与自理明显落后、学习长期困难 | 发育行为儿科评估（`03` §3.9） |

**早干预**：0-6 岁是干预效益最高的窗口（听力、语言、运动均如此）；确诊后尽快接入康复训练与教育支持，**不"等长大再看看"**。
**家长可做的四件事**：① 学龄前先攻语言与自理；② 与幼儿园/学校谈**个别化安排**（座位、作业量、辅助工具、陪读或助教支持）；③ 了解当地残联与特殊教育资源（`11` §6.6）；④ 自己不硬扛——支持需求是长期的，家长也需要固定休息（`07` §6.4）。
**对兄弟姐妹**：不把照顾责任转移给健全的孩子（避免亲职化，`07` §4.4）。
**情绪支持**：父母的悲伤、否认、愤怒都是正常过程，不需要用"正能量"盖住（`07` §5、§6）。

## §3 心理与精神健康

> **覆盖**：确诊后的家庭承接、情绪障碍信号、进食问题、拒学与学校恐惧、被诊断后的父母情绪。

⚠️ **红线**：本节任何内容出现自伤、自杀意念、或明确的精神病性症状 → **立即转 `09` §2**。

### 3.1 孩子确诊之后的家庭承接

**一句话回应**："谢谢你告诉我。我听到你了。我们会一起面对。"

| 父母常见反应 | 为什么有害 | 替代 |
|---|---|---|
| "这不可能，我们家没人有这种问题" | 否认会让孩子独自承担 | "我需要时间理解，但我在" |
| "你就是太脆弱了" | 把问题归为孩子品性 | "这不是软弱，是身体/大脑的疾病" |
| "你需要振作起来" | 把治疗责任推给孩子 | "我们一起找专业帮助" |
| 立刻制定全套康复计划 | 孩子被目标包围，更窒息 | 先稳定日常节律 |

**要点**：
- 心理健康问题**有生物学基础**，不是"想太多"，也不是教养失败的证明；
- 诊断是理解孩子的工具，不是标签；
- 治疗和干预是有效的，配合专业方案比自行摸索快得多；
- **父母自身情绪稳定是孩子康复的基础**——所以 `07` 的内容对本节同样适用。

**父母需要处理的自我情绪**（按顺序）：羞耻（"我失败了吗"）→ 自责（"我做错了什么"）→ 恐惧（"他会不会一辈子这样"）→ 接受（"这就是现在的情况"）。**这四步不用一次走完**，卡在某一步就按 `07` §2、§6 做。

### 3.2 情绪障碍的常见信号（观察用，非判断用）

| 维度 | 观察点 | 需要警惕的持续性 |
|---|---|---|
| 情绪 | 持续低落、易怒（儿童青少年常表现为易怒而非低落） | 超过 2 周 |
| 兴趣 | 对原本喜欢的事失去兴趣 | 超过 2 周 |
| 睡眠 | 入睡困难、早醒、嗜睡 | 明显偏离基线 |
| 食欲与体重 | 剧变 | 明显偏离基线 |
| 精力 | 持续疲倦、起床困难 | 影响上学 |
| 功能 | 成绩骤降、拒绝社交、拒绝上学 | 影响日常功能 |
| 躯体 | 反复头痛/腹痛但检查无异常 | 频繁 |

**判断纪律**：本包**不判断是否患病**。以上仅作为"是否需要专业评估"的参考；满足"持续 2 周以上 + 影响日常功能"两条 → 建议评估（`03` §3、`09` §3）。

### 3.3 进食问题（暴食/厌食/限制性进食）

**一句话回应**："我注意到你最近对吃东西的感觉变了。我想知道发生了什么。"

| 不要做 | 原因 |
|---|---|
| "你多吃点/少吃点！" | 把症状当意志力问题 |
| "你怎么这么不自律" | 加重羞耻，症状会转入更隐蔽 |
| "你就是想引起注意" | 把求助定义为操纵 |
| 全家盯着孩子吃饭、称重、记录 | 把冲突推到餐桌，进一步绑定症状与家庭关系 |

**要做**：
- 把关注从"吃了多少"转到"最近怎么了"（情绪、压力、人际、身体形象）；
- 说清归因："这不是你的错，也不是你意志力的问题。"
- **尽早就医**：进食障碍需要医学监测（体重、电解质、心率等），不能只靠心理沟通；
- 请专业介入时用"我陪你一起去"，而不是"你自己去"。

### 3.4 拒学 / 学校恐惧

**两种形态要分清**：

| 形态 | 特征 | 处理方向 |
|---|---|---|
| **分离焦虑型**（低龄常见） | 怕离开主要照顾者、上学前身体不适（腹痛、呕吐） | 缩短分离时长，重建安全感（`05` §4） |
| **回避型**（学龄期/青春期常见） | 怕被评判、怕被欺负、怕失败、怕社交 | 找到具体害怕的对象（某节课/某个人/某种场合） |

**处理顺序**：先找**怕的是什么**（不是先讲"必须上学"）→ 与学校沟通制定回校步骤（缩短时长/分阶段）→ 必要时专业介入。

**不要做**：❌ 用"再不去就送你回老家"威胁；❌ 长时间在家待着不做任何结构安排；❌ 反复带孩子做体检但忽视情绪层面的原因。

### 3.5 情绪被压成"正能量"（少见但重要）

**信号**：孩子从不允许自己难过、生气，一说负面情绪就自责，习惯性说"我没事"，甚至在家人悲伤时反过来安慰所有人。

**为什么值得关注**：长期压制负面情绪与躯体化、焦虑、抑郁风险相关。

**做法**：父母允许自己表达真实情绪（适龄、有度）→ 对孩子说："你可以生气，也可以难过，这些都是可以的。"→ 不要求孩子"懂事"。**反向要求孩子永远乐观，等于禁止他有情绪**（关联 `05` §11 情绪小生物）。

## §4 创伤与丧失

> **覆盖**：霸凌（含网络霸凌）、丧亲、宠物死亡、目睹家暴、父母入狱、被老师体罚、其他成人权威伤害。

⚠️ 本节涉及暴力的，若**正在发生** → 先保证安全，再处理关系（`09` §2）。

### 4.1 霸凌与欺凌

**先立三个前提**：

1. 霸凌是**权力不平衡**的持续欺压，不是"孩子间的打闹"；
2. 被霸凌的孩子最怕的不是霸凌者，是**父母的不理解和指责**；
3. 霸凌与被霸凌后抑郁、焦虑、拒学风险显著相关，需要主动干预。

**父母最该说的一句**："我听到你被欺负了。**这不是你的错。**"

| ❌ 绝对不能说的话 | 为什么 |
|---|---|
| "你怎么不还手？" | 把孩子变成责任人 |
| "为什么他们不打别人就打你？" | 暗示孩子本身有问题 |
| "你就不能忍一忍吗？" | 让孩子学会沉默 |
| "你怎么不早说？" | 指责推开了下一次求助 |

**沉默的受害者**（更需要留意）：孩子不告诉父母，通常是**怕报复**或**不相信父母会帮**，有的孩子认为是自己的错。

**发现方式**：身上不明伤痕、突然不想上学、文具/衣物频繁损坏丢失、情绪突变、回避社交、成绩骤降。

**父母可以做的五个动作**：
1. **先谢谢他说出来**："谢谢你告诉我。这需要很大的勇气。你没有做错任何事。"
2. **记录**：时间、地点、方式、涉及的人（书面记录是后续沟通的基础）；
3. **与学校沟通**：找班主任/心理老师/年级主任，要求**书面**的应对计划与跟进安排；
4. **教非暴力应对策略**：离开现场、结伴行动、找可信成人、记录（**不教"打回去"**，这通常让事情升级）；
5. **看情绪信号**：持续低落、失眠、拒学、自伤 → 按 `09` §2、§7 处理。

**不要做**：❌ 未经孩子同意直接找对方家长（可能让孩子在学校处境更糟）；❌ 让孩子自己"处理掉"；❌ 大事化小。

**网络霸凌的补充**：保留截图证据、屏蔽+举报、不让孩子独自反复查看，必要时联系平台与学校。**不鼓励孩子以同样的方式回击**。

### 4.2 丧亲

**核心原则**：**诚实、简单、重复、允许悲伤**。

**一句话回应**："爷爷/奶奶/爸爸/妈妈死了。死了意味着他不会再回来了。你可以难过，你想哭就哭。"

| ❌ 不要做 | 后果 |
|---|---|
| "他/她只是睡着了，会醒来的" | 制造睡眠恐惧（"我一睡着会不会也不醒"） |
| "不要哭了，哭也没用" | 否定悲伤，孩子学会隐藏 |
| 不让孩子参加告别仪式 | 剥夺哀悼与告别的机会 |
| 用"去旅行了/去很远的地方" | 长期困惑与期待 |

**分龄要点**：

| 年龄 | 特点 | 做法 |
|---|---|---|
| 0-3 岁 | 感受氛围变化，不懂"死亡" | 保持照顾者稳定、作息规律 |
| 3-6 岁 | 认为死亡是暂时、可逆的 | 简单、重复解释；允许反复问 |
| 6-9 岁 | 开始理解"永久"，可能好奇细节 | 具体回答，不回避，允许仪式参与 |
| 9-12 岁 | 理解死亡，可能用理性掩盖情绪 | 主动给表达渠道，不逼"谈感受" |
| 青春期 | 可能沉默、用行为表达 | 保留在场，不追问，给空间 |

**支持要点**：
- 5 岁以下需要**反复、简单**的解释；
- 孩子的哀悼常通过**游戏**表达（反复画、模拟葬礼、给逝者"写信"）；
- 需要留意的信号：持续睡眠问题、退行（变幼稚、黏人）、拒学、躯体化；
- 丧失父母对孩子是重大风险因素，**建议尽早提供专业支持**。

### 4.3 宠物死亡（第一次面对失去）

**关键认知**：宠物死亡是孩子**最安全的"死亡教育"**，也是"对所有重要关系丧失的哀悼能力"的练习。

| ❌ 不要做 | 为什么 |
|---|---|
| "只是一只仓鼠/金鱼嘛，我们再买一只" | 否定这段关系独特、不可替代 |
| "不要哭了，我们养个更好的" | 用替代品处理悲伤 |
| 偷偷把死去的宠物处理掉 | 孩子会长期困惑与内疚 |

**要做**：
1. **不急于修复**：悲伤需要时间；
2. **邀请参与告别仪式**：挖坑、放照片、说再见——仪式帮孩子完成心理告别；
3. **允许反复回忆**：孩子反复讲宠物的故事，是正常哀悼；
4. **不撒谎**：不说"去旅行了"；
5. **看后续信号**：情绪低落、退行、睡眠问题**持续一个月以上** → 考虑专业帮助。

**可以问的一句**："你和[宠物名字]在一起的那些日子，什么让你最开心？"

**延伸用法**（后续谈家人死亡时）："还记得[宠物名字]走的时候吗？我们也是这样怀念[逝者]，因为他/她对我们很重要。"

### 4.4 目睹家庭暴力

**关键事实**：**目睹 ≠ 没有影响**。在暴力环境中长大的孩子，即使没有被直接打，其神经生物学层面的影响与直接受虐的孩子**相似**——这是**继发性创伤**。

**孩子的常见表现**：异常平静（被误认为"不懂"）、警觉、讨好、过度照顾父母、躯体化、攻击或极度退缩、亲职化（为保护父母而压抑自己的恐惧）。

| 不要做 | 要做 |
|---|---|
| "大人的事跟你没关系" | 适龄承认："爸爸/妈妈吵架了，这不是你的错。" |
| 当着孩子继续争吵/摔东西 | 任何形式的当着孩子冲突都让孩子承受威胁感 |
| 以为孩子"睡熟了听不懂" | 听觉与身体感受不因睡着而停止 |
| 用"我们和好了"一句带过 | 孩子会反复观察气氛，需要一个明确的安全说明 |

**四步行动**：
1. **先保证当下安全**（孩子 + 受暴方的安全优先于关系修复）；
2. **停止当着孩子争吵**（包括冷战争吵的气氛性冲突）；
3. **适龄解释**："我们在学习怎么更好地处理问题。"＋"这不是你的错。"
4. **寻求专业支持**：家暴不是家庭内部事务，需要外部资源介入。

**如果暴力仍在持续**：首要任务是**安全计划**，不是关系修复，也不是"为了孩子忍一忍"。

### 4.5 父母入狱 / 长期被监禁

**核心原则**：孩子不需要知道所有细节，但需要**诚实的、适龄的解释**和**保持联结的方式**。

**可以说的**："我在这里是因为我做了一个错误的选择，但这不是你的错。我爱你，不管我在哪里，我都想着你。"

| ❌ 不要做 | 为什么 |
|---|---|
| "等你长大就懂了" | 孩子会用想象填补空白，通常更糟 |
| "不要告诉任何人" | 传递羞耻，让孩子承担保密的重负 |
| 不让孩子探望/联系 | 剥夺保持联结的机会 |

**照顾者（祖辈/亲戚）要做的**：
- 不在孩子面前批评在狱中的父母；
- 允许孩子表达愤怒、悲伤、困惑（不要求"懂事"）；
- 维持与父母的联结（写信、电话、探视、照片）；
- 保持学校生活与作息的稳定，减少"生活被翻天覆地"的部分。

**风险提示**：父母入狱对孩子是**多重打击**（经济、主要照顾者分离、社会污名），孩子可能出现内化（"是我不好他才离开"）→ 主动澄清归因、必要时寻求心理支持。

### 4.6 被老师体罚 / 成人权威伤害

**核心张力**：**护子本能 vs 理性判断**（也 vs 现实顾虑：得罪老师会不会让孩子被针对）。

**处理原则**：

1. **先共情孩子的感受**："当着全班的面被罚站，一定很不好受吧。"（共情≠立刻判定谁对谁错）
2. **温和收集具体信息**：发生了什么、打在哪里、还有谁被罚——为了判断完整事实，不是审问；
3. **判断严重程度**：
   - 轻微（一次罚站、口头批评）→ 优先校内私下沟通；
   - 中度（反复罚站、当众羞辱、多次动手）→ 正式向学校反映；
   - 严重（持续身体伤害）→ 留存证据（照片、就医记录、书面陈述），必要时向教育主管部门反映或报警；
4. **与学校沟通的姿势**：以"了解情况"开场，以"共同帮助孩子"为目标，不攻击、不指责；
5. **不让孩子当传话筒**——你有话自己说，孩子在家庭与学校之间做调解人会严重消耗他。

**法律背景（中国）**：《义务教育法》《未成年人保护法》明确禁止体罚和变相体罚。**但"法律上不对"和"现实中怎么处理"是两件事**，需要为孩子保留在校生活的可行路径（这也是家长最纠结的部分）。

### 4.7 创伤后的通用支持原则

| 原则 | 说明 |
|---|---|
| **先安全，后感受，最后才谈道理** | 顺序反了，任何处理都无效 |
| **恢复节律** | 睡眠、吃饭、上学的可预测性本身就是治疗 |
| **不逼叙述** | 不用"把事情经过说清楚"；允许孩子不说 |
| **不追问细节**（尤其对年幼孩子） | 反复追问可能加重侵入性记忆 |
| **恢复控制感** | 给选择："你想先做哪个？" |
| **避免二次伤害** | 不当众讲述孩子的遭遇、不把孩子的故事对外传播（关联 `07` 场景 75 公开叙事问题） |
| **家长先稳住** | 成年人的稳定是最好的安抚（`07` §2、§6） |
| **何时找专业** | 症状持续 2 周以上、影响日常功能、出现自伤或拒学 → `09` §3、§7 |

## §5 成瘾与屏幕

> **覆盖**：屏幕时间与内容、网络/游戏成瘾、短视频与社交媒体、网络小说/二次元沉迷、父母自身的手机依赖。

### 5.1 立场先行

> **屏幕不是问题的根源——问题是屏幕替代了什么。**

如果屏幕替代了陪伴、户外活动和面对面互动，那是问题；如果是有引导、有节制的使用，通常无害。父母自己对手机的依赖和孩子对屏幕的依赖，**是同一棵树上的两个枝杈**。

### 5.2 屏幕时间参考（按年龄）

| 年龄 | 建议 |
|---|---|
| 0-2 岁 | 不建议屏幕时间（视频通话除外） |
| 2-5 岁 | 每天 ≤ 1 小时高质量内容，且需有成人参与 |
| 6 岁以上 | 屏幕时间不应替代睡眠、身体活动和社交 |
| 关键判断 | **不是时长，而是内容质量与替代活动是否存在** |

**作息底线（比时长更硬）**：
- 睡前一小时无屏幕（含家长手机）；
- 吃饭时无屏幕；
- 卧室不放置个人设备（学龄期以上）。

### 5.3 游戏/网络沉迷

**背后的机制**：游戏提供了现实里缺的三样东西——**即时反馈、成就感、社群归属**。所以真正要问的不是"怎么让他停下来"，而是"**他为什么宁愿待在游戏里**"。

| ❌ 常见做法 | 后果 |
|---|---|
| "你怎么这么没出息，就知道玩游戏" | 把孩子与游戏绑得更紧（游戏是唯一不否定他的地方） |
| 直接没收/断网 | 崩溃→对抗→妥协→循环加固 |
| "你再这样这辈子就完了" | 恐吓无效，破坏关系 |

**替代做法**：
1. **先了解**：他在玩什么、和谁玩、哪一点最吸引（不了解就批评，等于自动出局）；
2. **可能的话一起玩**（这是理解孩子的入口）；
3. **在现实里造"成就感"**：找一件他能胜任、能被看见的事；
4. **共同定规则**，而不是单方面宣布；规则要写下来、包含"做到后的正向结果"；
5. **边界靠流程维持，不靠惩罚**（固定时段、计时器、设备存放位置）。

**一句话开场**："我注意到你最近花在游戏上的时间很多。我想知道，游戏里有什么让你觉得特别吸引？"

**什么时候需要专业介入**：出现明显功能损害（不上学、不睡、不社交）、停止后出现强烈戒断反应、伴随抑郁/焦虑/自伤 → `09` §3、§7。

### 5.4 短视频、社交媒体与网络小说/二次元

| 形态 | 主要机制 | 家庭重点 |
|---|---|---|
| 短视频 | 高频刺激、被动接收、难以自停 | 结构化管理（无手机时段/地点）＋替代活动 |
| 社交媒体 | 社会比较、被排斥的风险、夜间使用破坏睡眠 | 关注"看到什么"而非"看了多久"；睡眠保护优先 |
| 网络小说/二次元 | 强烈的情感沉浸与身份认同 | **不贬低其内容**（贬低=否定孩子的世界），从"你最喜欢哪个角色"进入对话 |

**共同原则**：
- **睡眠优先**：夜间使用是影响最大的单一变量；
- **替代优先**：先给一个更好的现实选项，再谈减少；
- **不搞突然清零**：断崖式切断会引发强烈对抗；
- **父母示范**：家长自己刷手机的状态，是孩子最直接的教材。

### 5.5 父母手机成瘾与"被留守"的孩子

**信号**：在家时各自看手机；孩子说"你在看手机没听我说话"；明明一家人都在一起，孩子却感到孤独。

**"有父母却像留守儿童"比真正的留守更隐蔽**，也更让孩子困惑。

**三个不要**：❌ "我这不是陪着你吗"；❌ "我一天忙到晚，回来刷会儿怎么了"；❌ 一边刷手机一边说"我在陪你"。

**可以做的**：
1. 回家后手机放到**固定位置**（不是没收，是"入场"）；
2. 每天至少 **15 分钟全心陪伴**（不看手机、不处理事务）；
3. **诚实承认**："我最近压力大，有时会用手机躲一下。这不是你的错。"（承认本身就在示范诚实）

**开场句**："我注意到我们在家时各自看手机。这种感觉可能不太对。"

## §6 身份与文化议题

> **覆盖**：多元文化/多语言家庭、移民与流动、性别身份认同的初步接纳、社会性焦虑议题。

### 6.1 多语言 / 多元文化家庭的身份困惑

**核心**：**身份探索是正常的，不是"背叛"。** 孩子需要空间整合多元身份，而不是被迫选边。

| ❌ 不要做 | 原因 |
|---|---|
| "你是×国人，就必须会说×语" | 把语言变成忠诚测试 |
| "你怎么连自己是谁都不知道" | 否定探索的正当性 |
| 强迫参加文化活动 | 把认同变成任务 |

**要说的话**：
> "我知道这对你来说可能很复杂——你有两个世界的部分。"
> "你觉得你是哪里人？你怎么看待自己的身份？"
> "不管你选择什么，你都是我的孩子。"

**关键认知**：多元身份**不需要"选边站"**；父母能给的是"选择的自由"，不是"强制的认同"。语言可以既保留又并存，不需要以牺牲一种为代价。

### 6.2 孩子是 LGBTQ+ / 性取向与性别认同

**核心事实**：

- 性取向与性别认同**不是选择**，不需要被"治好"；
- LGBTQ+ 青少年最大的心理健康风险来自**歧视与缺乏家庭支持**，不是身份本身；
- **家庭接纳是最强的保护因素**。

**父母的第一句话至关重要**：

> "谢谢你告诉我。我可能需要一些时间来消化，但我需要你知道：**你是我的孩子，我爱你。**"

| ❌ 不要做 | 为什么 |
|---|---|
| "你只是还没遇到对的人" | 否定他的自我认知 |
| "这个社会会怎么看你" | 把恐惧转成他的负担 |
| "是不是我们哪里做错了" | 把议题变成父母的自责 |
| 强行"矫正"、限制社交、找人说教 | 显著提升风险（抑郁、自伤、离家） |

**可以做**：
- 承认自己需要时间（诚实比假装接受更可持续）；
- 区分"我在担心什么"（社会的确存在歧视）和"我需要做什么"（我能不能成为他的安全基地）；
- 主动学习，问需要："我想了解你的感受，不只是你的身份标签。""我能做点什么让你好过一点？"
- 需要时对接支持资源（家长支持社群、专业咨询）。

**安全边界**：如果孩子因身份遭遇霸凌、被威胁或出现自伤/自杀意念 → 立即按 `09` §2 处理。

### 6.3 移民、流动与身份焦虑（补充）

- 常见的三重压力：语言、归属、代际文化冲突；
- 家庭做法：**不把"融入"与"保留"对立**，允许双重身份并存；
- 父母的语言能力不足时，**不让孩子长期充当翻译**（尤其涉及医疗、法律、财务等成人事务——这会形成亲职化，见 `07` §4.4）。

### 6.4 社会性焦虑议题（气候、公共卫生事件、社交媒体环境）

**特征**：孩子对世界性风险产生持续不安（极端天气、疾病、战争新闻、社会事件），伴随睡眠问题、注意力下降、反复确认安全。

**处理原则**：
1. **不否认**（"你想多了"会让孩子独自消化）；
2. **不放大**（成人式的全面分析会压垮孩子）；
3. **给可控感**：把注意力从"世界会怎样"转到"我们家能做什么"（一次具体的小行动）；
4. **限制暴露量**：控制新闻/短视频的接触，尤其是睡前；
5. **恢复节律**：睡眠、运动、同伴相处是最基础的稳定器。

**回应句**："你担心这件事，说明你在认真想它。我们可以一起看看，我们家现在能做什么。"

## §7 性教育

> **覆盖**：身体认知与命名、隐私与身体自主权、分龄性教育、青春期身体变化、早恋与亲密关系、网络色情与性安全。

### 7.1 立场先行

**性教育从出生就开始了**——通过身体部位的命名、抚触的方式、孩子提问时成人的反应。

**核心一句**："**你的身体是你自己的。**"

**关键事实**：回避与羞耻会让孩子觉得"这是不对的"，长期可能影响成年后的亲密关系；孩子对身体的好奇是**健康的发展过程**。

### 7.2 分龄内容表

| 年龄 | 主要议题 | 关键做法 |
|---|---|---|
| 0-3 岁 | 身体部位的正确命名、身体界限 | 用正式名称，不代称；洗澡、换衣时教"隐私" |
| 3-6 岁 | "我从哪里来"、男女差异、隐私概念 | 简单、真实、适龄；用绘本；不回避 |
| 6-9 岁 | 生育常识、身体安全（谁可以碰/不可以碰）、拒绝 | 明确"任何人都不能碰你的隐私部位"；教"说不+告诉大人" |
| 9-12 岁 | 青春期变化（月经、遗精、身体发育）、情感萌动 | 提前讲（不要等身体变化了才说，那会伴随羞耻与恐慌） |
| 12-18 岁 | 亲密关系、同意（consent）、避孕与性病常识、网络色情辨别 | 讲原则不讲恐吓；保持可谈的通道；尊重隐私 |

### 7.3 高频提问的标准应对

| 孩子的问 | ❌ 不要答 | ✅ 可以答 |
|---|---|---|
| "我从哪里来的" | "垃圾堆里捡的""长大就知道了" | 按年龄：小一点讲"从妈妈肚子里长出来的"；大一点讲基本生殖常识 |
| "性爱是什么" | 惊慌、回避、训斥 | 诚实但简洁："这是成年人相爱时会做的事，是很私人的事。你还不用做，但你想知道可以问我。" |
| 探索自己的身体（幼儿） | "不许摸！羞不羞" | 平静地："这是隐私部位，可以在自己的房间做，不在公共场合。" |
| "同学说××是同性恋" | "别跟这种人玩" | "喜欢谁是他的事，不因此判断一个人好坏。" |

**核心纪律**：回答的**情绪**比内容更重要——你的镇定本身就是教育；反过来，你的惊慌，也会被孩子完整接收。

### 7.4 身体安全（必须讲清的三条）

1. **隐私部位**：泳衣覆盖的部位，任何人（包括熟人、亲戚、老师、长辈）都不能随意碰；
2. **可以说"不"**：对任何让自己不舒服的身体接触，都可以拒绝，即使对方是大人；
3. **必须告诉大人**：无论谁要求"保密"，都不算数——**遇到"要保密"的要求，一定要告诉爸爸妈妈**。

**⚠️ 如果孩子已经说出被侵犯/被触碰的经历**：
- **不说"你怎么不早说""是不是你做了什么"**；
- 先相信、先安抚、**保存证据**（衣物、聊天记录、及时就医）；
- **立即报警（110）并寻求专业支持**，不要自行与对方交涉；
- 这不是孩子需要"保密"的事 → 走 `09` §2。

### 7.5 青春期早恋与亲密关系

- 早恋本身**不是问题**，关键在**关系质量与安全边界**；
- 不查手机、不全盘监控（侵犯隐私会切断沟通渠道，孩子转入地下更难保护）；
- 谈的原则：尊重＋边界＋安全＋同意；
- 话术方向：先开放（"你愿意跟我讲讲他/她吗"），再谈边界，不下禁令；
- 涉及性行为风险、网络性引诱、性勒索 → `09` §2、§7。

### 7.6 网络色情与性安全

- **不装作不存在**：孩子几乎必然会接触到，提前准备比事后惊慌有用；
- 重点是**批判性理解**：色情内容不等于真实亲密关系（无同意、无避孕、无情感）；
- 不谈"羞耻"，谈"分辨"；
- 遇到性引诱、裸照威胁、性勒索 → **保留证据、立即告知父母、必要时报警**（这类事件中孩子是受害者，先保护、后处理）。

## §8 其他特殊议题

> 以下议题在家庭中同样常见，处理原则与上文各节共用，这里只给**定位与要点**。

| 议题 | 关键点 | 交叉指向 |
|---|---|---|
| **寄宿 / 留学 / 异地就学** | 分离是有代价的：先重建关系（一起玩、不问成绩），再谈规则与期待；固定联系频率；留意"报喜不报忧" | `07` §4.3、`09` §3 |
| **父母工作分离 / 长期异地** | 学龄前优先保证**主要照顾者稳定**；联系节奏比时长重要；避免用物质替代陪伴 | `10` §3（爸爸参与） |
| **网络小说 / 二次元 / 虚拟角色沉迷** | 不贬低其世界（等于否定孩子）；从角色与情节进入对话；睡眠与社交功能作为底线 | §5.4 |
| **AI 聊天机器人情感依赖** | 先理解它满足了什么（被听见、不评判）；不粗暴禁用；同时提供现实中"会被听见"的经验；讲清"AI 会编、会迎合" | §5、`06` §1 |
| **孩子拒学（学校恐惧症）** | 先找"怕的是什么"，不先讲"必须去"；与学校分阶段回校 | §3.4 |
| **过分完美主义 / "我不能失败"** | 回避挑战比失败危害更大；表扬过程而非结果 | `05` §7、§8 |
| **被过度保护（"他什么都不会"）** | 逐步放权，从低风险任务开始；允许犯错 | `05` §8 |
| **父母心理控制（"我是为你好"）** | 把"为你好"换成"我那一刻想要的是什么"；孩子的选择权要保留 | `07` §5 |
| **父母自身未被评估的学习障碍** | 父母读写/计算/组织困难会直接影响辅导方式；不是"不关心孩子"，是没被识别；建议成人评估 | `07` §7.5 |
| **父母公开讲述孩子的故事** | 孩子的隐私不是素材；公开前需征得同意（尤其涉及疾病、创伤、成绩） | `09` §6 |
