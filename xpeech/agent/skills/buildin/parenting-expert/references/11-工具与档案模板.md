> **加载时机**：家长要的是"给我个表/帮我记/帮我建个档"而不是"告诉我该怎么办"——"帮孩子建个成长档案""记录今天吃了什么睡了多久""有没有生长曲线模板""我想测一下自己是什么教养风格""我想记录一下情绪""上次说的那个修复对话怎么说的""推荐几本育儿书"。也适用于家长上传体检报告/化验单要求存档解析、或上传记了一半的记录要求接着记。

## 使用须知（三条硬规则）

1. **先问用途，再给模板**。家长说"想记录"时，先确认是**要长期留档**（→ 建档）还是**临时记一周看看**（→ 给一张表就够）。上来给一整套目录，家长不会用。
2. **记录服务于观察，不服务于完美**。字段能删就删，宁可每天记 3 项，不要一周后放弃。
3. **写入前确认，写入后报路径**。任何模板拿去留档前，先问"要不要存下来"；存了要告诉家长存在哪、叫什么名字。

## §1 孩子档案

### 1.1 档案是干什么用的

**一句话**：档案是把"孩子的数据 + 家庭用过的方法 + 家长自己的模式"沉淀下来，让下一次判断不用从头问起。

三类用途：
- **纵向对比**：身高体重、里程碑、症状反复——单点是数字，连起来才是趋势；
- **就医准备**：医生最需要的是时间线（参见 `09` §1.3 就诊前记录模板）；
- **自我觉察**：养育反思记录的是父母的反应模式，与 `07` 配套使用。

**三条纪律**：
- 只记录、不评价（写"坐不住 5 分钟"，不写"专注力差"）；
- 追加、不覆盖（新数据加一行，旧结论不删）；
- 时效有期（超过时效的数据先与家长确认再用，见 §1.8）。

### 1.2 首次建档（4 轮渐进采集）

**不要一次问 20 个问题**。按下面 4 轮推进，每轮拿到回复再问下一轮；家长已给过的信息直接跳过；**缺信息也能先建骨架**，标注"待补充"，不要卡在建档前面。

| 轮次 | 问什么 | 为什么先问这个 |
|---|---|---|
| **第 1 轮 · 基础身份** | 姓名/昵称、出生日期、性别、出生情况（足月/早产几周、出生体重身长、分娩方式） | 决定后续所有月龄判断的基准 |
| **第 2 轮 · 当前身体与健康** | 最近一次身高体重头围（含测量日期）、过敏史、慢性病、手术史、当前用药、既往重大疾病 | 决定建议的基线，也是就医时的必填项 |
| **第 3 轮 · 发育与疫苗** | 抬头/翻身/独坐/爬行/扶站/独走时间、第一次有意义的词、疫苗接种进度 | 与 `01` §7 里程碑对照使用 |
| **第 4 轮 · 家长关心的重点** | 目前最想解决的问题 1-2 个、家庭结构、主要照护人 | 决定档案接下来往哪个方向长 |

**档案目录结构（建议）**

```
{孩子名}/
├── README.md                ← 档案索引（§1.4）
├── 基础档案.md              ← §1.3
├── 孩子画像.md              ← §1.6（培养视角，可选）
├── 日常记录/YYYY-MM-DD.md    ← §2.1
├── 成长记录/生长曲线.md      ← §1.5
├── 健康记录/               ← §2.2（症状、疾病）
├── 体检报告/               ← §2.4
├── 疫苗记录/疫苗接种表.md    ← §2.3
├── 行为心理/               ← §4 追踪结果、观察记录
```

**关键信息合理性校验（写入与读取时都执行）**：
- **出生日期**：早于当天（不可"未来出生"）、晚于 1970 年、推算月龄 ≤ 72 月——异常时**温和请家长确认**（"出生日期似乎有误，能帮我确认一下吗？"），**不输出任何基于错误日期的建议**；
- **早产周数**：1-20 周范围，超出 → 请家长确认；
- **喂养方式**：母乳/配方奶/混合/未知四值之外 → 记"未知"，下轮再问；
- 多孩家庭：每个孩子独立建档，对话中指定"现在问的是哪个孩子"，不做跨孩推断。
- **档案文件损坏/无法读取**：如实告知家长"档案读取失败，无法确认历史信息"，**不基于读取不到或残缺的数据下任何结论**；请家长确认是否重建（按 §1.2 重新采集，旧文件内容家长可自行查看 salvage），不让调试成本落在家长身上——给出明确的下一步（重建/跳过档案直接按通用口径回答并注明信息受限）。

### 1.7 档案更新（增量写入，不重写）

| 触发 | 动作 |
|---|---|
| 有新测量数据 | 追加一行到 `生长曲线.md` |

### 1.8 数据时效（写入与读取都适用）

| 数据 | 建议有效期 | 过期怎么办 |
|---|---|---|
| 身高体重头围 | 3 个月（0-1 岁 1 个月） | 先与家长确认最新数据再判断 |
| 疫苗记录 | 长期有效（只增不改） | — |
| 过敏史 | 长期，但标注确认日期 | 用前确认是否变化 |

## §3 评估工具

> ⚠️ **总边界**：本节所有量表都是**自省与自评工具**，不是诊断工具，**不能**用来给孩子贴标签、下结论。测出问题不是"确诊"，而是"提示该找谁"。任何异常结果 → `09` §3 风险分级 + `09` §7 转介。

### 3.1 父母觉醒自评表（5 级，看自己在哪一级）

**用法**：勾选符合的句子 → 找到自己当前所处等级 → 只做该等级对应的"建议重点"。**不要跳级**。

| 等级 | 自查项 | 建议重点 |
|---|---|---|
| **L1 无觉察** | □ 我主要用奖惩来管教孩子　□ 我认为孩子的"问题"是他自己的问题 | 先从"感受"开始——注意自己什么时候会发火 |
| **L2 觉察开始** | □ 我意识到自己的反应有时过度　□ 我有时会想"我小时候也是这样被对待的" | 从反思日记开始——记录自己的情绪触发点 |
| **L3 有意识（有暂停）** | □ 我能在发火前感觉到身体信号　□ 我有时会说"等一下，让我冷静一下" | 练习"暂停"——愤怒按停术（§5.1），6 秒空间 |
| **L4 反思行动** | □ 我会为自己的失控道歉　□ 我会和孩子讨论我的感受 | 坚持道歉——每次失控后修复（§5.2），修复即成长 |
| **L5 整合连接** | □ 我理解自己的模式来自哪里（代际传递）　□ 我能在孩子面前承认自己的脆弱　□ 我开始用"慈悲是体"来指导我和孩子的互动 | 走向"慈悲是体"——从理解自己到理解孩子 |

> **重要**：等级**不是分数**，不是越高越"好父母"。它只是提示"下一步往哪走"。等级低不代表失职，只代表还没开始。

### 3.2 父母教养风格 20 题自评（四种类型）

#### A 组

| 编号 | 题目 |
|---|---|
| a1 | 我认为孩子应该完全服从父母的决定 |
| a2 | 我不解释为什么制定规则，孩子遵守就是了 |
| a3 | 当孩子不听话时，我会用惩罚而不是沟通 |
| a4 | 我认为严格管教是爱孩子的表现 |
| a5 | 我不允许孩子质疑我的决定 |

#### B 组

| 编号 | 题目 |
|---|---|
| b1 | 我会解释制定规则的原因，并倾听孩子的想法 |
| b2 | 我对孩子有明确的期望，但也会考虑他们的意见 |
| b3 | 我会在坚定原则的同时，表达对孩子的关爱 |

| b5 | 我鼓励孩子独立思考，同时设定清晰的界限 |

#### C 组

| 编号 | 题目 |
|---|---|
| c1 | 我尽量避免与孩子发生冲突 |

| 编号 | 题目 |
|---|---|
| d1 | 我经常忙于工作，没有时间陪伴孩子 |

#### 四种风格对照与解读

| 组别 | 类型 | 特征 | 得分最高时的问题 | 建议 |
|---|---|---|---|---|
| A | **专制型** | 高要求、低回应；服从为上，惩罚多于沟通 | 权威型倾向不足 | 增加沟通，解释规则原因，尊重孩子想法 |
| B | **权威型** | 高要求、高回应；有规则、有温度 | ——（最理想） | 继续保持，有规则、有回应 |
| C | **溺爱型** | 低要求、高回应；回避冲突与界限 | 界限不足 | 适当设立明确规则和界限，帮助孩子建立规则感 |
| D | **忽视型** | 低要求、低回应；缺乏陪伴与关注 | 投入不足 | 增加陪伴时间，关注孩子的情感需求 |

> **亲子关系体检 8 条（不需要量表，家长自己过一遍）**
> ① 他会**主动**来找你说事（不只找另一个人）；② 他说真话不怕你——犯错时先想告诉你，而不是先隐瞒；③ 冲突后**能恢复**（一般 24 小时内回到正常互动）；④ 他敢在你面前哭、在你面前生气；⑤ 他会主动把朋友、作品、新发现拿给你看；⑥ 他求助时找得到你（而你不追问到底）；⑦ 他不必照顾你的情绪（`07` §4.4、§4.8）；⑧ 你不在时他会想起你，而不只是找你解决事情。

## §4 情绪与行为追踪

### 4.1 每日情绪打卡（家长版，10 秒）

家长每天给自己打一个分 + 一个词。**这是给家长的，不是给孩子的**（孩子的情绪见 `05` §2、§11）。

| 日期 | 情绪分数(1-10) | 情绪词 | 触发事件 | 我对孩子做了什么 |
|---|---|---|---|---|
| | | 安心/期待/疲惫/焦虑/感动/手忙脚乱/成就感 | | |

**用法**：看**7 天趋势**，不看单天。连续 7 天 ≤ 3 分 → 转 `07` §2、§5；出现"想打孩子""不如死了算了"这类念头 → **立即走 `09` §2**。

### 4.2 沟通模式诊断（回看一段对话，找模式）

把最近一次冲突的对话按"谁说了什么"逐条记下来，逐条标注属于下面哪种模式，最后算健康度。

**四种负面模式（要减的）**

| 模式 | 严重度 | 典型话术 |
|---|---|---|
| 批评 | ⭐⭐⭐ | "你总是…""你从来不…""你怎么又…" |
| 轻蔑 | ⭐⭐⭐⭐ | "真笨""没出息""像谁""服了" |
| 防御 | ⭐⭐ | "那是因为…""我又没…""那不是我的错" |
| 冷战 | ⭐⭐⭐ | "随便""嗯""哦""行吧""知道了" |

**四种正面模式（要加的）**

| 模式 | 权重 | 典型话术 |
|---|---|---|
| 共情 | 高 | "我理解你的感受""我知道你很难过" |
| 肯定 | 低 | "你说得有道理""我听到了" |
| 解决问题 | 高 | "我们一起想想""有什么办法""你觉得怎么做好" |
| 柔和开场 | 低 | "我想和你聊聊""我有个想法""我们可以谈谈吗" |

**健康度 = 正面得分 ÷（正面得分 + 负面得分）× 100%**

| 健康度 | 评价 | 建议 |
|---|---|---|
| ≥ 80% | 优秀 | 继续保持 |
| 60%-79% | 良好 | 可继续改进 |
| 40%-59% | 需关注 | 需要关注并改进沟通方式 |
| < 40% | 危险 | 建议系统学习非暴力沟通（书单见 `06` §1、§6.1） |

> ⚠️ **轻蔑（contempt）出现即优先处理**：它是所有模式里破坏力最强的一种，也是"孩子内化'我不够好'"的主要来源。看到轻蔑话术 → 转 `05` §7（羞耻感与自我价值）+ `07` §4。
> **边界**：本工具是自查镜，**不是给孩子的评分**，也不要拿去给伴侣"算账"——要做也先做自己的那一列。

### 4.3 行为 ABC 记录表（想知道"这行为为什么反复出现"时用）

| 日期/时间 | A 前因（发生前发生了什么） | B 行为（具体做了什么，客观描述） | C 结果（大人怎么反应、孩子得到什么） | 下次可换的做法 |
|---|---|---|---|---|
| | | | | |

**用法**：连续记 5-7 次同类行为，看 A 与 C 的模式。多数"反复出现的行为"，都能在 C 里找到"它为什么有效"。**记录的是行为，不是人品。**

### 4.4 习惯打卡表（21 天）

```
习惯：<名称>        目标周期：21 天
微步骤：1)< >  2)< >  3)< >
打卡：□1 □2 □3 … □21      （完成打 √；中断从微步骤重来）
奖励：连续 7 天 → <小奖励，非物质优先>
```

示例：自主入睡 = 洗澡 → 绘本 → 关灯说晚安，连续 21 天。

> 规则详见 `10` §4.4；奖励机制详见 `10` §2.6。**中断不等于失败**，回到第一步即可。

### 4.5 追踪的三条判断纪律

1. **看趋势不看单天**：睡眠、如厕、情绪、习惯都会反弹，判断依据是 7 天趋势。
2. **一次只追一件事**：同时追 5 个指标，最后一个都看不出结论。
3. **异常升级路径**：行为突变/持续 2 周以上影响生活 → `03` §3、`08` §2；出现自伤、拒学、社交退缩 → `09` §3；危机 → `09` §2。

## §5 互动工具

> 本节是"当场能用"的工具：情绪上头时怎么停下来、吼完怎么补、练哪句话、往哪儿看。**方法全是给家长的，不给孩子的。**

### 5.1 愤怒按停术（情绪上头时的 6 秒干预）

**为什么"下次忍住"没用**：情绪激动时，杏仁核（生存脑）立即激活战斗/逃跑反应，前额叶（思考脑）被压制，需要 **6-20 秒**才能接管；去甲肾上腺素与皮质醇进一步阻碍理性思考。**此时的行为由杏仁核控制，不是"意志力"能解决的。**

**第一步 · 感知触发（身体扫描）**

| 信号类型 | 具体表现 |
|---|---|
| 呼吸 | 变浅、变快，胸闷 |
| 肌肉 | 握拳、咬牙、肩膀紧绷 |
| 声音 | 提高、变硬、语速加快 |
| 思维 | "他总是…""我忍不了" |

识别到任一信号 → 立即进入第二步。

**第二步 · 生理中断（STOP）**

1. **S - Stop**：停止说话（尤其批评、威胁、质问）；停止行动（尤其伸手、推开、打）；物理性停下——站定、坐稳、不走动。
2. **T - Take breath**：腹式呼吸，**吸气 4 秒 → 屏住 2 秒 → 呼气 6 秒，做 3 次**。目标是让心率从 140+ 降到 100 以下。
3. **O - Observe**：我的身体有什么感觉？我的情绪到底是什么（不只是"生气"，可能是"害怕""委屈""无力"）？触发它的真正原因是什么？
4. **P - Proceed mindfully**：选择**回应**而不是**反应**——孩子这个行为背后的需求是什么？我想让这次互动教会他什么？

**第三步 · 重新连接**（已经吼了时）

1. 先等自己冷静（**不要**在情绪高峰时说话）；
2. 走到孩子身边；
3. 说："妈妈/爸爸刚才发火了，那是我自己的问题，不是你的错。"
4. 道歉（如有需要，用 §5.2 的完整四步）；
5. 重新设立规则（先连接，后规则）。

**紧急卡片（可打印贴冰箱）**

```
【愤怒来临前的身体信号】
□ 呼吸变浅/变快    □ 说话声音提高    □ 手握拳/身体紧绷

【立即做】（6 秒内）
1. 停下——不说话，不行动
2. 呼吸——腹式，3 次
3. 扫描——我感受到什么？

【然后问】
- 孩子真正需要的是什么？
- 我想让这次互动教会孩子什么？
```

**备选物理断点**（有人更管用）：**停下来 → 冷水冲手 10 秒 → 退后一步 → 再说话**。不是深呼吸，是给身体一个物理断点。

### 5.2 修复对话（REPAIR 六步，吼完/打完之后）

> **核心依据**："依恋不是从不犯错，而是在犯错后修复。"（Tronick 相互调节模型）"静止脸"实验发现：母亲短暂中断互动后重新连接，婴儿的皮质醇不仅恢复，还产生了更强的调节能力。**修复 = 成长的机会。**

> 与 `05` §10（四步修复法）、`07` §6.1 为同一修复原则：日常修复用 `05` §10 四步即可；冲突反复、情绪卡壳或需要完整场景话术时，用本节六步展开版。

**先纠正四个常见误解**

| 常见误解 | 事实 |
|---|---|
| "好父母不应该失控" | 所有父母都会失控，关键是失控后做什么 |
| "道歉会削弱权威" | 道歉恰恰教会孩子：认错是力量，不是软弱 |
| "孩子会忘的" | 孩子记住的不是事件本身，是事件后是否有修复 |
| "说'对不起'就够了" | 修复需要完整的步骤，不只是道歉 |

**六步法（顺序不可颠倒）**

| 步骤 | 做什么 | 说什么（可直接照说） |
|---|---|---|
| **R** Recognize 识别 | **对自己说**（内心）：我刚才失控了；我的反应超出了孩子行为的严重程度；我的杏仁核被激活了，这不是孩子的错。**不要跳过这一步** | —— |
| **E** Express responsibility 担责 | 明确"这是我的问题" | "妈妈/爸爸刚才对你发火了，那是我的问题，不是你的错。""我刚才说的话太重了，我不应该那样说。""我刚才吼你，是因为我没控制好自己的情绪，不是因为你有多糟糕。" |
| **P** Play back child's experience 回放感受 | 帮孩子命名情绪（孩子无法自己处理） | "你刚才被我吼的时候，是不是很害怕？""你是不是觉得妈妈/爸爸不爱你了？""你是不是觉得不管你怎么努力我都不满意？" |
| **A** Affirm connection 确认连接 | 用语言 + 身体语言确认关系 | "不管发生什么，妈妈/爸爸都爱你。这一点不会变。""你对我很重要，比任何事情都重要。" |
| **I** Invite new interaction 邀请新互动 | 让孩子体验"关系可以修复" | "我们现在重新来一次好吗？""你能不能再告诉我刚才发生了什么？这次我会好好听。" |
| **R** Re-establish rules 重建规则 | **修复完成后**，平静地重申规则 | "规则还是不变的。只是我刚才表达的方式不对。""我们还是需要讨论作业/手机，但这次我不会吼你。你准备好聊了吗？" |

**关键细节**：孩子点头或说"是"时，**不要辩解**，只说"嗯，我理解"。身体语言：蹲下来与孩子平视；孩子愿意就拥抱；孩子后退就不要追，保持距离但保持眼神接触。

**四个场景模板**

```
【场景 1 · 吼了孩子】
"妈妈/爸爸刚才吼你了，对不起。
 那是我自己情绪没控制好，不是你的错。
 你被我吼的时候，是不是吓到了？（等待回应）
 嗯，我理解。妈妈/爸爸永远爱你，这一点不会变。
 我们现在重新聊一下刚才的事情好吗？这次我会好好说话。"

【场景 2 · 打了孩子】
"妈妈/爸爸刚才打你了，对不起。那是我做错了，我没有任何理由打你。
 你痛不痛？（等待回应，如有伤先处理）
 你是不是很害怕？（等待回应）
 我保证以后不会再打你。如果我又失控了，你提醒我好吗？
 我爱你，不管发生什么。"

【场景 3 · 说了伤害性的话】
"我刚才说[具体话]，那是不对的。那不是事实，我生气的时候说了伤人的话。
 你是不是很受伤？（等待回应）
 你不是[笨/没出息/废物]。你是[孩子名字]，你很特别。
 我收回那句话，那不代表我的真实想法。"

【场景 4 · 冷暴力/忽视后】
"我刚才不理你/不看你，对不起。那是因为我自己在生气，不是因为你做错了什么。
 你是不是觉得我不在乎你了？（等待回应）
 我在乎你。我只是需要时间冷静，但我应该告诉你，而不是不理你。
 下次我需要冷静的时候，我会说'我需要 5 分钟'，好吗？"
```

**什么时候修（时机）**

| 时机 | 建议 |
|---|---|
| 刚发完火（5 分钟内） | ❌ 不要立刻修——你的情绪还没稳定 |
| 冷静后（15-30 分钟） | ✅ 最佳时机——你已冷静，孩子还在消化 |
| 当天晚些时候 | ✅ 可以，比不修好 |
| 第二天 | ⚠️ 可以，但效果递减 |
| 从不修 | ❌ 最糟——孩子学到"伤害是正常的" |

**会不会碰到的心理障碍（先拆掉再修）**

| 你的想法 | 为什么是障碍 | 怎么突破 |
|---|---|---|
| "道歉没用，我又会犯" | 完美主义阻止了修复 | 修复不是承诺不再犯，是承认这次错了 |
| "孩子还小，不懂" | 低估孩子的感受能力 | 3 岁以上的孩子都能感受到被伤害 |
| "道歉会让孩子不尊重我" | 混淆权威与尊重 | 道歉恰恰赢得尊重——你示范了勇气 |
| "我爸妈从来不道歉" | 代际模式 | 你可以选择不同，打破链条从你开始 |
| "道歉了孩子会得寸进尺" | 担心失去控制 | 修复关系 ≠ 放弃规则；先连接，再管教 |

**修复不等于**

- ❌ 否认发生过的事（"算了，别提了"）
- ❌ 用礼物代替对话（买玩具但不说话）
- ❌ 让孩子安慰你（"妈妈也很委屈"）
- ❌ 期待孩子立刻原谅（"我都道歉了你还想怎样"）
- ❌ 重复犯同样的错却不改变（道歉变成形式）

> **安全阀**：道歉之后规则要照旧；如果失控变成本月反复出现（≥ 每月 2-3 次）、出现打骂升级、孩子出现退缩/讨好/自伤，**不是靠修话术能解决的** → 转 `07` §5、`09` §3，必要时专业帮助。

### 5.3 呼吸计时（自己用，60 秒）

```
吸气 4 秒 → 屏息 2 秒 → 呼气 6 秒     ← 做 3 轮
（睡前放松版：吸气 3 → 屏 7 → 呼 3）
```

要点：呼气比吸气长（激活副交感）；肩颈放松，不追求"吸满"；做完再说话。**孕期使用屏息版前先咨询医生。**

### 5.4 场景练习（照着演一遍，比看十遍有用）

**练习 1 · 孩子说"不"**

1. 危机检测 → 无信号，进入正常分析；
2. 错位识别 → 某年龄段的"不"可能是独立意识萌芽（`05` §5）；
3. 回应结构（先接、再问、再分析）：

> "X 岁的孩子说'不要'，是一个很健康的发展信号——他在学习'我是一个独立的人，我有选择的权利'。"
> "但听起来你真的很累。这种'说什么都被拒绝'的感觉会让你很无力，对吗？"
> "当你让他'做'什么的时候，他的反应是什么？— 什么都不做 / 做但很勉强 / 做一半就停了"

**练习 2 · "我知道不该打孩子，但我忍不住"**

1. **共情优先**："我能听到你很挣扎——你知道打孩子不是你想做的，但你又控制不住。这种内心的撕裂感，让你很累，对吗？"
2. **不评判**："你不是'坏父母'。你是一个在压力下的父母，正在用你学过的方式处理问题。"
3. **给工具**：介绍 §5.1 愤怒按停术（6 秒：停下 → 呼吸 3 次 → 扫描身体）。

**练习 3 · 单亲/伴侣缺位**

1. 确认感受："独自承担所有育儿责任，一定很累。你不只是累，你可能还有孤独感，对吗？"
2. **不评判另一方**——不站队，不替家长强化对伴侣的评判；
3. 聚焦他能控制的：减少独自承担的压力 / 改善孩子与另一方的关系 / 找到属于自己的时间；
4. 识别资源：身边有没有可以帮忙的人（家人、社区、学校）。

**练习 4 · "我觉得我是坏父母"**

1. **危机检测**：注意抑郁/自杀风险信号，如有 → 立即转介（`09` §2）；
2. 承认感受："'我是坏父母'这个想法让你很痛苦，对吗？"
3. 重构："你是'坏父母'，还是'有时会犯错、但一直在努力的父母'？这两件事不一样。"
4. 引导自评：想不想做一次 §3.1 的觉醒自评，看看自己现在在哪一级。

**四条通用原则**：① 先共情，后分析；② 不评判、不站队；③ 给"能控制的那一小步"，不给宏大建议；④ 一切从"家长现在的状态"开始，不从"孩子的问题"开始。

### 5.5 父母速查卡（一页版）

**第一个问题（先问自己）**

> "我现在的反应，是在保护孩子，还是在保护我自己？"
> 保护 = 让孩子安全；防御 = 让自己感觉正确。

**第二件事（先做）**

> 停下来 → 冷水冲手 10 秒 → 退后一步 → 再说话。

**第三句（直接说）**

> "我刚才做错了。那是我的问题，不是你的错。"
> "我不知道怎么停下来，但我现在知道了。"
> "这是我的功课，不是你的。"

**第四个判断（安全信号）**

| 信号 | 行动 |
|---|---|
| 孩子有自伤/自杀念头 | 立刻就医（`09` §2） |
| 疑似虐待（含自己忍不住要打） | 儿童保护机构 / 立即求助（`09` §2） |
| 持续拒绝上学、社交退缩 | 心理咨询（`08` §3、`09` §7） |
| 情绪崩溃但能恢复 | 用 §5.1、§5.2 工具处理 |

**第五个认知（核心立场）**

> 不是"孩子有问题"，而是"我的反应在创造问题"。
> **认错，是改变的开始。**

### 5.6 年龄速查表（常见挑战 → 先问自己什么 → 优先做什么）

| 阶段 | 常见挑战 | 先问自己 | 优先行动 |
|---|---|---|---|
| **0-3 岁（萌芽期）** | 哭闹 | 你听到哭声时身体里发生了什么？ | 先认同，不立刻止哭 |
| | 咬人/打人 | 他在说什么？ | 教替代词，不是惩罚 |
| | 分离焦虑 | 谁更难受？ | 承认分离的痛苦，给过渡物 |
| | 吃饭/睡觉 | 谁在控制谁？ | 设定边界但给选择 |
| **3-6 岁（成长期）** | "不"满天飞 | 他在说"不"的时候，他是在说什么？ | 这是自主性，不是叛逆 |
| | 说谎 | 他害怕什么？ | 不要审判，先了解恐惧 |
| | 社交冲突 | 他学到了什么？ | 不是裁决，是教 |
| | 秩序敏感 | 打破秩序让他崩溃——这正常吗？ | 给他预告和准备 |
| **6-12 岁（扎根期）** | 成绩焦虑 | 你害怕的是什么？ | 是他的成绩还是你的面子 |
| | 朋友问题 | 你小时候怎么处理？ | 你的方法现在还能用吗 |
| | 作业拖拉 | 是不会还是不敢？ | 先问，不要假设 |
| | 青春期前期 | 门开始关上了吗？ | 现在打开还来得及 |
| **12-18 岁（觉醒期）** | 叛逆 | 谁在定义"叛逆"？ | 他在争取独立，不是攻击你 |
| | 手机/游戏 | 禁止有效吗？ | 协商规则，不要禁令（`08` §5） |
| | 成绩突然下降 | 你先问他还是先给建议？ | 先听 |
| | 拒绝交流 | 你给他的空间够吗？ | 减少追问，减少控制 |

> 速查表只提示"往哪看"，具体做法在 `05`、`06`；年龄段发育标准在 `01`。

### 5.7 每日反思提示（选 1 问，写 3 行即可）

- 今天哪一个瞬间，我的反应比事情本身更大？
- 今天我做什么时，孩子主动靠近了我？
- 今天我有没有替孩子做了他本可以自己做的事？
- 我今天说的哪句话，我希望他记住？哪句话希望他忘掉？
- 今天我的身体在什么时候给我发过信号（胸闷、咬牙、声音变硬）？

> 反思记录模板见 §2.7。**反思是给自己的，不是给自己判刑的。**

### 6.7 怎么用这份清单（给家长的建议）

- **初学者**：从父母效能训练（PET）与正面管教的**基础课程/入门书**开始，别一上来啃理论。
- **有基础者**：看依恋理论、家庭系统治疗等进阶内容。
- **按需取用**：不要一次买十本。当前卡在哪，就读哪一本的对应章节（例如：只想解决"忍不住吼"，直接读《不吼不叫》+ §5.1、§5.2）。
- **不追爆款**：任何"三天改变孩子""一招搞定"的说法，先按 `09` §4 做来源可信度检查。
- **回末延伸阅读（按需，不主动堆书单）**：家长问"想系统学/有没有书"或当前议题有经典对应书目时，从 §6.1/§6.3 推荐 **1-2 本最相关**的并给一句话理由（如吼叫议题→《不吼不叫》）；平时回答末尾不主动附书单。
