# 12 · 叙事与场景引擎

> **加载时机**：需要生成**面向孩子的内容**（跟孩子说的话、小故事、亲子仪式、角色扮演台词）；或需要按"**正在发生 / 事后修复 / 日常预防**"三种时机选择应对策略时加载。
> **读法**：只读命中章节——§1 时机三分×六场景 / §2 年龄分层叙事规则 / §3 固定家庭仪式 / §4 高频场景速查 / §5 内容规则与输出契约。
> **配套**：行为情绪的处理工具读 `05`；话术原句读 `06`；家长自救读 `07`；情绪小生物映射读 `05` §11；红色风险只出安全引导（`09` §2），**本文件不适用于红档**。
> **口径**：本文件是**辅域**——与主域文件同时命中时，主域定"做什么"，本文件定"按什么时机说、怎么说给孩子听"。单次回答最多加载 2 个文件的纪律不变。

## §1 时机三分 × 六场景速查

**先判时机，再选动作**：同一问题，"正在发生"只求降温、"事后修复"只求连接与复盘、"日常预防"只求演练与规则。时机判定错，动作就会错（如风暴中讲道理）。

| 场景 | 正在发生 | 事后修复 | 日常预防 |
|---|---|---|---|
| **情绪管理** | 稳家长→命名身体信号→一个共调节动作→平静后才给一个微小选择。**不要**：多提问、讲长故事、讲道理、多策略齐上 | 认可家长辛苦→家长自责先自我关怀（`07` §3.3）→低羞耻修复脚本（`05` §10）→帮孩子命名→约定下次小仪式 | 介绍一种情绪/小生物→连一个身体信号→练一个动作→固定趣味短语收尾 |
| **行为引导** | 一句话讲行为背后的需求→温和坚定说一句→给规则内一个选择；升级即切情绪管理。**不要**：讲道理、威胁后果、妥协底线、忽视情绪 | 不指责回顾→命名感受→重申规则+原因→约定下次做法 | 平静时立规则→规则可视化（贴纸/约定卡）→预演场景（"明天又想买玩具怎么办"）→做到及时肯定 |
| **学习支持** | 识别卡点（不会/不想/太累/太难）→稳家长（不催不吼不代劳）→一个小策略重启（拆任务/先做最简单的/歇 5 分钟）→肯定努力。**不要**：替做、反复催、拿排名施压、"这有什么难的" | 先修关系（若吼过）→一起复盘卡点→认可做到的部分 | 固定时间地点清干扰→练拆分与时间管理→养动机（好奇/胜任/自主）→家长觉察自己的焦虑不传递 |
| **社交问题** | 倾听不急着出主意→验证感受（"被排挤确实难受"）→帮孩子看自己能做的→涉安全升级（`09`/`08` §4）。**不要**："没什么大不了"、催"打回去/告老师"、批评其朋友、替孩子出头 | 回顾事件→命名感受与需求→角色演练"下次可以怎么说" | 练社交技能（加入/表达不同意/说不）→借游戏故事讨论场景→帮孩子找到舒适社交方式 |
| **青春期沟通** | 家长先稳住→不在情绪高峰解决问题→给双方降温→择机平等对话。**不要**：权威压制、翻旧账、讽刺、当众批评 | 主动找时机不强迫→承认自己说过头的话→表达无条件的关心→邀请而非要求对话 | 保住非正式连接（一起吃饭/运动）→"被邀请才给建议"→对孩子的世界好奇而非监控→适度自我暴露 |
| **家长成长** | 不分时机，按当下需求：**自责/内疚**→先接住再正常化再给行动（`07` §3.3、§6）；**教育分歧**→找共同目标给沟通框架（`07` §4.5）；**焦虑比较**→发展科普+接纳+聚焦自家孩子；**耗竭**→认可+正常化+自我关怀（`07` §6.4） | — | — |

## §2 年龄分层叙事规则（生成"面向孩子的内容"前必读）

| 年龄 | 规则 |
|---|---|
| 0-3 岁 | **不生成面向孩子的文字内容**。只指导家长的回应方式（动作、表情、语气、节奏）："他现在可能是……你可以……" |
| 3-4 岁 | 每次 2-4 句短话；不用抽象推理；靠声音、节奏和动作；最多给 1 个选择 |
| 5-6 岁 | 4-6 句短话；可用简单因果；一个情绪词 + 一个身体词；平静后给 1-2 个平等选项 |
| 7-8 岁 | 简短故事 + 命名与反思；可以包含"下次我们可以试试……"；保持具体 |
| 9-12 岁 | **不生成面向孩子的叙事内容**；用更成熟的比喻和直接情绪语言；可讨论策略与计划；"协商"口吻 |
| 13-18 岁 | **不对青少年"讲故事"或用幼稚化框架**；以"家长可以这样说"给对话建议；平等尊重 |

同一家庭多个孩子可能处于不同阶段，按各自阶段分别适配；边界年龄（3/6/12 岁）按具体描述灵活判断，不机械切分。

**年龄-场景交叉速查**（同一行为，不同年龄本质不同）：

| 场景 | 0-3 岁 | 3-6 岁 | 6-12 岁 | 12 岁以上 |
|---|---|---|---|---|
| "不听话"/规则冲突 | 自主性萌芽：转移注意+有限选择 | 自主 vs 规则初碰：接情绪+温和坚定+选择 | 规则意义与公平诉求：解释原因+协商+自然后果 | 权力关系重组：平等对话+协商规则+底线清晰 |
| 手机/屏幕 | 引导家长自身少当着孩子刷 | 缺替代活动：清晰规则+缓冲仪式+丰富活动 | 成就感/社交/逃避多需求：协商时间+替代满足 | 社交核心工具：协商而非控制+数字素养+信任 |
| 社交困难 | 平行游戏阶段，无需担心 | 社会化启蒙：旁观引导+示范社交语言 | 被排挤很痛：倾听+验证+技能练习 | 同伴核心、家长影响力下降：不批评朋友+做安全港 |

## §3 固定家庭仪式（0-8 岁，反复使用同一套）

让体验熟悉化，优先重复固定仪式，而非每次创造新玩法：

1. **"小生物来了"**——情绪小生物到场（`05` §11 选映射）；
2. **"身体哪里有感觉？"**——它跑到身体哪里了；
3. **"一起做一个动作"**——大人和孩子共同完成（吹火/踩地/拥抱）；
4. **"平静一点再选下一步"**——不着急，孩子不升级了才给选择。

危机模式下只用一个小生物、一个动作、一个微小选择（`09` 红档时整套仪式停用，只出安全引导）。

## §4 高频场景速查（底层情绪/需求 → 建议第一步）

> 与 `05`/`06` 重叠的常规场景不重复收录，此处收**时机维度下容易做错**的场景格。

| 场景 | 底层情绪或需求 | 建议第一步 |
|---|---|---|
| 不肯刷牙/洗澡/上床 | 挫败、疲劳、失控感（正在发生） | 节奏引导 + 过渡提示，不催促 |
| 出门前磨蹭 | 焦虑、抗拒、不堪重负 | 倒数 + 牵手连接 |
| 公共场合哭闹 | 不堪重负、羞耻、恐惧 | 减少围观压力 + 落地感，先离场再处理 |
| 屏幕时间结束 | 失落、被突然中断 | 预设缓冲仪式，提前 5 分钟预告 |
| 想买玩具不买就闹 | 即时满足、自主感 | 共情+坚定（"今天不买"）+ 延迟计划（写进愿望清单） |
| 说脏话/打人 | 试探边界/表达愤怒 | 温和阻止 + 命名需求 + 教替代表达 |
| 写作业拖拉 | 太难/太无聊/太疲劳/干扰 | 识别卡点 + 拆分 + 先做最简单的（`05` §8） |
| 不想上学 | 社交/学业/老师/起床困难（需分辨） | 倾听原因 + 不急于解决 + 找真正痛点（`03` §3、`08` §4 排查） |
| 考试焦虑 | 怕失败/家长期望太高 | 正常化 + 准备策略 + 减少结果导向 |
| 被同学排挤 | 归属感、被接纳 | 倾听+验证+不急于出主意（`08` §4） |
| 跟好朋友闹翻 | 连接、被理解 | 命名感受 + 讨论修复方式 |
| 对着干/顶嘴（青春期） | 自主性、被尊重 | 不升级对抗 + 降温 + 择机平等对话 |
| 什么都不说（青春期） | 空间、不被审问 | 保持可用性 + 不追问 + 用行动连接 |

## §5 面向孩子的内容规则与输出契约

### 5.1 内容规则（生成"跟孩子说的话/小故事"时）

- **正在发生时**：面向孩子的内容 ≤ 5-6 句（低龄更少）；命名小生物与身体信号（0-8 岁）；只给一个动作；孩子不升级了才给选择。
- **事后修复时**：不详细重述冲突；聚焦安全、关爱与重新连接；给双方的艰难感受留空间。
- **日常预防时**：保持趣味简短；用重复的熟悉短语；排练而非解释。
- 家长要"讲个故事"：故事服务于当下的情绪与场景（把孩子的处境投射到角色），长度按 §2 年龄分层，结尾回到"下次我们可以试试……"。

### 5.2 输出契约（适用时按此顺序组织，并入主技能文件的「输出结构」）

1. **给家长先看的**：发生了什么（一句发展心理学解释）→ 此刻先做 → 现在可以说（1-2 句原话）→ **现在先别做**（1-2 件）；
2. **给孩子的内容**（3-8 岁适用，按 §2 分层；9 岁以上改为"家长可以这样说"）；
3. **可以一起做的动作**（一个具体亲子互动）；
4. **长期建议**（1-2 句：规则/习惯/沟通模式）。

### 5.3 结束原则

成功的结局不是"孩子听话了"——压力下的服从是顺从，不是成长。成功的结局是：家长回到稳定状态、孩子感到被理解、亲子关系依然可用、家庭多了一个可重复使用的方法。
