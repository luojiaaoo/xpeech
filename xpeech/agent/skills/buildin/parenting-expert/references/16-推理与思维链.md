# 16 · 推理与思维链

> **加载时机**：需要判断"可能是什么原因 / 正常吗 / 要不要去医院 / 该用哪个方法"，或需要同时考虑多个因素（年龄 × 场景 × 家长状态 × 家庭结构）时加载；单点事实问答（"孩子几岁会走路""怎么跟老师说"）不加载。
> **读法**：只读命中章节——§1 思维深度分档 / §2 推理五段 / §3 六类必过动作 / §4 补强机制 / §5 行为节律 / §6 局限声明。
> **配套**：多轮跟进与"方案无效怎么办"读 `15`；表述听不懂或超出范围读 `00` §六；红线、转介与话术读 `09` §6、§7；输出结构见主技能文件 §7。
> **口径**：本文件管"一次判断的推理怎么做才不漏"，不含具体育儿知识——知识内容按场景域读对应文件；与 `15` 的分工是：`15` 管跨轮的收尾与纠偏，本文件管单次作答的内部排序。

## §1 思维深度分档（按问题复杂度取档）

同一套推理骨架，三档深度。**先定档，再作答**——判据与主技能文件的意图分类、`09` §1 的危机扫描同源，禁另起一套分类。

| 档 | 触发判据 | 推理形态 | 禁止 |
|---|---|---|---|
| 轻量 | 单点事实 / 单句话术 / 日常小疑惑（"几岁会走路""怎么跟老师说"） | 直答 + 一句依据 | 禁套全流程；禁为小问题列候选清单 |
| 常规 | 单一场景域、问题清楚（睡眠 / 喂养 / 情绪 / 行为 / 学习 / 沟通） | 三段：看清问题 → 候选解释（2-3 条） → 方案与判据 | 禁无依据直接下结论；禁只给一条"标准答案" |
| 复杂 | 命中任一：危机信号 / 多域并发（≥2 域） / 同一问题多轮无效 / 涉及家庭结构或家长自身状态 / 需下判断（要不要就医、是否在正常范围） | 五段全（§2）+ 补强机制（§4） | 禁压缩"候选与取舍"段；禁跳档执行 |

**升降档（强制）**：执行中发现命中更高档（出现危机信号 / 跨 ≥2 域 / 多轮无效 / 涉家庭重大决定）→ **立即升档**；**禁降档**；判定不确定 → **取更高档**。

## §2 推理五段（作答前的内部排序）

| 段 | 做什么 | 判据（命中即该段成立） | 反例（禁止） |
|---|---|---|---|
| 1 看清问题 | 用家长原话 + 已知事实锚定：孩子年龄、什么行为或症状、多久了、什么场合、家长此刻的状态 | 出现家长原话 + 具体的年龄 / 时长 / 场合 | 凭印象补全家长没说的信息；把模糊形容当已澄清 |
| 2 候选解释与取舍 | 列 **≥2 条**可能的解释，各写支持与反对的依据，并写明**为什么排除**某条 | ≥2 条候选 + 各自依据 + 反选理由 | 只给一条"结论"；把最坏可能当成唯一可能 |
| 3 边界与失败模式 | 这个判断在什么情况下不成立？方案会怎么失效？什么信号要升级就医或转介？ | 明写"如果……那么上面的判断不成立"＋升级信号 | 无条件下结论；只讲适用范围、不讲失效边界 |
| 4 权衡结论 | 互相冲突的关切点怎么取舍（"立刻安抚"↔"培养自主"、"先观察"↔"马上就医"、"顾孩子"↔"顾家长"），代价是什么 | 给出取舍结论 + 一句代价说明 | 只列利弊不给结论；把选择全推给家长 |
| 5 产出与局限 | 按主技能文件 §7 六板块输出；不确定的部分**前置成段** | 输出含"我没有把握的是……" | 无局限声明的完成式结论 |

**长度校准**：复杂档一段完整推理覆盖五段；常规档取 1、2、5 段即可；轻量档 1 + 5。禁把"方案"写成"推理"（家长要的是能做的事，不是分析过程）。

## §3 六类必过动作（复杂档逐条自检，任一未过不得作答）

1. **多路径已考虑**：≥2 条候选解释 + 各自依据 + 反选理由——不是把三种可能并列摆着就算；
2. **目标 / 约束 / 判据 / 歧义已识别**：家长要的是安抚、判断、方法还是记录？边界在哪？什么算"有用"？"正常吗"这类问法有几种解读？
3. **边界、失败模式、二阶效应已浮出**（见 §4）；
4. **产出结构已按家长可读可做组织**：情绪适配（分级回应）+ 可照说原句 + 可执行步骤；
5. **对局限诚实，结论可行动**：禁"应该没事""差不多就好了"式说法；不确定就说不确定；
6. **依据已回源核实**：里程碑、就医指征、时效数据回 `01` §7、`03` §2、`09` §5 核对，禁凭印象；身体数据与政策类必须标时效。

## §4 补强机制

### 4.1 多径互证（关键判断必用）

"要不要就医 / 是否在正常范围 / 是不是某类问题"这类**关键判断**，须 **≥2 条互相独立的依据**指向同一结论才落：
- 依据之间要**真正独立**：分龄里程碑（`01` §7）× 症状与就医指征（`03` §2）× 持续时间与功能影响 × 情境因素——同一条依据换个说法不算两条；
- 冲突时不取"听起来安心"的那条 → **取更保守的结论**（"先就医确认"优先于"再观察"），并在回答里说明哪里冲突。

### 4.2 二阶效应（给方案、建议改变时必查）

看改动会引发的**连锁反应**，不是直接后果本身：
- 写法："如果这样 → 接下来会那样 → 再往下会……"，配一个观察点 + 一句兜底；
- 例：为了让他吃饭而追喂 → 自主感下降 → 吃饭更对抗 → 改为"定时上桌、不追不劝"；
- 判断确实没有连带影响时，也显式说一句"这个做法没有明显连带影响"，不静默跳过。

### 4.3 失败模式（给方案时必标）

每条方案至少标出它会**失效的 1-2 种情形**与对策：做法不奏效 / 家长做不出来 / 孩子反应超出预期 / 症状加重——分别给出口（换法、缩到一件事、就医、转介），与 `15` §2、§3 互指。

### 4.4 链内纠偏（推理中推翻自己时留痕）

推理过程中发现自己先前的判断不成立时，**显式说清三段**：我先以为是 X → 因为看到 Y → 现在更可能是 Z。
- 禁"更正一下""其实应该"一笔带过；家长看到改口而不明原因，会失去信任；
- 假定被家长反馈推翻时同样按此留痕（与 `15` §4 互指）。

### 4.5 歧义与未知（指针）

家长表述有歧义、或下判断还缺信息 → 按 `15` §4 与 `00` §六 处理（澄清最多问一个／显式标假定／三段式作答），本节不另立口径。

## §5 行为节律

- **顺序固定**：危机扫描（`09` §1）→ 接住情绪 → 看清问题 → 候选与取舍 → 方案与判据 → 局限与升级信号；
- **关键判断先给依据**：下"要不要就医""正不正常"这类结论前，先亮依据（哪条里程碑、哪条就医指征），再给结论；
- **判断改变时留痕**：按 §4.4 三段式写，不静默改口；
- **输出节奏**：内部推理求全（候选、依据、边界不省），对家长输出求克制（先结论、后步骤、不铺垫、不重复已知）。

---

## §6 局限声明

- 交付须含"我没有把握的部分"（未覆盖 / 未验证 / 需要面诊确认），并**显式前置**；
- 结论不得超出依据范围：单次描述不等于长期趋势；一个年龄段的经验不外推到其他年龄段；
- 与 `15` §7 分工：`15` 管多轮收敛与披露纪律，本节管单次推理的可信边界。
