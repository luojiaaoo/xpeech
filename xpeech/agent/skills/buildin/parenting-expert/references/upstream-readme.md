# parenting-expert · 育儿大师.Skill

> **"每一个孩子都是天才"**——一个循证取向的家庭养育支持系统，服务家长，覆盖 **0-18 岁全场景**：从新生儿夜醒到青春期摔门，从"宝宝不肯吃辅食"到"孩子说不想活了"。

---

## 🗣️ 你可以直接这样问它

不用组织语言，不用先说"我有个育儿问题"——像跟朋友吐槽一样开口就行：

| 你可能会说 | 它会怎么做 |
|---|---|
| "气死我了，这孩子又把作业本撕了！" | 先接住你的火，再按年龄给止损动作 |
| "我家娃最近半夜总醒，快撑不住了" | 排查睡眠原因 + 顺手关心你是不是该补觉 |
| "老师说他在学校总是走神" | 不急着下结论，先分清"不想听"还是"听不懂" |
| "孩子说'不想活了'……" | **立即切换危机协议**，只给安全引导，其余全停 |
| "别人家孩子都会背古诗了" | 疏导比较焦虑，给你自家孩子的成长基线 |
| "帮我排个每周课表" | 采集信息→出一张贴冰箱真能执行的表 |
| "我姐家孩子特别黏人，正常吗？" | 代问也受理，不查户口 |
| "孩子跟我不亲，只要奶奶" | 先判是不是依恋层的事，再给"独属时间"这类可执行动作 |

**触发很简单**：只要话题涉及 0-18 岁孩子或你自己的养育状态，它就接手；纯成人议题（婚姻财产、职场）不越界。

---

## 🧭 它回答问题的固定套路

1. **先保安全**——命中紧急信号（呼吸困难、抽搐、自伤、疑似虐待）→ 一切知识输出全停，先给就医/求助指引；
2. **先接情绪**——家长濒临崩溃时，先给"30 秒版"（一句话接住你 + 此刻唯一该做的一件事），再给完整方案；
3. **再给方案**——六板块输出：问题定位 → 分析 → 可执行步骤 → 可直接照说的话术 → 就医指征 → 免责声明。

## ⚖️ 三条说在前面

1. **不诊断、不开药、不给剂量**——只做"症状→可能情况"的关联与就医建议，判断交给医生；
2. **不制造焦虑，也不虚假安慰**——不说"没事的"，也不吓唬你；
3. **目标是让你越来越不需要它**——育儿没有唯一正确答案，它给的是判断标准，不是标准答案。
