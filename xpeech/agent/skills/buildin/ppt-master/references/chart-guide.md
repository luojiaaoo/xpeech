# 图表类型选择指南

本指南帮助 PPT Master Skill 根据用户的数据特征，推荐最合适的图表类型。

---

## 一、支持的图表类型

以下图表均可通过 `python-pptx` 原生生成，无需额外截图。

| 图表类型 | 配置键值 | 适用场景 |
|---------|---------|---------|
| 柱状图（簇状） | `bar_clustered` | 类别比较、排名（类别 ≤ 8） |
| 柱状图（堆积） | `bar_stacked` | 展示部分与整体的关系 |
| 柱状图（百分比堆积） | `bar_100` | 展示各部分在整体中的占比变化 |
| 条形图（簇状） | `bar_horizontal` | 类别比较（类别名称较长时） |
| 条形图（堆积） | `bar_h_stacked` | 部分与整体（类别名称较长时） |
| 折线图（带标记） | `line_markers` | 连续时间序列趋势 |
| 折线图（堆积） | `line_stacked` | 累计趋势 |
| 饼图 | `pie` | 简单比例/占比（类别 ≤ 5） |
| 饼图（3D） | `pie_3d` | 比例/占比（视觉增强） |
| 环形图 | `doughnut` | 比例/占比（强调整体） |
| 面积图 | `area` | 趋势 + 量级变化 |
| 雷达图 | `radar` | 多维度综合比较 |
| 散点图 | `scatter` | 展示两个变量之间的关系 |

## 三、数据特征 → 图表推荐规则

### 柱状图 / 条形图
- **数据类型**：分类型 X 轴，数值型 Y 轴
- **适用场景**：比较不同类别的数值大小
- **选择规则**：类别标签短 → 柱状图；类别标签长 → 条形图

### 折线图
- **数据类型**：连续型 X 轴（时间/顺序），数值型 Y 轴
- **适用场景**：展示数据随时间或顺序的变化趋势
- **选择规则**：数据点 ≥ 6 时效果最佳

### 饼图 / 环形图
- **数据类型**：分类型，数值型（总和为100%）
- **适用场景**：展示部分占整体的比例
- **选择规则**：类别 ≤ 5 使用饼图，> 5 建议改用柱状图

### 面积图
- **数据类型**：连续型 X 轴，数值型 Y 轴
- **适用场景**：展示趋势的同时强调量级

### 雷达图
- **数据类型**：多维度分类型，数值型
- **适用场景**：同一主体在多个维度的综合表现
- **选择规则**：维度 3-8 个效果最佳

### 散点图
- **数据类型**：两个连续型变量
- **适用场景**：展示两个变量之间的关系
