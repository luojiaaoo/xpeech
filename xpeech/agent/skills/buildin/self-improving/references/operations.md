# 查询、遗忘与导出

操作范围默认是当前用户的 `memory/self-improving/`。只读取当前问题涉及的分类和文件。

## 查询

先选择与具体问题相关的分类，读取已有的 `必读.md`，再读相关主题。目录或文件可能已变化，路径失效时查看实际目录；没有直接匹配的名称时，再在相关正文中定向搜索。

回答应基于读到的内容，必要时给出文件和章节来源。没有记录就说明没有找到，不凭名称补造经验。用户问“上次”或“最近”时，按记录中真实保留的日期和依据回答；没有这些信息就说明无法确定，不能把当前整理结果伪装成完整事件日志。

统计按实际分类、文件和有效规则计算。候选推测不算已验证的方法，必读中的短规则及其引用的详细说明不重复计为两条经验。

## 遗忘与撤销

用户要求“忘记某条经验”且范围清晰时，删除对应正文、相关必读要求以及其他主题中的同一经验副本。文件仍有其他内容时保留它们，整份文件均无须保留时才移除。范围有歧义时先澄清，不扩大为清空整个分类。

若该经验曾提炼到 `memory/MEMORY.md`，且在本次遗忘范围内，再精确删除对应摘要，保留其他事实。`memory/HISTORY.md` 原始会话记录保留原样，不属于经验清理范围。

用户是在纠正旧做法或提出新约定时，修订当前有效规则并保留新条件；不要将规则更新误当成清除历史记录。回查历史时，以当前明确要求和有效备忘录为准，旧说法本身不是重新采用旧规则的授权。

## 导出

默认导出用户指定范围内各分类直接包含的可见 `.md` 文件，保留相对 `memory/self-improving/` 的路径，包含相关必读。不要加入根层杂项、符号链接、隐藏内容、`MEMORY.md` 或 `HISTORY.md`；用户明确要求包含重要长期规则时再纳入 `MEMORY.md` 并说明范围。

用可用的 `shell` 和 Python 标准库 `zipfile` 生成 ZIP，放在数据目录外；同名文件存在时另起名称。核实归档可读取并包含预期文件后，用 `send_file` 返回实际文件。工具不可用或失败时说明情况，不虚构文件或下载地址。
